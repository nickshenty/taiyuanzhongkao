# 高考英语2545词数据集生成完成记录 2026-07-06
## 背景
原方案用LLM逐批生成高考词汇因频繁调用失败废弃，改为从权威开源词表抓取解析，最终从ECDICT开源英汉词典筛选高考标签词条生成数据集。

## 数据源
来源：skywind3000/ECDICT（MIT License）
- 全量CSV共76万词条，文件大小63MB
- 筛选tag=gk的高考词汇共3677条，远大于需求2545条

## 分配规则
按等级分配到56天（Day2-Day57，Day1为测试日不学新词）：
- A2基础级：Day2-Day7 6天，50词/天，共300词
- B1核心级：Day8-Day21 14天，50词/天，共700词
- B2进阶级：Day22-Day42 21天，45词/天，共945词
- C1剩余级：Day43-Day57 15天，40词/天，共600词
总计2545词，全部来自高考大纲范围无超纲词。

## 产出物
1. 生成脚本：./codeact/scripts/generate_vocab_data.py，已注册到codeact索引，支持一键重生成
2. 最终数据集：./codeact/scripts/vocab_data.json，共290KB，JSON格式完全符合要求

## 数据校验结果
- 缺失词性：0，缺失释义：0
- 释义残留词性前缀：0，释义长度全部≤40字符
- 无重复词，所有单词排序后按词频优先选取常用高频词
- 仅5个缺失词性的词由LLM自动补充，剩余全部来自ECDICT原始字段解析
