# 纪检应知应会知识速查索引

> 建设银行党员领导干部党风廉政建设应知应会基础知识汇编（2024年版）
> 共110个知识点，四大部分

## 第一部分：综合知识（知识点1-8）
1. **两个责任**：党委主体责任 + 纪委监督责任
2. **第一责任人**：书记"四个亲自"——重要工作亲自部署、重大问题亲自过问、重点环节亲自协调、重要案件亲自督办
3. **一岗双责**：业务工作 + 党风廉政建设责任制
4. **党建与业务"四同"**：同谋划、同部署、同推进、同考核
5. **党内监督体系**：党委全面监督、纪委专责监督、党的工作部门职能监督、基层组织日常监督、党员民主监督
6. **"三不腐"**：不敢腐、不能腐、不想腐
7. **"四风"**：形式主义、官僚主义、享乐主义、奢靡之风
8. **"三个区分开来"**：先行先试失误 vs 明知故犯；探索试验失误 vs 明令禁止后违纪；推动发展无意过失 vs 谋取私利

## 第二部分：纪律处分条例（知识点9-92）

### 基础概念
9. 党章是最根本的党内法规
10. **处分工作五原则**：党要管党、党纪面前一律平等、实事求是、民主集中制、惩前毖后治病救人
11. **四种形态**：①谈话提醒/批评教育/责令检查/诫勉 ②党纪轻处分/组织调整 ③党纪重处分/重大职务调整 ④严重违纪涉嫌犯罪追究刑事责任
12. **五种处分**：警告、严重警告、撤销党内职务、留党察看、开除党籍
13. **处分影响期**：警告1年、严重警告1.5年、撤销党内职务2年、留党察看恢复后2年、开除党籍5年内不得重新入党
14. **留党察看**：分一年/二年，最长不超2年；期间无表决权、选举权、被选举权

### 从轻/从重/不予追究
15. **从轻/减轻6情形**：主动交代、配合审查如实说明、检举立功、主动挽回损失、主动上交退赔、其他
16. **不予追究**：不可抗力
17. **从重/加重5情形**：强迫唆使他人违纪、拒不上交退赔、处分后又故意违纪、处分后发现遗漏、其他

### 合并处理与特殊情形
18. **合并处理**：两种以上违纪→按最高处分加重一档；其中一种应开除→直接开除
19. 违反刑法不构成犯罪→视情节警告至开除
20. 违反财经纪律→视情节警告至开除
21. **嫖娼或吸毒→开除党籍**
22. 犯罪情节轻微（不起诉/免予刑罚/单处罚金）→撤销党内职务/留党察看/开除党籍
23. **故意犯罪判主刑（含缓刑）/剥夺政治权利/过失犯罪判3年以上→开除党籍**
24. 预备党员违纪→轻则保留（批评教育/延长预备期），重则取消资格
25. 违纪所得→收缴或责令退赔；职务/职称等利益→纠正

### 政治纪律（26-40）
26. 公开发表妄议/丑化言论→视情节警告至开除
27. 制作贩卖传播有严重政治问题资料→警告至开除；私自携带寄递→警告至开除；私自阅看浏览→警告至撤销党内职务
28. 搞团团伙伙/拉帮结派/政治攀附→严重警告或撤销党内职务；导致政治生态恶化→留党察看或开除
29. 结交政治骗子→严重警告至开除；充当政治骗子→撤销党内职务至开除
30. 不落实党中央大政方针→警告至开除
31. 政绩观错位/违背新发展理念→警告至开除
32. 搞两面派做两面人→警告至开除
33. 制造散布政治谣言/诬告陷害→警告至开除
34. 不按规定请示报告重大事项→警告至留党察看
35. 干扰巡视巡察/不落实整改→警告至开除
36. 对抗组织审查（串供/伪造销毁证据/阻止检举/包庇同案/虚假情况）→警告至开除
37. 信仰宗教→限期改正→劝退→除名；参与宗教煽动→开除
38. 组织迷信活动→撤销党内职务至开除；参加迷信活动→警告至开除
39. 不履行主体责任/监督责任→警告至留党察看
40. 放任违反政治纪律→警告至留党察看

### 组织纪律（41-52）
41. 违反民主集中制→警告至留党察看
42. 拒不执行/擅自改变上级决定→警告至留党察看
43. 拒不执行组织分配调动→警告至开除
44. **不按规定说明和报告**：①拒绝作证/虚假情况→警告至开除 ②瞒报个人事项→警告/严重警告 ③不如实说明问题→警告/严重警告 ④不报告个人去向→警告/严重警告 ⑤不如实填报档案→警告/严重警告 ⑥篡改伪造档案→严重警告至留党察看 ⑦隐瞒入党前严重错误→一般除名
45. 违规参加老乡会校友会战友会→警告至撤销党内职务
46. 拉票助选干扰选举→警告至开除
47. 违规选人用人/用人失察→警告至开除
48. 能上能下工作中搞好人主义→警告至留党察看
49. 违规谋取人事利益→警告至开除
50. 侵犯党员权利（压制批评检举等）→警告至开除
51. 违规取得外国国籍/国境外居留→撤销党内职务至开除
52. 违规办理因私出国证件/未经批准出入境→警告至开除；擅自改变行程→警告至撤销党内职务

## 第三部分：相关党内规章（知识点93-99）
93. **问责对象**：党组织+领导干部（重点是党委、纪委及其领导成员）
94. **问责方式**：对党组织→检查/通报/改组；对领导干部→通报/诫勉/组织调整或处理/纪律处分
95. **问责时效**：终身问责
96. **党内监督重点对象**：党的领导机关和领导干部，特别是主要领导干部
97. **述责述廉重点**：政治纪律规矩、管党治党责任、党风廉政建设和反腐败、廉洁纪律
98. **执纪审查重点**：不收敛不收手 + 问题线索集中/群众反映强烈 + 重要岗位且可能提拔（三者同时具备是重中之重）
99. **个人事项漏报/瞒报**：
    - 漏报房产<50㎡或投资<30万→情节较轻→批评教育/检查/限期改正
    - 漏报房产≥50㎡或投资≥30万→情节较重→诫勉/取消考察资格/调离/改任
    - 两种以上漏报→从重
    - 瞒报→诫勉至降职；情节较重→追究纪律责任

## 第四部分：职务违法犯罪（知识点100-110）

### 政务处分
100. **六种处分**：警告、记过、记大过、降级、撤职、开除
101. **处分期**：警告6个月、记过12个月、记大过18个月、降级/撤职24个月
102. **处分影响**：处分期内不得晋升职务/岗位/职称；记过以上不得晋升薪酬；撤职→降低职务+薪酬
103. 公职人员犯罪→故意犯罪判管制/拘役/有期以上（含缓刑）→开除；过失犯罪判3年以上→开除；单处/并处剥夺政治权利→开除

### 贪污罪（第104条）
- 利用职务便利，侵吞/窃取/骗取公共财物
- 3万元以上→3年以下+罚金
- 20万元以上→3-10年+罚金或没收
- 300万元以上→10年以上或无期+罚金或没收；特别重大损失→无期或死刑

### 挪用公款罪（第105条）
- 非法活动：3万元以上立案→5年以下
- 营利活动/超3个月未还：5万元以上立案→5年以下
- 非法活动300万+/营利活动500万+不退还→10年以上或无期

### 受贿罪（第106条）
- 索取/非法收受财物为他人谋利
- 3万元以上→3年以下+罚金
- 20万元以上→3-10年+罚金或没收
- 300万元以上→10年以上或无期；特别重大损失→无期或死刑
- 利用职权地位通过其他国家工作人员→以受贿论处

### 银行特有罪名
107. **违法发放贷款罪**：
    - 数额200万以上 或 损失50万以上→立案→5年以下+1-10万罚金
    - 数额特别巨大或特别重大损失→5年以上+2-20万罚金
    - **向关系人发放→从重处罚**

108. **违规出具金融票证罪**（信用证/保函/票据/存单/资信证明）：
    - 数额200万以上 / 损失50万以上 / 多次违规 / 接受贿赂违规→立案
    - 情节严重→5年以下；特别严重→5年以上

109. **国有企业人员失职罪**：损失50万以上 或 破产/停业停产1年以上→立案→3年以下；特别重大→3-7年

110. **国有企业人员滥用职权罪**：损失30万以上 或 破产/停业停产6个月以上→立案→3年以下；特别重大→3-7年
