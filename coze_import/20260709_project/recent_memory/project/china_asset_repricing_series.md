## 系列结构（暂定6篇）

### 第一篇·总论：全球资产定价的底层逻辑
- 利率、汇率、风险溢价三要素
- 美元周期拐点信号分析
- 人民币升值的经济基础与节奏预判
- 核心观点：中国资产为何"便宜"

### 第二篇·权益类资产：A股核心资产估值修复
- 对比国际同行的估值修复空间
- 重点标的：
  - **金融板块**：建行、工行、招行（低估值+高股息）
  - **消费板块**：茅台、海天、伊利（品牌溢价+消费升级）
  - **科技板块**：比亚迪、宁德时代、中芯国际（国产替代+出海）
  - **能源板块**：中远海能、招商轮船（航运周期+地缘溢价）

### 第三篇·房地产与REITs
- 一线 vs 二三线城市的分化逻辑
- 商业地产REITs的定价重构
- 人口结构与城镇化下半场

### 第四篇·大宗商品与资源
- 黄金、铜、原油的人民币计价逻辑
- 中国定价权的提升路径
- 资源类央企的估值重估

### 第五篇·债券市场
- 中美利差倒挂的修复逻辑
- 外资增持中国国债的趋势
- 人民币国际化的债券支撑

### 第六篇·总结与展望
- 中国资产重新定价的完成度评估
- 未来3-5年的投资主线
- 风险因素与情景分析
