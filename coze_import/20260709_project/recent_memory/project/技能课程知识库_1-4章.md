## 技能一 · 膳食调查与评价

### 技能一第1节：食物摄入量调查

#### 一、膳食调查方法（4种主要方法）

| 方法 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 记账法 | 团体/家庭，有账目 | 简便、成本低、可记录较长时间 | 需完整账目，难精确 |
| 回顾法（24h回顾） | 个人 | 快速、灵活 | 依赖记忆，易低估/高估 |
| 称重法 | 个人/家庭 | 精确 | 工作量大，需连续3天以上 |
| 食物频率法（FFQ） | 大规模流行病学调查 | 快速、可评估长期习惯 | 依赖回忆，量化不精确 |

#### 二、24小时膳食回顾法关键要点
- 询问时间：前一天24小时所有摄入
- 细节：食物名称、品牌、烹饪方法、调味品用量
- 常用辅助工具：食物模型、图谱、家庭用量估算
- 局限性：周末与工作日差异、特殊日子（节日）需排除

#### 三、称重法工作程序
1. 入户称量家中所有可食食物的生重、熟重
2. 计算生熟比 = 生重/熟重（用于折算生重）
3. 记录每餐摄入量
4. 连续称量3天（2个工作日+1个周末）
5. 扣除废弃部分（皮、核、骨）= 实际可食部

#### 四、记账法工作程序
1. 收集食物购买或消耗原始凭证（发票、记录）
2. 统计一定时期内各类食物总消耗量
3. 计算平均每人每日摄入量 = 总消耗量/家庭总人日数
4. 与膳食参考摄入量比较

#### 五、食物频率问卷（FFQ）
- 评估过去1个月～1年的平均摄入频率
- 半定量FFQ：按标准份次询问（如"每天几次/每周几次"）
- 量化关键：标准份的定义（25g面包=1份？）

#### 六、人日数计算
- 概念：一个成人每日消费的食物量
- 折算系数：儿童折算为成年男子的人日数
- 公式：总人日数 = Σ(各类食物摄入量/推荐量) × 标准人系数
- **难点**：不同年龄、性别的折算系数不同

### 技能一第2节：膳食调查结果的计算与评价

#### 一、膳食结构分析与评价

**膳食结构概念**：各类食物的品种和数量在膳食中所占的比重。

**评价依据**：《中国居民平衡膳食宝塔》（2022版）

**评价方法**：
1. 统计各类食物的摄入总量
2. 将被调查者的劳动强度按低、中、高水平
3. 与平衡膳食宝塔建议的各类食物参考摄入量进行比较
4. 分析判断各类食物摄入量是否满足人体需要

#### 二、营养素摄入量计算

**标准人系数折算**：
- 成年男子轻体力劳动 = 1.0
- 成年女子轻体力劳动 = 0.9
- 儿童、老年人按体重/体表面积折算

**人日数计算**：
```
总人日数 = 家庭成员人日数之和
人日数 = 餐次比 × 在家用餐餐次比
```

#### 三、营养素参考摄入量（DRIs）

| 指标 | 定义 | 用途 |
|------|------|------|
| EAR | 平均需要量，满足50%人群 | 评估群体摄入不足 |
| RNI | 推荐摄入量，满足97-98%人群 | 评估个体摄入是否充足 |
| AI | 适宜摄入量，证据不足无法制定EAR时 | 参考摄入水平 |
| UL | 可耐受最高摄入量 | 预防过量 |
| AMDR | 可接受宏量营养素范围 | 三大产能营养素比例 |

#### 四、能量食物来源分配计算
- 蛋白质供能比 = 蛋白质摄入量×4kcal/总能量×100%
- 脂肪供能比 = 脂肪摄入量×9kcal/总能量×100%
- 碳水化合物供能比 = 碳水化合物×4kcal/总能量×100%
- 标准：蛋白质10-20%，脂肪20-30%，碳水50-65%（AMDR）

#### 五、三餐能量分配
- 早餐：25-30%
- 午餐：30-40%
- 晚餐：30-40%
- 评价标准：各餐能量比例是否合理

#### 六、营养素来源分布
- 动物性食物来源占比
- 植物性食物来源占比
- 三餐食物供能比

#### 七、膳食调查评价工作程序
1. 入户调查：膳食调查方法选择、询问、记录
2. 记录并计算这三天的营养素摄入量
3. 与参考摄入量做对比并做出评价
4. 根据调查结果优化膳食结构

#### 八、人群膳食调查报告撰写格式
**内容结构**：
- 题目、报告撰写者姓名和单位
- 前言
- 主体：人群对象、材料、方法、结果
- 讨论
- 结语
- 参考文献
- 致谢

**撰写工作程序**：
① 撰写提纲：背景、目标、方法、结果、结论  
② 撰写背景和目标  
③ 描述调查方法  
④ 描述被调查群体人口基本情况  
⑤ 描述食物摄入情况  
⑥ 描述居民膳食能量和主要营养素摄入情况  
⑦ 居民膳食结构现状与《膳食指南》比较  
⑧ 结论和建议  
⑨ 全文修改和完善
