# 隆中计划

## 基本信息
- **项目代号：** 隆中（取自诸葛亮"隆中对"——一次咨询定一生走向）
- **品牌名称：** 酉鸣聊升学
- **启动日期：** 2026年7月1日
- **优先级：** 🔴 最高优先级
- **状态：** 规划中
- **对标模式：** 张雪峰式升学指导（个人IP + 付费咨询 + AI驱动）

## 项目愿景
建立AI驱动的升学指导品牌，面向全国所有高考/中考考生和家长。核心模式：
- 高考服务：覆盖全国31个省/直辖市/自治区，服务所有层次考生（985/211/双一流/普通本科/高职专科全部高校约3000+所）
- 中考服务：聚焦山西太原/朔州
- 短视频平台（抖音/小红书）输出升学指导内容，打造个人IP
- AI自动化完成资料收集、政策研究、基础咨询回复
- 基础咨询免费 + 深度咨询付费
- 数据来源多元化：省招办指南、高校招生网、掌上高考、千问高考咨询、第三方数据等
- 极少人力，最大化AI产能

## 商业模式设计
```
内容层（免费引流）：抖音/小红书短视频 → 建立信任 → 积累粉丝
基础服务层（免费/低价）：AI自动问答 → 常见问题解答 → 数据采集
付费服务层（高客单价）：个性化1v1咨询 → 志愿填报方案 → 升学规划
```

## 核心工作内容

### 1. 内容生产（短视频）
- 升学政策解读（新高考改革、强基计划、综合评价等）
- 院校/专业分析（就业前景、薪资、考研率）
- 志愿填报策略（冲稳保、专业优先vs学校优先）
- 热门话题（"选XX专业后悔了吗""XX分能上什么学校"）
- 家长焦虑点切入（"普通家庭孩子怎么选""文科生出路"）

### 2. AI自动化体系
- **资料收集引擎**：全网搜索院校信息、录取数据、政策变化
- **知识库建设**：院校库、专业库、录取数据、政策解读
- **自动回复系统**：基于知识库的问答机器人（微信/抖音/小红书）
- **内容脚本生成**：AI辅助批量生产短视频脚本

### 3. 公司运营
- 公司注册（教育咨询类）
- 账号矩阵运营
- 付费咨询流程设计
- 用户分层管理

## 目标受众
- **核心受众：高考考生家长**（全国，第一阶段聚焦高考，中考暂缓）
- 内容视角：站在家长角度，帮他们算清楚"孩子读什么专业→将来干什么工作→能赚多少钱"这笔账
- 中考（太原/朔州）：第二阶段再启动

## 内容定位演进
- **第一阶段（个人IP）**：数字人出镜，账号"酉鸣聊升学"，以升学规划师身份切入，正文中自然体现20余年体制内经验和国有大行背景
- **第二阶段（机构化）**：积累粉丝后转型专业机构品牌，团队化运营

### 身份露出策略（重要）
- **标题/摘要/封面**：绝不出现"行长""金融高管""银行"等字眼
- **正文内容**：可以模糊提及"我在国有大行工作20多年""体制内管理经验"等，作为可信度背书
- **核心人设**：升学规划师，而非金融高管

## 视频形式（双版本并行）

### 版本A：数字人版（量）
- 定位：大众化内容普及，批量高频输出
- 内容类型：政策解读、院校介绍、专业分析、数据盘点、热点回应
- 产量目标：日更或多更
- 优势：可规模化，成本低，不依赖个人时间

### 版本B：真人出镜版（质）
- 定位：精华深度讲解，建立核心信任
- 内容类型：核心观点输出、深度分析、"行长说"系列、答疑精华
- 产量目标：周更或少量精更
- 优势：人格魅力、权威感、粉丝粘性更强

### 协同策略
- 数字人版负责日常曝光+引流 → 筛选高意向用户
- 真人版负责深度信任建立 → 转化付费咨询
