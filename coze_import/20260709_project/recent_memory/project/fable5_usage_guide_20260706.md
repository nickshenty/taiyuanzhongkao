# Thariq Fable 5 深度使用指南核心要点（2026-07-06）

## 核心思想
人机协作瓶颈不在模型能力，而在用户发现和澄清"未知"的能力。提示词/上下文是"地图"，真实工作的代码/现实约束是"疆域"，两者差距就是未知项。

## 四类未知分类
1. 已知的已知：明确写在提示词里的内容
2. 已知的未知：用户清楚自己还没搞明白的部分
3. 未知的已知：对用户来说显而易见、不会刻意写下来，但看到就能认出的内容
4. 未知的未知：用户完全没考虑过的潜在问题

## 三阶段实操流程
### 实现前
- 盲点扫描：让模型主动帮你找未知的未知
- 头脑风暴+原型：用假数据做原型验证效果再动真实代码
- 反问：让模型围绕歧义点逐个采访用户澄清
- 参考资料优先：直接指向已有代码/设计，比语言描述高效
- 实现计划：先出计划暴露决策点供审阅

### 实现中
维护implementation-notes.md，记录所有偏离计划的决策和原因

### 实现后
打包原型+规格+实现笔记成推介文档，让模型给用户做测验确保理解所有变更
