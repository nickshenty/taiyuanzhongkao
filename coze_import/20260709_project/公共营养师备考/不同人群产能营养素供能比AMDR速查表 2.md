## 三、考试核心记忆口诀

### ⭐ 三大人群三组数
- **成人**：碳水50-65 / 脂肪20-30 / 蛋白10-20（最基础，必背）
- **婴幼儿**：脂肪是主角（48%→40%→35%），碳水蛋白未制定
- **老年人**：蛋白提至**15-20%**（唯一与成人不同之处！）

### ⭐ 易考易错点
1. **4岁是蛋白质AMDR的转折点**：4岁蛋白质8-20%（下限8%），6岁起统一为10-20%
2. **1-3岁脂肪是AI（35%），不是AMDR范围**，容易误选为30-35%
3. **老年人蛋白质下限15%**——这是2023版的核心变化，防肌少症
4. **孕妇乳母AMDR与成人相同**，增加的是绝对量（g/d），不是供能比
5. **碳水50-65%从1岁开始统一适用**，所有1岁以上人群都一样
6. **婴儿期碳水AMDR未制定**，因为母乳/配方奶为主

### ⭐ 供能系数（配合AMDR考计算题）
- 碳水化合物：4 kcal/g
- 蛋白质：4 kcal/g
- 脂肪：9 kcal/g

**计算公式**：某营养素供能比 = (该营养素摄入量×供能系数) / 总能量摄入 × 100%
