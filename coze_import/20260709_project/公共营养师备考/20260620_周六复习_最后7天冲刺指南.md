## 三、易混淆对比（⚠️考试陷阱）

| 疾病 | 缺乏营养素 | 记忆 |
|------|-----------|------|
| 克**汀**病（呆小症） | **碘** | "碘**呆**硒心" |
| 克**山**病 | **硒** | |
| 癞皮病（3D） | **烟酸**（VB3/PP） | |
| 脚气病 | **VB1** | ⚠️不是VB2！ |
| 夜盲症 | **VA** | |
| 坏血病 | **VC** | |
| 佝偻病 | **VD** | |
| 巨幼红细胞贫血 | **叶酸+VB12** | |
| 口角炎/舌炎/唇炎 | **VB2** | |

### 2. 铁/钙吸收因素
| | 促进 | 抑制 |
|--|------|------|
| **铁** | VC + 肉类因子 + 有机酸/胃酸 | 草酸 + 植酸 + 茶多酚 |
| **钙** | VD + 乳糖 + 适量蛋白 | 草酸 + 植酸 + 过量纤维 |

### 3. 蛋白质评价 vs 含量
- 蛋白质评价**5指标**：消化率、生物价(BV)、功效比值(PER)、氨基酸评分(AAS)、净利用率(NPU)
- ⚠️ **蛋白质含量测定 ≠ 评价方法**！

### 4. 膳食调查方法辨析
| 方法 | 特点 | 能否分析个体 |
|------|------|-------------|
| 24h回顾法 | 适合个体+群体，3天含休息日 | ✅可以 |
| 记账法 | 适合集体，可长期 | ❌不能 |
| 称重记账法 | 比记账法精准，适合全年 | ❌不能 |
| 膳食史法 | 人力少，不受主观影响 | - |
| 称重法 | 最精准 | ✅可以 |

### 5. 膳食纤维分类
| 类型 | 包括 | 特点 |
|------|------|------|
| **可溶性** | 果胶、树胶、黏胶、部分半纤维素、低聚果糖 | 降糖降脂 |
| **不溶性** | 纤维素、木质素、部分半纤维素 | 促进肠蠕动 |
- ⚠️ 膳食纤维**不明显促进**矿物质吸收（草酸植酸反而抑制）

## 四、计算题公式速查

### 必会公式
1. **BMI** = 体重(kg) ÷ 身高(m)²
   - 中国标准：24-27.9 超重，≥28 肥胖
   
2. **INQ** = 营养素密度 ÷ 能量密度
   - 营养素密度 = 某营养素含量 ÷ 该营养素RNI
   - 能量密度 = 食物能量 ÷ 能量RNI

3. **供能比** = 某营养素(g) × 供能系数 ÷ 总能量 × 100%

4. **NRV%** = 营养素含量 ÷ NRV × 100%
   - 蛋白质NRV = 60g

5. **烟酸当量** = 烟酸(mg) + 色氨酸(mg) ÷ 60

6. **可食部比例** = 可食部重量 ÷ 毛重 × 100%

7. **称重记账法消费** = 结存 + 购进 - 废弃 - 剩余

8. **标准人日** = 标准人系数 × 人日数

## 六、多选题答题技巧

### 常见"全选"场景
- 膳食纤维生理作用（促进蠕动/降胆固醇/调血糖/增饱腹感）
- 膳食指南核心推荐（8条全对）
- 营养标签强制标示（1+4全标）
- 母乳对母亲益处（降产后出血/乳腺癌/糖尿病/避免体重滞留）
- 亚硫酸盐在罐头中作用（抑酶/漂白/防腐/减少褐变）

### 常见"陷阱"选项
- "蛋白质含量"作为评价方法 → ❌ 不是评价方法
- "VB2缺乏→脚气病" → ❌ 脚气病=VB1
- "硒缺乏→克汀病" → ❌ 克汀病=碘，克山病=硒
- "食盐≤6g" → ❌ 是5g
- "膳食纤维促进矿物质吸收" → ❌ 不明显促进
- "孕早期能量增加" → ❌ 不增加
