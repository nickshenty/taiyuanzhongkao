# 📝 答案与解析

| 题号 | 答案 | 考点 | 解析 |
|------|------|------|------|
| **1** | **B** | 人体骨骼数量 | 成人骨共**206块**，是高频考点。易与儿童骨数量（217-218块）混淆 |
| **2** | **C** | 公共营养师职业守则 | 职业守则4条：遵纪守法/忠于职守/认真负责/科学求实。"仪表端庄"是服务行业通用要求，非本职业守则原文 |
| **3** | **D** | 癞皮病3D | 癞皮病=烟酸缺乏，典型3D：皮炎(Dermatitis)+腹泻(Diarrhea)+痴呆(Dementia)。** dysphagia（吞咽困难）不属于3D**，是干扰项 |
| **4** | **B** | 克山病病因 | 克山病=**硒缺乏**导致的心肌损害（心肌病型）。易与克汀病（碘缺乏→呆小症）混淆 |
| **5** | **A** | 膳食称重法计算 | 可食部比例 = **可食部重量 ÷ 毛重 × 100%**，这是膳食调查的基础计算 |
| **6** | **B** | BMI计算公式 | BMI = 体重(kg) ÷ 身高(m)²。分母是身高的平方，不是身高本身 |
| **7** | **B** | 能量计算题 | 碳水供能量 = 2000 × 55% = 1100kcal；碳水重量 = 1100 ÷ 4 = **275g** |
| **8** | **ABC** | 蛋白质功能 | 蛋白质功能：构成机体组织、调节生理功能、供给能量。**促进脂溶性维生素吸收是脂肪的功能**，不是蛋白质 |
| **9** | **AB** | 必需脂肪酸 | 必需脂肪酸包括：**亚油酸（n-6）**和**α-亚麻酸（n-3）**。油酸和软脂酸是非必需脂肪酸 |
| **10** | **ABC** | 尿液收集 | 24小时尿液收集：①当日晨起第一次尿后开始；②加防腐剂（甲苯/盐酸）；③冷藏保存。**D错误**：记录总量精确到**1ml**，不是0.1ml |
