## 🔥 速记卡2：技能四·膳食指导核心公式

### 三大产能营养素供能比
```
碳水：55%-65%  ← 记住"中间值60%"
脂肪：20%-30%  ← 记住"中间值25%"
蛋白：10%-15%  ← 记住"中间值12%"
```

### 能量计算公式
```
能量(kcal) = 蛋白质(g)×4 + 脂肪(g)×9 + 碳水(g)×4
```

### 食谱编制五步法
1. 确定能量目标（标准体重×体力系数）
2. 计算宏量营养素（按供能比分配）
3. 分配三餐（30-40-30）
4. 选择食物（谷薯→蔬菜→蛋白→奶豆→油）
5. 调整完善（查DRIs对比微调）

### 食谱评价三维度
| 维度 | 评价内容 | 核心指标 |
|------|----------|----------|
| 营养素计算 | 与DRIs比较 | 达标率 |
| 食物结构 | 各类食物比例 | 多样性≥12种/天 |
| 能量来源 | 三大营养素比例 | 三餐30-40-30 |
