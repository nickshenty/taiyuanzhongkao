## 一、营养教育概述

### 营养教育的定义与目的
- **目的**：提高各类人群对营养与健康的认识，消除或减少不利于健康的膳食因素，改善营养状况，预防营养性疾病的发生，提高健康水平和生活质量
- **现代观点**：不仅传播营养知识，还应为个体、群体和社会改变膳食行为提供必需的营养知识、操作和服务
- **特点**：途径多、成本低、覆盖面广

### 营养教育的主要对象
1. **个体**：公共营养和临床营养工作的对象
2. **群体**：学校、部队、食品企业等各类组织机构
3. **社区**：地域性共同体，以居住或工作环境为主的社会联系
4. **其他**：政府部门的有关领导和工作人员

### 营养教育工作者应具备的能力
- 掌握营养与食品卫生学、食品学、预防医学等专业理论
- 了解社会、经济、政策及文化因素对膳食的影响
- 具有社会心理学、认知、教育及行为科学基础
- **具有传播营养知识的能力**
- 有现场组织协调和研究能力

## 二、营养教育的实施步骤

一个完善的营养教育项目应包括**6个方面**的工作：

### 步骤1：了解教育对象
- 对目标人群进行简略调查和评估
- 发现和分析主要营养健康问题
- 从知识、态度、行为（KAP）等方面分析问题深层次原因
- 了解营养相关的人力、财力、物力、政策和信息资源
- 明确哪些行为可以改变，哪些难以改变

### 步骤2：制订营养教育计划
- 根据知信行关系密切程度、行为可改变性、外部条件、危害性、受累人群数量确定**优先项目**
- 确定营养干预目标（总体目标与具体目标）
- 制订传播、教育策略及实施计划

### 步骤3：确定营养教育途径和资料
- 确认是否有现成的营养教育材料
- 确定最佳传播途径：个体传播、面对面交流、讲课、大众传播
- 确定最适合的宣传方式：小册子、幻灯片、录像片、讲课

### 步骤4：营养教育前期准备
- 根据需求编写营养教育材料
- **编写要求**：内容科学、通俗易懂、图文并茂
- 对材料进行**预试验**：
  - 了解教育对象的反映和意见
  - 了解能否接受、记住宣传要点
  - 根据反映修改教育资料
  - 确定推广方式和分发追踪方法

### 步骤5：实施营养教育计划
- 确定宣传材料和活动时间表
- 让工作者明确各自任务
- 通过传播途径将营养内容传递给教育对象
- 观察教育对象反映，按步骤查找原因

### 步骤6：教育效果评价
| 评价阶段 | 主要内容 |
|:--------:|:---------|
| **近期效果** | 知识、态度、信息、服务的变化 |
| **中期效果** | 行为和相关危险因素的变化 |
| **远期效果** | 营养健康状况和生活质量的变化（身高、体重、劳动生产力、智力、寿命、精神面貌、医疗费用等）|

## 三、营养教育的相关理论

### 1. 健康传播理论
- **传播五要素**：传播者、受传者、信息、传播媒介、反馈
- **健康传播**：以"人人健康"为出发点，运用各种传播媒介获取、传递、交流、分享健康信息的过程

### 2. 行为改变理论

#### 知信行理论模式（KAP）⭐重点
- **三个连续过程**：获取知识 → 产生信念 → 形成行为
- "知"是知识和学习
- "信"是正确的信念和积极的态度
- "行"是基于"知""信"而采取的行动
- **三个关键步骤**：接受知识、确立信念、改变行为

#### 健康信念模式（HBM）
是否采纳健康行为与5个因素有关：
1. 感知疾病的威胁
2. 感知健康行为的益处和障碍
3. 自我效能（效能期待）
4. 社会人口学因素
5. 提示因素

#### 计划行为理论（TPB）
帮助理解人如何改变自己的行为模式

## 四、社区营养管理概述

### 社区营养的定义
社区营养是指在社区内，运用营养科学理论、技术及社会性措施，研究和解决社区人群营养问题，包括：
- 食物生产和供给
- 膳食结构
- 饮食行为
- 社会经济
- 营养政策
- 营养教育
- 营养性疾病预防

### 社区的概念
- WHO概念：人口数10万~30万，面积5000~50000km²
- 我国：城市街道/居委会，农村乡(镇)/村
- 具有共同地理环境、文化、利益和问题

### 社区营养管理的基本程序（5步骤）⭐
1. **现状调查**
2. **确定项目目标**
3. **制订计划**
4. **执行计划**
5. **评价效果**

### 社区营养管理的主要工作内容
1. 了解社区人群营养和健康状况及其影响因素
2. 社区营养监测、干预和评价
3. 社区营养改善

## 五、社区动员（5个方面）

### 1. 社区卫生专业人员主动参与
- 基层社区卫生人员是具体执行者
- 是工作计划、实施和评价的技术力量
- 对保证工作顺利开展发挥关键作用

### 2. 促使社区人群主动参与
- 社区基层组织（居委会/村委会）是主要对象
- **家庭**是组成社区的基本细胞
- 利用血缘关系和家庭中不同角色成员参与
- **关键人物**（劳动模范、明星、领导）的"名人效应"

### 3. 动员领导部门积极参与
- 向有关领导宣传工作的目的、意义、预期效果
- 使领导及时了解营养行动计划
- 争取对社区营养工作的支持

### 4. 动员非政府组织参与
包括：营养学会、食物与营养咨询委员会、学生营养与健康促进会、消费者协会、食品协会、老年协会、妇联、青联等

### 5. 加强部门之间的沟通、协调和合作
将社区营养工作融入社区整体工作中

## 七、营养改善项目

### 1. 分析营养问题
- 哪些人患营养不良或慢性病（年龄、职业、经济水平、民族等）
- 存在何种营养不良和营养慢性疾病
- 营养不良的程度
- 营养不良、慢性病的主要膳食原因

### 2. 确定项目目标
考虑因素：
- 特定目标人群营养不良程度、性质和原因
- 干预项目涉及的范围、拥有的资源、社区参与
- 拟选干预措施的有效性、可行性、成本效益

### 3. 制定计划

#### 总体计划主要内容
1. 项目背景描述
2. 总目标及具体分目标
3. 拟采取的营养干预措施（普及营养知识、推行食品强化、补充营养素、改善婴儿喂养、改善环境卫生条件等）
4. 所需人力、物力清单
5. 时间安排
6. 经费预算
7. 执行组织机构和协作单位
8. 项目评价方案（过程评价、效果评价）

#### 制订计划的要求
| 要求 | 说明 |
|:----:|:-----|
| 针对性 | 安排的活动能够实现项目具体目标 |
| 可行性 | 资源、技术、经费、时间、社区参与性符合要求 |
| 靶目标 | 针对高危人群产生效果 |
| 低经费 | 优先选用低成本高效益措施 |
| 可评价 | 有评判标准和可测量性 |

### 4. 执行计划
- 广泛发动和依靠群众
- 保持部门间密切配合
- 做好项目的档案、收支账目及现场工作管理
- 做好项目报告制度（工作进展报告、经费报告、总结报告、评价报告）
- 严格按计划执行并进行监测

### 5. 项目评价（4个方面）⭐
| 评价内容 | 说明 |
|:---------:|:-----|
| **投入** | 资源（经费、食物、材料、交通）和劳动力是否到位、合理 |
| **产出** | 对项目执行系统的评价 |
| **效果** | 对营养健康状况的改善，行为和生理变化（知识提高、观念转变、行为改变、发病率降低） |
| **效益** | 社会效益和经济效益（提高劳动生产率、增强体力、延长寿命、提高生活质量、降低医疗成本） |

## 八、社区营养教育程序

### 基本交流模式
1. **单向交流**：来源→加工→信息→渠道→解码→受者
2. **双向交流**：单向交流+信息反馈
3. **大众交流**：报刊、广播、电视、因特网
4. **参与式交流**：所有参与者同等机会表达意见

### 社区营养教育程序
1. **设计**：确定教育对象、目的、宣传知识、制定目标、选择评价指标、经费预算
2. **选择教育途径和资料**：利用现有宣教材料，选择最佳途径和形式
3. **准备营养教育资料和进行预试验**
4. **社区营养教育实施**：举办培训班、散发材料、组织讨论会
5. **社区营养教育评价**
