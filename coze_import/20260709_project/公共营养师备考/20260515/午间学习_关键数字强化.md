## 🎯 薄弱环节强化

### 【公共营养计算题】

1. **BMI计算**
   ```
   BMI = 体重(kg) / 身高²(m)
   ```
   - 中国标准：18.5-23.9正常

2. **标准体重**
   ```
   男性：身高(cm) - 105
   女性：身高(cm) - 107.5
   ```

3. **每日能量需求**
   ```
   能量(kcal) = 标准体重 × 能量系数
   ```
   | 劳动强度 | 轻/中/重体力 |
   |----------|-------------|

4. **体质指数分类**
   | 分类 | BMI |
   |------|-----|
   | 偏瘦 | <18.5 |
   | 正常 | 18.5-23.9 |
   | 超重 | 24-27.9 |
   | 肥胖 | ≥28 |
