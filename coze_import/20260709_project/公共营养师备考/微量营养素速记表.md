## 三、易混淆速记

| 对比点 | 区分 |
|--------|------|
| 佝偻病 vs 骨软化症 | 佝偻病=婴幼儿，骨软化症=成人；都是**缺VD和钙** |
| 缺铁性贫血 vs 巨幼贫 | 缺铁性贫血=缺**铁**（小细胞低色素）；巨幼贫=缺**叶酸/B₁₂**（大细胞） |
| 夜盲症 vs 脚气病 | 夜盲症=缺**VA**；脚气病=缺**VB₁**（不是缺VB族就脚气） |
| 克汀病 vs 克山病 | 克汀病=缺**碘**（呆小症）；克山病=缺**硒**（心肌病） |
| 癞皮病3D | 缺**烟酸** → 皮炎(Dermatitis)+腹泻(Diarrhea)+痴呆(Dementia) |
| 坏血病 vs 脚气病 | 坏血病=缺**VC**；脚气病=缺**VB₁** |
| VD来源特殊性 | 日照是VD主要来源，食物来源有限 |
| VB₁₂唯一性 | 唯一含金属元素(钴)的维生素；唯一动物来源必需维生素 |
| 铁吸收促进/抑制 | ✓VC+肉类因子+有机酸；✗草酸+植酸+茶多酚+钙锌竞争 |
| 钙吸收促进/抑制 | ✓VD+乳糖+蛋白质；✗草酸+植酸+膳食纤维 |

## 四、数字速记口诀

**矿物质RNI口诀**：
- 钙800、磷720、镁330（mg级）
- 铁12/18、锌12/8.5（mg级，分男女）
- 碘120、硒60（μg级）

**维生素RNI口诀**：
- VA 800/700（μgRAE）、VD 10μg=400IU、VE 14mg、VK 80μg
- B₁ 1.4、B₂ 1.4/1.2、烟酸14/13（mg级）
- B₆ 1.2、B₁₂ 2.4（mg→μg级）
- 叶酸400、VC 100

**缺乏症一句话**：
- 钙→骨软，铁→贫血，锌→不长，碘→呆小，硒→心伤
- VA→夜盲，VD→佝偻，B₁→脚气，B₂→口角，烟酸→3D，叶酸→畸形，B₁₂→巨幼，VC→坏血
