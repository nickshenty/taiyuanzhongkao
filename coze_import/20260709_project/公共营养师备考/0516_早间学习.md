# 早间学习笔记 - 2026年5月16日

## 学习模块：模块九 - 食品安全基础

### 一、食品污染（三大类）

#### 1. 生物性污染
- **细菌**：沙门氏菌、大肠杆菌（常见致病菌）
- **霉菌**：**黄曲霉毒素**（强致癌⚠️，花生、玉米中常见）
- **寄生虫**：蛔虫、绦虫
- **昆虫**：苍蝇、蟑螂

#### 2. 化学性污染
- 农药残留
- **重金属**：铅、汞、砷
- 食品添加剂滥用
- N-亚硝基化合物

#### 3. 物理性污染
- 杂物（金属屑、玻璃碎片）
- 放射线污染

---

### 二、食源性疾病

#### 定义
由摄食进入人体的各种致病因子引起的、通常具有感染或中毒性质的一类疾病

#### 五大分类
1. 细菌性食物中毒
2. 真菌及其毒素食物中毒
3. 动物性食物中毒
4. 植物性食物中毒
5. 化学性食物中毒

#### 预防三原则
1. 防止食品污染
2. 控制细菌繁殖
3. 杀灭病原菌

---

### 三、食品卫生管理体系

#### GMP（食品良好生产规范）
- 从原料到成品的全程质量控制

#### HACCP（危害分析关键控制点）
- 识别关键控制点（CCP）
- 建立临界值
- 监测纠偏

#### 食品标签管理
**必须标注**：品名、配料、净含量、生产日期、保质期
**营养标签**：能量、蛋白质、脂肪、碳水化合物、钠（5项强制）

---

### 四、常见食品卫生问题

| 食品类别 | 主要卫生问题 |
|---------|-------------|
| 粮食 | 霉菌、农药 |
| 蔬菜水果 | 农药残留 |
| 肉类 | 抗生素、激素 |
| 水产品 | 组胺、重金属 |

**重点记忆**：
- 组胺中毒：青皮红肉鱼（如金枪鱼）
- 黄曲霉毒素：强致癌，主要污染花生、玉米、坚果
