### 三、记忆口诀

#### 必需氨基酸（9种）
- 笨蛋(苯丙氨酸)来(赖氨酸)宿(苏氨酸)舍(色氨酸)
- 屋檐(异亮氨酸)下(缬氨酸)
- 一(一亮氨酸)两(亮氨酸)组(组氨酸)
- 蛋(蛋氨酸)家(甲硫氨酸)同音

#### 铁缺乏分期
IDS → IDE → IDA
(储存铁减少 → 缺铁性红细胞生成期 → 缺铁性贫血期)

#### 奶是钙最佳来源
奶制品（最佳）、豆类、虾皮
