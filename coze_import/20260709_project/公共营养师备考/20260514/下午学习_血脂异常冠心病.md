## 一、血脂异常基础知识

### 1. 流行情况（中国数据）

| 指标 | 数据 |
|:-----|:-----|
| ≥18岁成人血脂异常总体患病率 | **40.4%**（约5.6亿人） |
| 高甘油三酯血症 | 13.1% |
| 低高密度脂蛋白胆固醇血症 | 33.9% |
| 知晓率 | 仅11.7% |
| 治疗率 | 10.1% |
| 血脂达标率 | **仅4.8%** |

### 2. 血脂分类

#### 甘油三酯（TG）
- **来源**：食物脂肪消化吸收 + 肝细胞合成（以葡萄糖为原料）
- **去路**：氧化供能、储存于脂肪组织
- **危害**：
  - 空腹TG＞1.7 mmol/L时，心血管风险增加
  - TG≥2.3 mmol/L是心血管疾病**高危因素**
  - TG≥5.6 mmol/L可导致**急性胰腺炎**

#### 胆固醇（TC）
- **来源**：肝脏合成约1g/日 + 食物吸收约0.3g/日
- **特点**：两个来源互相协调，饮食胆固醇对血液影响**极小**
- **去路**：
  - 肝脏转化为胆汁酸（最主要，约0.5g/天）
  - 肾上腺/睾丸/卵巢合成类固醇激素
  - 皮肤转化为维生素D3

#### 脂蛋白对比

| 脂蛋白 | 胆固醇 | 蛋白质 | 甘油三酯 | 磷脂 |
|:------:|:------:|:------:|:--------:|:----:|
| **LDL**（坏） | 50% | 22% | 6% | 22% |
| **HDL**（好） | 17% | 55% | 3% | 25% |

- **LDL-C（低密度脂蛋白胆固醇）**："坏"胆固醇 → 动脉硬化首要因素
- **HDL-C（高密度脂蛋白胆固醇）**："好"胆固醇 → 动脉硬化保护因素

### 3. 血脂异常诊断标准

| 指标 | 合适范围 | 边缘升高 | 升高 | 降低 |
|:----:|:--------:|:--------:|:----:|:----:|
| **TC** | ＜5.18 | 5.18~6.19 | ≥6.22 | - |
| **LDL-C** | ＜3.37 | 3.37~4.12 | ≥4.14 | - |
| **HDL-C** | ≥1.04 | - | ≥1.55 | **＜1.04** |
| **TG** | ＜1.70 | 1.70~2.25 | ≥2.26 | - |

### 4. 冠心病基础知识

- **冠心病**：冠状动脉粥样硬化心脏病的简称
- **病变过程**：冠状动脉硬化 → 血管壁变厚、管腔狭窄 → 心肌缺血
- **临床表现**：
  - 心肌缺血：胸闷、气短、心慌（静坐改善，上楼/负重加剧）
  - 心绞痛：心肌缺血达≥75%时出现剧烈疼痛
  - 心梗（心肌梗死）：血管完全堵塞，心肌坏死
  - 心律失常/心脏骤停

## 二、饮食干预原则（重点）

### 1. 减少能量摄入 + 增加运动

| 方法 | 具体措施 |
|:-----|:---------|
| **饮食** | 少吃精制谷物（白米白面），增加全谷/粗粮/杂豆；不吃甜食/点心/饮料 |
| **运动** | 中等强度锻炼，每天消耗≥200kcal（约中速步行50-60分钟）；累计≥1万步/天 |
| **有氧运动** | 快速步行、慢跑、骑车、游泳、球类、跳舞 |
| **非有氧运动** | 举重、哑铃、俯卧撑、短跑（❌不算） |

### 2. 低饱和脂肪 + 低反式脂肪

#### 饱和脂肪过高危害
- 促进肠道胆固醇吸收、肝脏胆固醇合成
- 升高TC和LDL-C → 动脉粥样硬化、冠心病、高血压
- 增加某些癌症（乳腺癌、结肠癌、前列腺癌）和糖尿病风险

#### 反式脂肪危害
- ↑↑LDL-C（坏胆固醇）
- ↓↓HDL-C（好胆固醇）
- 对血脂的不利影响可能大于饱和脂肪酸

#### 具体做法
1. 选择"瘦"的肉类（鱼虾、海鲜、鸡胸肉、瘦牛/猪/羊肉）
2. 用脱脂/低脂牛奶代替普通牛奶
3. 剔除肉眼可见脂肪（鸡皮、肥肉、肉皮）
4. 不吃猪油、奶油、人造奶油、油炸食品
5. 少吃氢化油、棕榈油、椰子油加工食品

### 3. 增加不饱和脂肪酸

| 类型 | 代表油脂 | 作用 |
|:-----|:---------|:-----|
| **单不饱和脂肪酸** | 橄榄油、油茶籽油、芥花油、高油酸葵花籽油 | ↓TC、↓LDL-C、↓TG、↑HDL-C |
| **多不饱和脂肪酸** | 大豆油、花生油、玉米油、葵花籽油、核桃油、亚麻油、紫苏油 | ↓TC、↓TG（需适量，取代饱和脂肪） |

### 4. 增加DHA + EPA

- **来源**：鱼类（最好）、海藻、蛋黄、鱼油/海藻油补充剂
- **作用**：↓TC、↓TG
- **推荐**：每周至少2次，每次150-200g（≈含200-500mg DHA+EPA）
- 亚麻酸在体内可转化为DHA（但可能不充分）

### 5. 增加卵磷脂

- **食物来源**：大豆制品（豆浆）、蛋黄、瘦肉、卵磷脂补充剂
- **作用**：↓TC、↓TG

### 6. 增加植物甾醇

- **作用**：竞争性抑制肠道吸收胆固醇 → ↓TC
- **来源**：大豆、坚果、烹调油（强化）、植物甾醇补充剂

### 7. 增加膳食纤维（尤其是可溶性）

- **作用**：干扰胆固醇吸收及胆汁酸重吸收，增加胆固醇排泄
- **推荐食物**：
  - 全谷（燕麦、全麦）、粗粮、薯类
  - 大豆、杂豆类、坚果
  - 蔬菜（绿叶菜、十字花科、菌藻类、鲜豆类）
  - 水果（带皮带籽食用更佳）

### 8. 增加植物化学物质

| 类别 | 代表食物 |
|:-----|:---------|
| 红黄颜色蔬菜 | 胡萝卜、番茄、南瓜 |
| 绿叶蔬菜 | 小白菜、菠菜、韭菜 |
| 十字花科 | 西兰花、油菜、甘蓝、菜花、萝卜 |
| 其他 | 大蒜、洋葱、柑橘、蓝莓、沙棘、全谷、咖啡、茶 |

### 9. 限制饮酒

- **限量**：酒精＜25克/日
- **换算**：啤酒750ml / 葡萄酒250ml / 高度白酒50ml
- **公式**：酒精(g) = 毫升数 × 酒精度数 × 0.8

## 四、学习要点总结

### 🔴 考试重点数字
1. 血脂异常患病率：40.4%（约5.6亿人）
2. 血脂达标率：仅4.8%
3. TG边缘升高：1.70~2.25 mmol/L
4. TG升高：≥2.26 mmol/L（心血管高危）
5. HDL-C降低：＜1.04 mmol/L
6. 饮酒限量：＜25g酒精/日
7. 每周吃鱼：≥2次，每次150-200g

### 🟡 关键概念
1. **LDL-C是"坏"胆固醇** → 动脉硬化首要因素
2. **HDL-C是"好"胆固醇** → 动脉硬化保护因素
3. **饱和脂肪和反式脂肪**是升高血脂的主要敌人
4. **单不饱和脂肪酸**（橄榄油）效果最好
5. **膳食纤维**（尤其可溶性）能降低胆固醇吸收
6. 饮食胆固醇对血液影响极小，不必过度限制

### 🟢 实用干预要点
1. 减肥（BMI目标）
2. 有氧运动（≥1万步/天）
3. 少吃饱和脂肪和反式脂肪
4. 增加鱼类摄入（每周≥2次）
5. 多吃全谷物、蔬菜、水果
6. 限制饮酒（＜25g/日）

## 五、对比记忆：冠心病 vs 脑血管疾病营养干预的异同

| 项目 | 相同点 | 不同点 |
|:-----|:-------|:-------|
| 能量控制 | 均需控制总能量、减肥 | - |
| 脂肪限制 | 均需限制饱和脂肪和反式脂肪 | 冠心病更强调单不饱和脂肪酸 |
| 膳食纤维 | 均推荐增加 | - |
| 鱼类 | 均推荐（ω-3脂肪酸） | - |
| 饮酒 | 均需限制 | - |
| 特殊营养素 | - | 冠心病强调卵磷脂、植物甾醇 |
