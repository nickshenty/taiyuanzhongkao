## 三、核心易错点辨析（5分钟）

### ❌ 容易混淆的知识点

| 易错点 | 正确理解 |
|:------:|:--------:|
| 蛋白质主要消化场所 | **胃**（不是小肠） |
| 脂肪主要消化场所 | **小肠** |
| 碳水消化起点 | **口腔**（唾液淀粉酶） |
| 胃液pH | **强酸**（1-2），不是碱性 |
| 胰液pH | **弱碱**（7.8-8.4） |
| 胆汁作用 | **乳化脂肪**（不是消化） |
| 小肠吸收面积 | 环行皱褶+绒毛+微绒毛，约**200m²** |
| 大肠主要吸收 | **水分** |

### 🔑 关键记忆点

1. **铁的吸收**：血红素铁（动物）> 非血红素铁（植物）
2. **铁促进吸收**：维生素C + 肉类
3. **铁抑制吸收**：草酸、植酸、茶多酚（喝茶影响铁吸收！）
4. **钙促进吸收**：维生素D + 乳糖
5. **钙抑制吸收**：草酸、植酸、膳食纤维
