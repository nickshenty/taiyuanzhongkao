## 三、判断题（10题，每题2分，共20分）

| 题号 | 答案 | 核心依据 |

| **1** | **A 正确** | 监督执纪"四种形态"第一种形态=谈话提醒、批评教育、责令检查、诫勉 |
| **2** | **B 错误** | 警告处分不影响薪酬晋升（仅影响职务晋升），记过及以上才不得晋升薪酬 |

| **5** | **A 正确** | 因故意犯罪被判处主刑（含缓刑）或被剥夺政治权利的，应当给予**开除党籍**处分 |
| **6** | **A 正确** | 利用职务影响违规操办婚丧喜庆事宜，造成不良影响的，视情节给予警告直至撤销党内职务处分；借机敛财或侵犯公私利益的，从重加重处分直至开除党籍。题干表述与《纪律处分条例》完全一致 |
| **7** | **A 正确** | 违反接待管理规定超标准、超范围接待或借机大吃大喝，对直接责任者和领导责任者，视情节给予警告直至撤销党内职务处分。题干表述与《纪律处分条例》第116条一致 |

| **9** | **A 正确** | 利用职权为亲属谋取利益，视情节给予警告直至开除党籍处分 |

## 关键知识点速记

### 党纪处分五种及影响期
| 处分类型 | 影响期 | 核心后果 |
|---------|--------|----------|
| 警告 | 1年 | 不得提拔/进一步使用 |
| 严重警告 | 1.5年 | 不得提拔/进一步使用 |
| 撤销党内职务 | 2年 | 不得担任与原职相当或更高职务 |
| 留党察看 | 察看期+恢复后2年 | 无表决权/选举权/被选举权 |
| 开除党籍 | 5年 | 不得重新入党 |

### 政务处分六种
警告(6月)、记过(12月)、**记大过(18月)**、降级(24月)、撤职(24月)、开除

### 六大纪律
政治纪律、组织纪律、廉洁纪律、群众纪律、工作纪律、生活纪律

### "四种形态"
1. 谈话提醒、批评教育、责令检查、诫勉（常态）
2. 党纪轻处分、组织调整（大多数）
3. 党纪重处分、重大职务调整（少数）
4. 严重违纪涉嫌犯罪追究刑事责任（极少数）
