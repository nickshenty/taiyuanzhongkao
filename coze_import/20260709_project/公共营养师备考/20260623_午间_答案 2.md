# 6月23日 午间10题 参考答案

### 单选题
| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | A | 24小时膳食回顾法是**膳食调查方法**四种之一（回顾法、称重法、记账法、食物频率法） |
| 2 | B | 称量法一般要求连续调查**3天**（含1个周末日），取平均值更准确 |
| 3 | A | **孕早期蛋白质不增加**（0g），孕中期+15g/d，孕晚期+30g/d |
| 4 | D | 乳母蛋白质增加**25g/d**（因泌乳需要大量蛋白质） |
| 5 | C | 老年人优质蛋白应占**50%以上**（保证必需氨基酸供应，预防肌少症） |
| 6 | C | 100g生米≈**250g**熟饭（生熟比1:2.5）；100g生面≈150g熟馒头（1:1.5） |
| 7 | C | **称重法**准确度最高（直接称量每餐食物重量），但费时费力 |
