### 解析

**Q1.** NRV% = 营养素含量 ÷ NRV × 100% = 200÷800×100% = **25% → D**

**Q2.** 必需氨基酸8种（口诀：甲硫赖缬异亮苯色苏）+ 婴幼儿组氨酸。丙氨酸人体可自行合成，属非必需氨基酸 → **C**

**Q3.** 烟酸当量 = 烟酸 + 色氨酸÷60 = 5 + 120/60 = 5 + 2 = **7mgNE → B**（⚠️顽固错题：色氨酸÷60！）

**Q4.** VB₆（吡哆醇）作为转氨酶辅酶参与氨基酸代谢 → **C**。A=VD功能，B=烟酸缺乏症，D=VB₆存在于动植物食物中（豆类、畜肉、肝脏、鱼类）

**Q5.** 上臂肌围 = 上臂围 - 3.14×皮褶厚度(mm) = 24.5 - 3.14×2.0 = 24.5 - 6.28 = **18.22cm → B**

**Q6.** B错误。血红素铁吸收率15-35%，远高于非血红素铁1-5% → **B**。⚠️顽固错题强化：铁吸收机制！

**Q7.** C错误。膳食纤维中的草酸、植酸会**抑制**矿物质吸收，不是促进 → **C**。ABDE均为正确功能

**Q8.** B错误（磷脂**有助于**脂肪乳化消化，不是抑制）。ACDE正确 → **ACDE**

**Q9.** C错误。VC促进的是**非血红素铁**吸收，不是血红素铁 → **ABDE**。D=叶酸经典考点，E=色氨酸→烟酸转化

**Q10.** E错误。人体最主要供能物质是**碳水化合物**（供能50-65%），不是蛋白质 → **ABCD**
