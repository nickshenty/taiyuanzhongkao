## 技能（一）膳食调查和评价

### 第一节 食物摄入量调查
**核心考点：**

**一、膳食调查方法（4种）★**
| 方法 | 适用场景 | 优缺点 |
|------|----------|--------|
| 24小时回顾法 | 个人 | 快速、但不适合长期 |
| 膳食称重法 | 团体/家庭 | 精确、但耗时 |
| 食物频率法（FFQ） | 流行病学调查 | 快速、但主观性强 |
| 化学分析法 | 科研 | 最准确、但成本高 |

**二、24小时回顾法要点★**
- 询问近24小时内的食物摄入
- 从每餐开始询问，零食也要记录
- 常用辅助工具：食物模型、食谱图册
- 调查时间：15-40分钟

**三、膳食称重法步骤★**
1. 准备工作：称量容器、食物成分表
2. 称量记录：每日早中晚三次称量
3. 计算生重、熟重、废弃率
4. 整理计算全日食物和营养素摄入量

**四、调味品和油的称量**
- 记录使用总量，计算实际摄入量
- 注意烹调方法和烹调损失

---

### 第二节 膳食调查结果的计算与评价
**核心考点：**

**一、数据计算★**

**1. 食物重量换算**
- 食物可食部比例 = 可食部重量 ÷ 毛重 × 100%
- 实际摄入量 = 可食部重量 × 消费比例

**2. 营养素摄入量计算**
- 全日某种营养素摄入量 = Σ(每种食物消费量 × 该种食物可食部比例 × 食物成分表中的含量)
- 平均每人每日摄入量 = 总摄入量 ÷ 调查天数 ÷ 用餐人数

**二、膳食结构评价★**

**1. 谷类食物**
- 轻体力活动男性：250-300g/d
- 轻体力活动女性：200-250g/d

**2. 蔬菜水果**
- 蔬菜：300-500g/d
- 水果：200-350g/d
- 深色蔬菜应占1/2以上

**3. 蛋白质来源**
- 动物蛋白+豆类蛋白：占总蛋白30-50%
- 优质蛋白：≥30%

**三、膳食调查评价指标★**
| 指标 | 评价标准 |
|------|----------|
| 能量三餐比例 | 早30%、中40%、晚30% |
| 能量来源比例 | 碳水55-65%、脂肪20-30%、蛋白10-15% |
| 蛋白质来源 | 优质蛋白≥30% |
| 铁的食物来源 | 动物性≥20% |
| 钙的食物来源 | 奶类≥20% |

## 技能（二）人体营养状况测定和评价

### 第一节 人体体格测量
**核心考点：**

**一、体格测量常用指标★**

**1. 身高测量**
- 方法：赤足立正姿势，枕骨粗隆最高点
- 记录：精确到0.1cm
- 时间：上午10点前

**2. 体重测量**
- 设备：校正后体重秤
- 要求：空腹、排空膀胱、着轻薄内衣
- 记录：精确到0.1kg

**3. 腰围测量**
- 位置：腋中线肋缘下缘与髂前上棘连线中点
- 标准：男性≥85cm，女性≥80cm为中心性肥胖

**4. 臀围测量**
- 位置：臀部最突出部位

**二、体质指数（BMI）★**
- 计算：BMI = 体重(kg) ÷ 身高(m)²
- 标准：
  - 体重过低：<18.5
  - 正常：18.5-23.9
  - 超重：24-27.9
  - 肥胖：≥28

**三、腰臀比（WHR）**
- 计算：腰围 ÷ 臀围
- 标准：男性>0.9，女性>0.85为中心性肥胖

**四、皮脂厚度测量**
- 常用部位：肱三头肌、肩胛下角
- 测量仪器：皮脂厚度计
- 记录：精确到1mm

**五、上臂围和上臂肌围**
- 上臂围：上臂中点周长
- 上臂肌围 = 上臂围 - 3.14 × 皮脂厚度(mm)
- 参考值：男性25.3cm，女性23.2cm

### 第二节 常见生物样品的收集和保存
**核心考点：**

**一、尿液收集★**

**1. 24小时尿液的收集**
- 收集时间：当日晨起第一次尿后至次日晨起第一次尿
- 保存方法：加入防腐剂（甲苯或盐酸），冷藏保存
- 记录：总量，精确到1ml
- 用途：氮平衡、矿物质代谢研究

**2. 晨尿的收集**
- 收集：清晨第一次尿液中段
- 用途：常规体检、某些代谢物检测

**3. 尿标本保存**
- 冷藏：4℃保存，不超过6小时
- 化学防腐：甲苯（10-20ml/L）、盐酸、硼酸

**二、粪便收集**

**1. 常规粪便收集**
- 收集量：5-10g
- 保存：冷藏24小时内送检
- 或加入10%福尔马林保存

**2. 代谢粪便收集**
- 用于：氮平衡、矿物质吸收研究
- 要求：全部收集，混匀取样

**三、血液采集★**

**1. 末梢血采集**
- 部位：指尖、耳垂
- 优点：方便快捷
- 缺点：易受部位、温度影响

**2. 静脉血采集**
- 部位：肘正中静脉
- 要求：空腹12小时
- 项目：血糖、血脂、肝肾功能、微量元素等

**3. 血标本保存**
- 血清/血浆：分离后冷冻保存
- 全血：冷藏保存
- 及时送检

**四、头发采集**
- 部位：枕部发根处
- 长度：1-3cm
- 用途：反映一段时间内微量元素状况
- 注意：避免使用洗发水、染发剂

**五、生物样品采集注意事项★**
- 采样时间：空腹、安静状态
- 记录：采样时间、患者状态、饮食情况
- 防止污染：无菌操作
- 及时送检或正确保存

### 第三节 营养不良的症状和体征判别
**核心考点：**

**一、营养不良分类**

**1. 消瘦（Marasmus）**
- 原因：能量严重不足
- 表现：体重下降，皮下脂肪减少，肌肉萎缩
- BMI：<18.5
- 特点：身高与年龄比例相对正常

**2. 蛋白质营养不良（Kwashiorkor）**
- 原因：蛋白质严重不足
- 表现：水肿、肌肉萎缩、皮肤病变、肝肿大
- 血浆蛋白明显降低

**3. 混合型营养不良**
- 能量和蛋白质同时缺乏
- 临床表现最严重

**二、蛋白质营养状况评价指标★**

| 指标 | 正常值 | 缺乏标准 |
|------|--------|----------|
| 血清白蛋白 | 35-55g/L | <35g/L |
| 血清前白蛋白 | 200-400mg/L | <200mg/L |
| 视黄醇结合蛋白 | 26-76mg/L | <26mg/L |
| 运铁蛋白 | 2.2-4.0g/L | <2.0g/L |
| 纤维连接蛋白 | 190-280mg/L | <190mg/L |

**三、维生素缺乏症状★**

**1. 维生素A缺乏**
- 眼部：夜盲症、干眼症、Bitot斑
- 皮肤：干燥、毛囊角化过度
- 生长发育：迟缓

**2. 维生素B1缺乏（脚气病）**
- 干性：周围神经炎、感觉异常
- 湿性：水肿、心脏扩大
- 婴儿脚气病：突然心力衰竭

**3. 维生素B2缺乏**
- 口角炎、唇炎、舌炎
- 阴囊炎、皮炎
- 眼部：羞明、流泪

**4. 维生素C缺乏（坏血病）**
- 出血：牙龈出血、皮下出血
- 骨膜下血肿
- 伤口愈合不良

**5. 维生素D缺乏**
- 佝偻病（儿童）：方颅、肋骨串珠、X/O型腿
- 骨软化症（成人）：骨痛、骨质疏松

**6. 烟酸缺乏（癞皮病）**
- 3D症状：皮炎、腹泻、痴呆

**四、矿物质缺乏症状★**

**1. 铁缺乏**
- 缺铁性贫血：乏力、头晕、面色苍白
- 实验室：血红蛋白↓、血清铁↓、铁蛋白↓

**2. 锌缺乏**
- 味觉障碍：异食癖
- 生长发育迟缓
- 免疫功能下降
- 皮肤病变

**3. 钙缺乏**
- 手足抽搐
- 骨质疏松
- 佝偻病

**4. 碘缺乏**
- 地方性甲状腺肿
- 克汀病（呆小症）

**五、体征检查要点★**
- 头发：稀疏、失去光泽
- 皮肤：干燥、弹性差
- 眼睛：Bitot斑、结膜苍白
- 口腔：牙龈出血、舌炎
- 指甲：匙状甲（缺铁）
- 下肢：水肿

## 技能（三）营养咨询和教育

### 第一节 交流和咨询
**核心考点：**

**一、营养咨询的原则★**

**1. 礼貌热情**
- 态度和蔼，营造轻松氛围
- 使用尊称

**2. 通俗易懂**
- 用通俗语言解释专业术语
- 避免医学术语堆砌

**3. 因人施教**
- 根据对象的年龄、文化、职业调整
- 考虑接受能力

**4. 循序渐进**
- 每次讲解1-3个要点
- 重点突出

**二、咨询技巧★**

**1. 倾听技巧**
- 专注、耐心、不打断
- 适当点头、目光接触
- 记录关键信息

**2. 提问技巧**
- 开放式问题：了解更多信息
- 封闭式问题：确认具体事实
- 启发式提问：引导思考

**3. 反馈技巧**
- 正面反馈：鼓励好的行为
- 纠正性反馈：温和指出问题
- 避免批评、指责

**三、咨询步骤★**

1. **准备阶段**
   - 了解咨询者基本情况
   - 准备相关资料、工具

2. **开场阶段**
   - 建立信任关系
   - 说明咨询目的

3. **信息收集阶段**
   - 询问饮食情况
   - 了解健康状况
   - 评估营养需求

4. **分析评估阶段**
   - 分析饮食问题
   - 找出主要营养问题

5. **建议指导阶段**
   - 制定改善计划
   - 给予具体建议

6. **跟踪随访**
   - 定期复查
   - 调整方案

**四、特殊情况处理**
- 拒绝改变：分析原因，寻找突破口
- 焦虑情绪：安抚情绪，建立信任
- 文化差异：尊重习俗，寻找替代方案

## 技能（四）膳食指导和评估

### 第一节 膳食指导和评估
**核心考点：**

**一、膳食指导原则★**

**1. 均衡营养**
- 食物多样，谷类为主
- 多吃蔬菜水果和薯类
- 常吃奶类、豆类或其制品
- 适量鱼、禽、蛋、瘦肉

**2. 清淡少盐**
- 每日烹调油25-30g
- 盐<6g

**3. 食不过量**
- 能量摄入与消耗平衡
- 保持健康体重

**二、特定人群膳食指导**

**1. 老年人膳食指导**
- 少量多餐
- 细软食物
- 预防营养不良
- 补充水分

**2. 儿童膳食指导**
- 保证生长发育需要
- 培养良好饮食习惯
- 控制零食

**3. 孕妇膳食指导**
- 孕早期：清淡少油
- 孕中晚期：增加鱼禽蛋瘦肉
- 补充叶酸、铁、钙

**三、膳食评估方法★**

**1. 膳食多样化评分**
- 满分12分
- 涵盖：谷类、蔬菜、水果、奶类、动物性食物、豆类、油盐

**2. 膳食质量指数（DQI）**
- 综合评价膳食质量

**3. 营养素摄入量评价**
- 与DRIs比较
- 评价达标率

### 第二节 食谱编制
**核心考点：**

**一、食谱编制原则★**

**1. 满足营养素需要**
- 能量满足需要
- 各营养素达到推荐量

**2. 食物多样**
- 每天≥12种食物
- 每周≥25种食物

**3. 比例合理**
- 能量比例合理
- 蛋白质来源合理

**4. 烹调合理**
- 减少营养素损失
- 注意色香味形

**5. 经济实惠**
- 符合当地饮食习惯
- 考虑经济条件

**二、食谱编制步骤★**

**1. 确定能量目标**
- 计算标准体重
- 评估体力活动水平
- 计算能量需要

**2. 计算宏量营养素**
- 碳水化合物：55-65%
- 脂肪：20-30%
- 蛋白质：10-15%（或按1g/kg体重）

**3. 分配三餐**
- 早餐：30%
- 午餐：40%
- 晚餐：30%

**4. 主食选择**
- 粗细搭配
- 全谷物≥1/3

**5. 副食选择**
- 蔬菜：300-500g
- 水果：200-350g
- 动物性食物：适量

**6. 调整完善**
- 营养素微调
- 烹调方法选择

**三、食谱表达形式**
| 形式 | 内容 |
|------|------|
| 表格式 | 列出每餐食物名称和用量 |
| 交换份法 | 按食物交换份分配 |
| 图片法 | 直观展示食物量 |

**四、食物交换份法★**

**1. 谷薯类**
- 1份 = 25g大米 = 25g面粉 = 125g土豆

**2. 蔬菜水果类**
- 1份 = 500g叶菜 = 200g水果

**3. 肉蛋类**
- 1份 = 50g瘦肉 = 1个鸡蛋

**4. 奶豆类**
- 1份 = 250ml牛奶 = 50g豆腐

**5. 油脂类**
- 1份 = 10g植物油 = 15g花生米

### 第三节 食谱营养评价和调整
**核心考点：**

**一、食谱营养评价★**

**1. 营养素计算**
- 查找食物成分
- 计算营养素含量
- 与DRIs比较

**2. 食物结构评价**
- 各类食物比例
- 食物多样性
- 烹调方法

**3. 能量来源评价**
- 三大产能营养素比例
- 三餐能量分配

**二、食谱调整方法★**

**1. 能量调整**
- 能量不足：增加主食、烹调油
- 能量过剩：减少主食、烹调油

**2. 蛋白质调整**
- 不足：增加蛋奶肉豆
- 过量：减少动物性食物

**3. 维生素调整**
- VA不足：增加肝脏、深色蔬菜
- VC不足：增加新鲜蔬菜水果

**4. 矿物质调整**
- 铁不足：增加动物肝脏、血制品
- 钙不足：增加奶类、豆制品

**三、食谱营养标签**

**1. 主要内容**
- 能量、蛋白质、脂肪、碳水化合物
- 主要维生素、矿物质

**2. 表示方法**
- 每100g含量
- 每份含量
- 占NRV%

## 技能（五）食品营养评价

### 第一节 食品营养标签制作
**核心考点：**

**一、营养标签组成★**

**1. 营养成分表**
- 强制标示：能量、蛋白质、脂肪、碳水化合物、钠

### 第二节 食品营养价值分析
**核心考点：**

**一、食品营养价值的评价指标★**

**1. 营养素密度**
- 定义：单位能量食品中营养素含量
- 计算：营养素含量/能量
- 意义：评价食物营养价值

**2. 营养质量指数（INQ）★**
- 计算：营养素密度/能量密度
- INQ=1：营养素与能量平衡
- INQ>1：营养素供给有余
- INQ<1：营养素供给不足

**3. 蛋白质质量评价**
- 氨基酸评分（AAS）
- 蛋白质消化率校正氨基酸评分（PDCAAS）
- 蛋白质功效比（PER）

**二、食物营养价值特点★**

**1. 谷类**
- 优点：提供能量、B族维生素、膳食纤维
- 缺点：蛋白质赖氨酸低

**2. 蔬菜水果**
- 优点：VC、胡萝卜素、叶酸、膳食纤维
- 特点：深色蔬菜营养价值更高

**3. 动物性食物**
- 优点：优质蛋白、脂溶性维生素、矿物质
- 缺点：饱和脂肪、胆固醇

**4. 豆类**
- 优点：优质蛋白、不饱和脂肪酸
- 大豆：异黄酮、植物甾醇

**三、食物营养价值的影响因素★**
- 加工方式
- 烹调方法
- 储存条件
- 成熟度
- 品种

### 必背公式★

**一、体格测量公式**

```
BMI = 体重(kg) ÷ 身高(m)²
理想体重 = 身高(cm) - 105

**二、膳食调查计算公式**

```
某营养素摄入量 = Σ(食物消费量 × 可食部比例 × 营养素含量)
平均每人每日摄入量 = 总摄入量 ÷ 调查天数 ÷ 用餐人数

### 计算题详解★

**类型一：BMI和标准体重计算**

```
例：某男性，身高175cm，体重70kg
求：(1)BMI (2)评价 (3)理想体重

解：
(1) BMI = 70 ÷ 1.75² = 70 ÷ 3.0625 = 22.86
(2) 评价：BMI=22.86，在18.5-23.9范围内，属于正常
(3) 理想体重 = 175 - 105 = 70kg
    或 70 × (1 ± 10%) = 63-77kg
```

**类型二：营养素摄入量计算**

```
例：某人摄入大米200g（含蛋白质8%，铁1.1mg/100g），
    菠菜300g（含蛋白质2.4%，铁2.9mg/100g），
    计算蛋白质和铁的摄入量

解：
蛋白质 = 200×8%+300×2.4% = 16+7.2 = 23.2g
铁 = 200×1.1/100+300×2.9/100 = 2.2+8.7 = 10.9mg
```

**类型三：能量来源计算**

```
例：某人摄入能量2000kcal，其中蛋白质80g，脂肪60g
求：各产能营养素供能比

解：
蛋白质供能 = 80×4 = 320kcal，320÷2000×100% = 16%
脂肪供能 = 60×9 = 540kcal，540÷2000×100% = 27%
碳水供能 = 2000-320-540 = 1140kcal，1140÷2000×100% = 57%
```

**类型四：INQ计算**

```
例：某食物每100g提供能量150kcal，钙100mg，计算钙的INQ
（参考：能量2250kcal，钙800mg）

解：
钙密度 = 100÷150 = 0.67mg/kcal
能量密度 = 2250÷2250 = 1kcal/kcal
INQ = 0.67÷1 = 0.67
评价：INQ<1，对钙营养价值不高
```

**类型五：食谱能量计算**

```
例：某食谱含谷类300g，蔬菜400g，肉类150g，豆腐100g，植物油25g
计算总能量

解：
查表或计算：
谷类：300÷25×90 = 1080kcal
蔬菜：400÷500×90 = 72kcal
肉类：150÷50×90 = 270kcal
豆腐：100÷25×90 = 360kcal
油脂：25÷10×90 = 225kcal
总能量 = 1080+72+270+360+225 = 2007kcal
```

**类型六：24小时回顾法计算**

```
例：某人24小时回顾调查：
早餐：馒头100g，鸡蛋1个(60g)，牛奶250ml
午餐：米饭200g，瘦肉100g，青菜300g，植物油15g
晚餐：面条150g，豆腐100g，青菜200g，植物油10g
计算能量和蛋白质

解：
按各类食物能量和蛋白质含量分别计算并汇总
```
