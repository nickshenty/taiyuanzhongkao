## 第一节 孕妇营养

### 一、孕期生理特点

| 时期 | 时间 | 生理变化 |
|------|------|----------|
| 孕早期 | 1-12周 | 消化系统反应（孕吐）、基础代谢略↑ |
| 孕中期 | 13-27周 | 胎儿快速生长、体重增加、子宫增大 |
| 孕晚期 | 28-40周 | 胎儿成熟、体重增长高峰、行动不便 |

### 二、孕期营养需要 ⭐⭐⭐高频

#### 能量
- **孕早期**：与非孕妇女相同，EER 1800kcal/d（轻体力）
- **孕中期**：+250kcal/d
- **孕晚期**：+400kcal/d

#### 蛋白质
- **孕中期**：+15g/d（65+15=80g）
- **孕晚期**：+30g/d（65+30=95g）
- **重点**：优质蛋白≥1/3

#### 矿物质（重点记忆）

| 矿物质 | 每日推荐 | 缺乏危害 | 食物来源 |
|--------|----------|----------|----------|
| **钙** | 1000mg/d（不随孕期↑） | 母体骨密度↓、胎儿佝偻病 | 奶制品、豆制品 |
| **铁** | 孕中期+7mg/d（19mg/d） | 缺铁性贫血、早产 | 红肉、动物肝脏 |
| **锌** | +5mg/d（9.5mg/d） | 胎儿发育迟缓 | 海产品、瘦肉 |
| **碘** | +110μg/d（230μg/d） | 克汀病 | 碘盐、海带 |

#### 维生素（重点记忆）

| 维生素 | 每日推荐 | 缺乏危害 | 食物来源 |
|--------|----------|----------|----------|
| **叶酸** | **600μgDFE/d**（↑200） | **神经管畸形** | 深绿叶菜、动物肝脏 |
| **VA** | 770μgRAE/d | 胎儿眼发育异常 | 动物肝脏、胡萝卜 |

| **VC** | 115mg/d（+15） | 坏血病 | 新鲜蔬果 |

### 三、孕期体重管理 ⭐⭐⭐必考

| 孕前BMI | 推荐体重增加 |
|----------|--------------|
| <18.5（消瘦） | 12.5-18kg |
| 18.5-23.9（正常） | 11.5-16kg |
| 24-27.9（超重） | 7-11.5kg |
| ≥28（肥胖） | 5-9kg |

**记忆口诀**：瘦多胖少，正常11.5-16

### 四、孕期膳食指南

1. ✅ 补充叶酸，常吃含铁丰富的食物
2. ✅ 选用碘盐（每周1-2次海产品）
3. ✅ 孕中晚期增加奶、鱼、禽、蛋、瘦肉的摄入
4. ✅ 禁烟酒，愉快孕育新生命

## 第二节 乳母营养

### 一、泌乳生理

- **泌乳机制**：催乳素+催产素
- **泌乳量**：平均750-800ml/d
- **乳汁成分**：优质蛋白（乳清蛋白为主）、乳糖、脂肪、矿物质、维生素

### 二、乳母营养需要 ⭐⭐⭐高频

#### 能量
- **EER**：+500kcal/d（约2300-2500kcal/d）
- **判定泌乳量是否充足**：婴儿体重正常增长

#### 蛋白质
- **RNI**：+25g/d（80g/d）
- **优质蛋白**：保证1/3以上

#### 矿物质

| 矿物质 | 每日推荐 | 说明 |
|--------|----------|------|
| **钙** | **1200mg/d** | 维持母体钙平衡 |
| **铁** | 24mg/d | 补充孕期损耗（42天后恢复月经） |
| **锌** | +4.5mg/d（12.5mg/d） | 促进婴儿发育 |
| **碘** | 240μg/d | 碘盐+海产品 |

#### 维生素
- **VA**：1300μgRAE/d（+300）
- **VD**：10μg/d
- **VB1**：1.5mg/d（+0.3）
- **VB2**：1.5mg/d（+0.3）
- **VC**：150mg/d（+50）

### 三、乳母膳食指南

1. ✅ 增加鱼、禽、蛋、瘦肉和海产品摄入
2. ✅ 增加含钙丰富的食物（每天500ml牛奶）
3. ✅ 适当增加汤汁（每天8-10杯水）
4. ✅ 忌烟酒，避免浓茶和咖啡

## 第三节 婴儿营养（0-1岁）

### 一、婴儿期生理特点

- **生长迅速**：第一年体重增长约3倍
- **消化系统不完善**：消化酶活性低
- **免疫功能差**：依赖母乳抗体

### 二、喂养方式 ⭐⭐⭐必考

#### 母乳喂养

**优点**：
1. 营养全面、比例适宜
2. 增强婴儿免疫力
3. 促进母婴感情
4. 经济、方便、温度适宜

**初乳**：产后5天内的乳汁，富含免疫球蛋白（SIgA）

**母乳保存时间** ⭐⭐⭐：
| 保存条件 | 保存时间 |
|----------|----------|
| 室温（25℃） | 4小时 |
| 冰箱冷藏（4℃） | 24小时 |
| 冰箱冷冻（-18℃） | 3-6个月 |

#### 婴儿配方奶

- 无法母乳喂养时的替代品
- 以牛乳为基础改造
- 必须符合GB 10765/10767

### 三、婴儿营养需要

| 营养素 | 0-6月龄 | 7-12月龄 |
|--------|---------|----------|
| 能量 | 90kcal/kg/d | 80kcal/kg/d |
| 蛋白质 | 9g/d | 15g/d（+5） |
| 钙 | 200mg/d | 250mg/d |
| 铁 | 0.3mg/d（储备） | **10mg/d**（辅食） |
| VD | 10μg/d | 10μg/d |

### 四、辅食添加 ⭐⭐⭐高频

**添加时间**：6个月（不早于4个月、不晚于6个月）

**添加原则**：
1. **循序渐进**：由少到多、由稀到稠、由细到粗
2. **每次只加一种**：观察3-5天无过敏再添加新食物
3. **口味清淡**：1岁内不加盐、糖

**辅食引入顺序**：
1. **富铁泥糊状食物**（强化铁米粉）→ 肉泥、肝泥
2. 蔬菜泥、水果泥
3. 蛋黄
4. 鱼虾肉末

| 钙 | 600mg/d | 600mg/d |
| 铁 | 9mg/d | 9mg/d |
| 锌 | 4mg/d | 4.5mg/d |

### 三、膳食指南

3. ✅ 食物多样，少盐少糖
4. ✅ 鼓励参与食物制作
5. ✅ 定期监测体格指标

## 第七节 老年人营养

### 一、老年人生理变化 ⭐⭐⭐

| 系统 | 变化 |
|------|------|
| 消化系统 | 咀嚼力↓、胃酸↓、肠蠕动↓ |
| 代谢 | 基础代谢↓、合成代谢↓ |
| 感官 | 味觉、嗅觉减退 |
| 体成分 | 肌肉量↓、体水分↓、骨密度↓ |

### 二、营养需要 ⭐⭐⭐高频

| 营养素 | 推荐摄入 | 备注 |
|--------|----------|------|
| **能量** | ↓10%（约1800kcal） | 随年龄递减 |
| **蛋白质** | 1.0-1.2g/kg/d | 优质蛋白≥1/2，防肌肉衰减 |
| **钙** | **1000mg/d** | 骨质疏松预防 |
| **VD** | **15μg/d** | 促进钙吸收 |
| **铁** | 12mg/d | 吸收率↓，但需求不降 |
| **膳食纤维** | 25-30g/d | 预防便秘 |
| **水** | 1500-1700ml/d | 渴感减退 |

### 三、老年人膳食指南 ⭐⭐⭐

1. ✅ **少量多餐**：每天4-5餐
2. ✅ **细软食物**：切碎煮烂
3. ✅ **优质蛋白**：鱼、蛋、奶、豆
4. ✅ **预防贫血**：红肉、动物肝脏
5. ✅ **补钙+VD**：奶制品、户外活动
6. ✅ **低盐低脂**：<6g盐/d
7. ✅ **充足饮水**：主动饮水

### 四、老年慢性病营养 ⭐⭐⭐

#### 高血压
- 限盐<5g/d
- 增钾（蔬菜、水果）
- 减重

#### 糖尿病
- 碳水50-60%
- 低GI食物
- 定时定量

#### 骨质疏松
- 钙+VD
- 蛋白质适量
- 户外活动
