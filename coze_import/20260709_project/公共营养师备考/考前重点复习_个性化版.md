## 第一部分 ⚠️ 你的顽固错点TOP 20（考前必看）

> 以下按错误频次排序，错2次以上的点全部列入。

| # | 错点 | 正确答案 | 易混项 |
|---|------|----------|--------|
| 1 | 克山病/克汀病病因 | **克山病=硒，克汀病=碘**（碘呆硒心） | 容易反过来 |
| 2 | 癞皮病"3D" | **皮炎+腹泻+痴呆**（烟酸缺乏） | 牙龈出血≠3D，是VC缺乏 |

| 7 | EAR vs RNI应用 | **EAR评群体摄入不足率 / RNI评个体** | 容易搞反 |

| 9 | 蛋白质功能 | **构成组织+调节功能+供给能量** | 促进脂溶性维生素吸收=脂肪功能❌ |
| 10 | 蛋白质互补作用 | **种属越远效果越好** | 同种属❌ |
| 11 | 豆腐/豆浆/整粒消化率 | **豆腐 > 豆浆 > 整粒大豆** | 生物价最高=鸡蛋（不是豆腐） |

| 13 | GI影响因素 | **不受碳水绝对量影响**（绝对量影响GL） | 容易选"碳水含量" |
| 14 | 铬的功能 | **GTF组成 + 糖代谢 + 脂代谢** | 不参与甲状腺（那是碘） |
| 15 | 食物评价方法 | **INQ / PER / AAS**（RNI是标准❌ BMI是指标❌） | 容易多选 |
| 16 | 营养教育方法 | **讲座 + 讨论 + 案例 + 角色扮演** | 膳食称重法=调查方法❌ |
| 17 | 营养教育评价 | **知识 + 态度 + 行为** | 经济收入❌ |
| 18 | VK功能 | **参与凝血因子合成** | 经常选成其他维生素功能 |
| 19 | VB₆辅酶功能 | **转氨酶辅酶**（氨基酸代谢） | 容易选成脱氢酶 |

## 第二部分 🧬 氨基酸与蛋白质核心考点

### 一、必需氨基酸（8+1种）

| 类别 | 氨基酸 |
|------|--------|
| **成人8种** | 蛋氨酸、赖氨酸、缬氨酸、异亮氨酸、亮氨酸、苯丙氨酸、色氨酸、苏氨酸 |
| **婴幼儿+1种** | **组氨酸**（第9种） |
| **条件必需** | 半胱氨酸、酪氨酸（体内可由蛋氨酸/苯丙氨酸转化） |

> ⚠️ **精氨酸≠必需氨基酸**（是条件必需氨基酸，你多次错选）

### 二、蛋白质分类

| 类型 | 定义 | 代表食物 |
|------|------|----------|
| **完全蛋白** | 必需氨基酸种类齐全、比例适当 | 蛋、奶、鱼、肉、**大豆** |
| **半完全蛋白** | 含必需氨基酸但比例不适当 | 麦胶蛋白（小麦） |
| **不完全蛋白** | 缺少一种或多种必需氨基酸 | 玉米胶蛋白、动物结缔组织 |

> ⚠️ **猪肉不是"完全蛋白的典型代表"**（脂肪含量高）；大豆是植物中唯一完全蛋白

### 三、蛋白质营养价值评价（5个指标）

| 指标 | 英文缩写 | 含义 |
|------|----------|------|
| 消化率 | TD/NPD | 被消化吸收的比例 |
| 生物价 | BV | 被利用合成机体的比例（**鸡蛋最高**） |
| 功效比值 | PER | 体重增长÷蛋白摄入量 |
| 氨基酸评分 | AAS | 与参考蛋白比较（FAO/WHO方法） |
| 净利用率 | NPU | 消化率×生物价 |

### 四、限制氨基酸与互补作用

| 食物 | 第一限制氨基酸 |
|------|----------------|
| 谷类 | **赖氨酸** |
| 豆类 | **蛋氨酸** |

- **蛋白质互补**：多种食物混合食用，互补限制氨基酸 → 提高生物价
- **原则**：种属越远越好、搭配种类越多越好、同时食用效果最佳

### 五、蛋白质关键数字

| 项目 | 数值 |
|------|------|
| 能量系数 | **4 kcal/g** |
| 成人RNI | 男65g/d，女55g/d |
| 供能比 | 10-20% |
| 优质蛋白占比 | ≥30% |
| 热效应（TEF） | 30-40%（三大营养素中最高） |
| 含氮量换算 | 蛋白质 = 含氮量 × **6.25** |
| 老年人AMDR | **15%~20%E**（2023版） |

## 第三部分 💊 维生素核心考点

### 一、脂溶性维生素（ADEK）

| 维生素 | 功能关键词 | 缺乏症 | 食物来源 | ⚠️易混点 |
|--------|-----------|--------|----------|----------|
| **VA** | 视觉+上皮组织 | 夜盲症、干眼症 | 肝脏/蛋黄/深色菜 | 过量可致畸 |
| **VD** | **促钙吸收**+骨钙化 | 佝偻病/骨软化 | **晒太阳为主**+鱼肝油 | VA≠VD功能（你多次混淆） |
| **VE** | **抗氧化**+细胞膜 | 少见（早产儿溶血） | 植物油/坚果 | VE才有抗氧化，不是VA |
| **VK** | **凝血因子合成** | 凝血障碍/新生儿出血 | 绿叶菜/肠道菌合成 | 你反复错过 |

> ⚠️ **脂溶性维生素共同特点**：溶于脂肪✅ / 可在体内储存✅ / 过量可中毒✅ / 不是都有抗氧化功能❌（只有VE）

### 二、水溶性维生素

| 维生素 | 功能关键词 | 缺乏症 | 特殊点 | ⚠️易混点 |
|--------|-----------|--------|--------|----------|
| **VB₁** | **糖代谢**辅酶（TPP） | **脚气病** | 怕碱、精白加工损失 | VB₁=糖代谢，不是脂肪 |
| **VB₂** | 氧化还原辅酶（FAD/FMN） | **口-眼-阴囊-皮肤** | 肝肾奶蛋 | **≠牙龈出血**（那是VC） |
| **烟酸（B₃）** | NAD/NADP辅酶 | **癞皮病3D** | 色氨酸÷60=烟酸当量 | 3D=皮炎+腹泻+痴呆 |
| **VB₆** | **转氨酶辅酶** | 脂溢性皮炎 | 氨基酸代谢 | ≠脱氢酶辅酶 |
| **VB₁₂** | 红细胞+神经系统 | **巨幼贫+神经损害** | 唯一含金属元素钴 | 需内因子辅助吸收 |
| **叶酸** | DNA合成+红细胞 | **巨幼贫+神经管畸形** | 孕妇600μgDFE | 预防神经管畸形是叶酸❗ |
| **VC** | 抗氧化+胶原+促铁吸收 | **坏血病（牙龈出血）** | 极不稳定 | 代谢产物经尿液排出 |

### 三、维生素缺乏症速查（高频配对题）

| 缺乏症 | 对应维生素 |
|--------|-----------|
| 夜盲症 | **VA** |
| 脚气病 | **VB₁** |
| 口角炎/舌炎 | **VB₂** |
| 癞皮病3D | **烟酸** |
| 牙龈出血 | **VC**（不是VB₂❗） |
| 巨幼红细胞贫血 | **叶酸 + VB₁₂** |
| 佝偻病 | **VD** |
| 凝血障碍 | **VK** |
| 干眼症 | **VA** |

## 第四部分 🧪 矿物质易错点

### 一、碘 vs 硒（碘呆硒心）

| 元素 | 缺乏症 | RNI | 来源 |
|------|--------|-----|------|
| **碘** | **克汀病**（呆小症）+ 甲状腺肿 | 120μg/d（孕妇230μg/d） | 海带/紫菜/碘盐 |
| **硒** | **克山病**（心肌病） | 60μg/d | 海产品/动物内脏 |

> ⚠️ 这是你最顽固的错误，至少错了4次。记住：**碘=呆（克汀病），硒=山（克山病）**

### 二、钙吸收全解析

| 因素 | 促进✅ | 抑制❌ |
|------|--------|--------|
| VD | ✅ 最强促进因子 | - |
| 乳糖 | ✅ | - |
| 蛋白质 | ✅ 适量促进 | ❌ 过量不利 |
| 草酸 | - | ❌ 菠菜/苋菜含草酸 |
| 植酸 | - | ❌ 谷物外皮 |
| 膳食纤维 | - | ❌ 过量纤维不利 |
| 钙铁锌 | - | ❌ **竞争抑制**（同补相互干扰） |

### 三、铁吸收全解析

| 因素 | 促进✅ | 抑制❌ |
|------|--------|--------|
| VC | ✅ 最强促进因子 | - |
| 肉类因子 | ✅ | - |
| 有机酸/胃酸 | ✅ | - |
| 草酸 | - | ❌ |
| 植酸 | - | ❌ |
| 茶多酚 | - | ❌ |
| 过量钙/锌 | - | ❌ **竞争抑制** |

> ⚠️ **血红素铁**（动物血/肝/瘦肉）吸收率远高于**非血红素铁**（植物性）

### 四、铬

| 功能 | 内容 |
|------|------|
| GTF | 葡萄糖耐量因子组成成分 |
| 糖代谢 | ✅ |
| 脂代谢 | ✅ |
| 甲状腺 | ❌ 不参与（那是碘） |

## 第五部分 📐 必背公式与计算

### 一、能量与供能比

| 公式 | 说明 |
|------|------|
| 蛋白质能量 = g × **4** kcal | 碳水同 |
| 脂肪能量 = g × **9** kcal | |
| 供能比 = 该营养素能量 ÷ 总能量 × 100% | |
| 含氮量 → 蛋白质 = 含氮量 × **6.25** | |

### 二、营养标签计算

| 公式 | 说明 |
|------|------|
| NRV% = 含量 ÷ NRV × 100% | 钙NRV=800mg |
| INQ = 营养素密度 ÷ 能量密度 | >1为营养价值高 |
| GL = GI × 碳水含量(g) ÷ 100 | 血糖生成负荷 |

### 三、体格测量

| 公式/指标 | 内容 |
|-----------|------|
| BMI | 体重(kg) ÷ 身高(m)² |
| 中国标准 | <18.5低/18.5-23.9正常/≥24超重/≥28肥胖 |
| 腰围 | 男≥85cm / 女≥80cm（中心性肥胖） |
| 可食部 | 食物重量 × 可食部百分比 |
| 上臂肌围 | 上臂围 - 3.14 × 皮脂厚度(mm) |

## 第七部分 🔬 DRIs应用（必考）

| 指标 | 用途 | 易错点 |
|------|------|--------|
| **EAR** | 评估**群体**摄入不足发生率 | ≠评估个体 |
| **RNI** | 评估**个体**摄入是否满足 | EAR的2个SD |
| **AI** | 当RNI不确定时用作参考 | ≠RNI精确替代 |
| **UL** | 评估个体**过量风险** | 不是推荐量 |

## 🏀 最后叮嘱

1. **单选先做确定的，不确定的先跳过**
2. **多选题"差一个"全丢分** — 宁可少选不要多选（除非规则是多选少选都扣分）
3. **计算题先写公式再代入**
4. **看到"碘/硒"就想"碘呆硒心"**
5. **看到"牙龈出血"就选VC，看到"口角炎"就选VB₂**
6. **看到"晒太阳"就选VD**
