## 三、六大核心知识框架速览

### 1️⃣ 蛋白质（必考）
```
氨基酸：9种必需（成人8种+婴幼儿多组氨酸）
评价四指标：BV(利用)、PER(增重)、AAS(氨基酸)、NPU(净利用)
互补三原则：种属远、种类多、时间近
完全蛋白：鸡蛋(BV94)、大豆、牛奶
优质蛋白≥总蛋白50%
```

### 2️⃣ 维生素（必考）
```
脂溶性(ADEK)：可储存，过量中毒
  A=夜盲+上皮+视觉  D=钙磷吸收+骨  E=抗氧化  K=凝血
水溶性(B族+C)：不储存，需每日补充
  B1=脚气病  B2=口角炎/舌炎  B3(PP)=癞皮病(3D)
  B6=神经系统  B12+叶酸=巨幼红细胞贫血  C=坏血病+促铁吸收
VA当量：1μgRE = 12μgβ-胡萝卜素（⚠️12不是6！）
```

### 3️⃣ 矿物质（高频）
```
口诀：钙骨铁贫血锌不长 碘呆硒心
钙：奶100mg/100ml最佳；VD促吸收；草酸植酸抑吸收
铁：VC+肉类因子促吸收；草酸植酸抑吸收
锌：食欲减退/异食癖/生长迟缓
硒：克山病(心肌病)；抗氧化
碘：甲状腺肿/呆小症；孕妇RNI=230μg/d
```

### 4️⃣ 膳食纤维
```
可溶性：果胶、树胶、β-葡聚糖 → 降血糖降血脂
不溶性：纤维素、半纤维素、木质素 → 促肠道蠕动
"木头硬=不溶；果冻软=可溶"
```

### 5️⃣ 膳食调查方法
```
24h回顾法：个体+群体，3天含休息日，15-40min
记账法：集体/长期，不能分析个体
称重记账法：比记账精准，适合全年
称重法：最精准，负担重
FFQ：饮食习惯/长期摄入模式
```

### 6️⃣ 膳食指南2022
```
食物多样≥12种/天；每周≥25种
烹调油25-30g；盐≤5g
大豆坚果25-35g；薯类50-100g
奶300-500g；畜禽肉40-75g；水产品40-75g
三餐比：30-40-30
```
