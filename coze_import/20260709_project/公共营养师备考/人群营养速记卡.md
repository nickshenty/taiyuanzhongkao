## 一、孕妇营养 ⭐⭐⭐

### 能量与体重
| 孕期 | 能量增加 |
|------|----------|
| 孕早期（1-12周）| 不增加 |
| 孕中期（13-27周）| **+250kcal/d** |
| 孕晚期（28周-分娩）| **+400kcal/d** |

- 孕前BMI正常者孕期总增重：**11.5-16kg**
- 孕前BMI<18.5增重：**12.5-18kg**
- 孕前BMI≥25增重：**7-11.5kg**

### 关键营养素
| 营养素 | RNI | 要点 |
|--------|-----|------|
| **叶酸** | **600μgDFE/d** | 孕前3个月开始，补到孕3月，防神经管畸形 |
| **铁** | **19mg/d**（孕中晚期）| 孕早期16mg/d，增加7mg |
| **钙** | **1000mg/d** | 孕早中晚不变 |
| **碘** | **230μg/d** | 整个孕期 |
| **VA** | **770μgRAE/d** | 过量致畸 |

### 易错点
- ❌ 钙孕期需要量不增加（还是1000mg/d）
- ✅ 铁需要量孕中期才增加
- ✅ 叶酸需从孕前3个月开始补

## 二、乳母营养 ⭐⭐⭐

| 营养素 | 增加量 |
|--------|--------|
| **能量** | **+500kcal/d** |
| **蛋白质** | **+25g/d** |
| **钙** | **1200mg/d** |
| **VA** | **1300μgRAE/d** |
| **碘** | **120μg/d** |
| **锌** | **+4mg/d** |

### 泌乳生理
- 初乳：产后7天内
- 过渡乳：7-14天
- 成熟乳：14天以后
- **泌乳量约750-850ml/d**

### 易错点
- ❌ 乳母钙需要量是1200mg/d，不是1000mg/d
- ✅ 能量+500，蛋白质+25g

## 三、婴儿营养 ⭐⭐⭐

### 喂养原则
- **0-6月龄：纯母乳喂养**
- 母乳是婴儿最佳食物
- 特殊情况可用配方奶

### 母乳保存 ⭐
| 保存条件 | 时间 |
|----------|------|
| 室温（25-37℃）| **4小时** |
| 冷藏（4℃）| **24小时** |
| 冷冻（-18℃）| **3-6个月** |

### 辅食添加
- **时间：6个月**
- **首选：富铁泥糊状食物**（高铁米粉、瘦肉泥）
- 辅食添加原则：由少到多、由细到粗、由一种到多种

### 婴儿营养素需要
| 营养素 | 0-6月龄 | 7-12月龄 |
|--------|---------|----------|
| 能量 | 90kcal/kg/d | 80kcal/kg/d |
| 蛋白质 | 9g/d | 20g/d |
| **铁** | 0.3mg/d | **10mg/d** |
| VD | 10μg/d | 10μg/d |

### 易错点
- ❌ 铁在7-12月突然增加到10mg/d（孕期储备耗尽）
- ✅ 6个月后必须添加辅食，首选富铁食物

## 四、幼儿营养（1-3岁）⭐⭐

### 生理特点
- 生长速度减慢
- 咀嚼消化能力增强
- 断奶过渡期

### 营养素需要
| 营养素 | RNI |
|--------|-----|
| 能量 | 1100-1200kcal/d |
| 蛋白质 | 25-30g/d |
| 钙 | 600mg/d |
| 铁 | 9mg/d（男）/10mg/d（女）|

### 合理膳食原则
- 三餐两点制
- 单独制作
- 避免刺激性食物

---

## 五、学龄前儿童（3-6岁）⭐⭐

### 营养素需要
| 营养素 | 3-4岁 | 4-6岁 |
|--------|-------|-------|
| 能量 | 1200-1250kcal | 1300-1400kcal |
| 蛋白质 | 30-35g/d | 30-40g/d |
| 钙 | 600mg/d | 800mg/d |

### 骨骼发育
- **钙需要量增加**
- 钙磷比：1.5:1

## 六、学龄儿童及青少年（6-18岁）⭐⭐

### 青春期特点
- 第二个生长高峰
- 性器官发育
- 营养需求剧增

### 关键营养素
| 营养素 | 需要特点 |
|--------|----------|
| **钙** | 峰值骨量形成期，需1200mg/d |
| **铁** | 女童月经后需18mg/d |
| **锌** | 青春期需要增加 |

## 七、老年人营养 ⭐⭐⭐

### 生理变化
- 基础代谢率↓（60岁后↓10-15%）
- 消化吸收功能↓（胃酸↓、酶活性↓）
- 体成分变化（肌肉↓、脂肪↑）
- 免疫功能↓

### 营养需求调整
| 项目 | 调整 |
|------|------|
| **能量** | **↓10-20%** |
| **蛋白质** | **1.0-1.2g/kg/d**（高质蛋白≥1/3）|
| **钙** | **1000mg/d** |
| **VD** | **15μg/d** |
| **铁** | 12mg/d（与成人相同）|

### 膳食原则
- 食物细软易消化
- **少食多餐**
- 主动足量饮水
- 适度户外活动

### 易错点
- ✅ 老年人能量↓，但蛋白质要保证（防肌少症）
- ✅ 钙和VD同时补充，促进吸收
