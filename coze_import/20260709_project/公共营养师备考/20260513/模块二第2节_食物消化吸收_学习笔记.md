## 一、消化系统组成【需记忆】

### 1.1 消化管（7个部位）
> 口腔 → 咽 → 食管 → 胃 → 小肠 → 大肠 → 肛门

| 部位 | 关键特点 |
|------|----------|
| 口腔 | 咀嚼、唾液淀粉酶（消化碳水起点） |
| 咽 | 食物通道 |
| 食管 | 蠕动推送食物 |
| 胃 | 蛋白质主要消化场所 |
| 小肠 | **最主要吸收场所**（表面积200m²） |
| 大肠 | 主要吸收水分 |

### 1.2 消化腺
- **肝** → 分泌胆汁
- **胰** → 分泌胰液
- **唾液腺** → 分泌唾液

---

## 二、营养过程【理解记忆】

```
摄入 → 消化 → 吸收 → 利用
```

| 环节 | 具体过程 |
|------|----------|
| **摄入** | 食物由体外进入胃肠 |
| **消化** | 食物破碎、混合，大分子→小分子 |
| **吸收** | 小分子穿透肠壁，进入血液/淋巴 |
| **利用** | 运输到需要部位，代谢更新 |

### 消化方式对比【重要】
| 类型 | 方式 | 具体表现 |
|------|------|----------|
| **机械消化** | 物理作用 | 咀嚼、胃肠蠕动、磨碎、搅拌 |
| **化学消化** | 化学分解 | 消化液+消化酶分解食物 |

## 三、三大产能营养素消化【高频考点】

### 3.1 蛋白质消化
- **消化场所**：**主要在胃内**
- **消化过程**：
  ```
  蛋白质 → 多肽 → 寡肽 → 氨基酸
  ```
- **关键酶**：胃蛋白酶、胰蛋白酶、糜蛋白酶

### 3.2 脂肪消化
- **消化场所**：**主要在小肠内**
- **消化过程**：
  ```
  甘油三酯 → 短链脂肪酸 + 游离脂肪酸
  ```
- **关键酶**：胰脂肪酶
- **辅助因素**：胆汁乳化

### 3.3 碳水化合物消化
- **消化起点**：**自口腔开始**（唾液淀粉酶）
- **主要场所**：**小肠**
- **消化过程**：
  ```
  淀粉 → 多糖 → 寡糖 → 单糖（葡萄糖）
  ```
- **关键酶**：唾液淀粉酶、胰淀粉酶

### 📊 三大营养素消化场所汇总
| 营养素 | 主要消化场所 | 关键消化酶 |
|--------|--------------|------------|
| 蛋白质 | **胃** | 胃蛋白酶、胰蛋白酶 |
| 脂肪 | **小肠** | 胰脂肪酶+胆汁 |
| 碳水 | **小肠**（口腔开始） | 唾液淀粉酶、胰淀粉酶 |

## 四、各部位消化吸收特点【重要】

### 4.1 口腔
- **吸收功能**：基本无吸收功能 ❌
- **消化功能**：唾液淀粉酶开始分解碳水

### 4.2 胃
- **吸收功能**：吸收少量水、乙醇
- **消化功能**：
  - 胃壁蠕动研磨
  - 胃蛋白酶消化蛋白质
  - 形成食糜

### 4.3 胃酸的作用【需牢记】
1. ✅ 激活胃蛋白酶，提供酸性环境
2. ✅ 抑制和杀死随食物进入胃的细菌
3. ✅ 促进胰液、胆汁、肠液分泌
4. ✅ 有助于**小肠对铁和钙的吸收**

### 4.4 小肠【最关键】
- **吸收功能**：最主要吸收场所
- **粘膜表面积**：约 **200m²**
- **小肠液作用**：
  - 消化食物
  - 保护肠粘膜免受胃酸侵蚀

#### 胰液特点
| 项目 | 内容 |
|------|------|
| **pH值** | 7.8 ~ 8.4（弱碱性） |
| **作用** | 中和进入小肠的胃酸 |
| **消化酶** | 胰淀粉酶、胰脂肪酶、胰蛋白酶原、糜蛋白酶原 |

#### 胆汁特点
| 项目 | 内容 |
|------|------|
| **每日分泌量** | 800~1000mL |
| **颜色** | 金黄色/橘棕色（肝胆汁）→ 深棕色（胆囊胆汁） |
| **味道** | 苦味 |
| **主要成分** | 胆色素、胆盐 |
| **作用** | 乳化脂肪，促进脂肪消化 |

### 4.5 大肠
- **吸收功能**：主要吸收**水分和盐类**
- **分泌功能**：分泌黏液（保护肠粘膜、润滑粪便）
- **细菌作用**：含有分解食物残渣的酶
- **细菌分解产物**：单糖、乙酸、乳酸、CO₂、沼气、氢气

## 五、吸收形式对比【重要】

### 被动转运 vs 主动转运
| 类型 | 是否耗能 | 具体方式 |
|------|----------|----------|
| **被动转运** | ❌ 不耗能 | 被动扩散、易化作用、滤过、渗透 |
| **主动转运** | ✅ 耗能 | 逆浓度梯度，需要载体 |

## 六、易混淆知识点对比【强化记忆】

### 对比1：三大营养素消化场所
| 营养素 | 主要消化场所 |
|--------|--------------|
| 蛋白质 | **胃**（起始） |
| 脂肪 | **小肠**（起始） |
| 碳水化合物 | **小肠**（主要），口腔（起点） |

### 对比2：各部位吸收功能
| 部位 | 主要吸收什么 |
|------|--------------|
| 口腔 | 基本无吸收 ❌ |
| 胃 | 少量水、乙醇 |
| **小肠** | **最主要吸收场所**（200m²） |
| 大肠 | 水分 |

### 对比3：消化液特点
| 消化液 | pH | 主要成分/作用 |
|--------|-----|---------------|
| 胃液 | 强酸（1-2） | 胃蛋白酶 |
| 胰液 | **弱碱（7.8-8.4）** | 多种消化酶 |
| 胆汁 | — | 胆盐（乳化脂肪） |
| 小肠液 | — | 消化+保护粘膜 |

### 对比4：胆汁vs胆囊胆汁
| 类型 | 颜色 | 特点 |
|------|------|------|
| 肝胆汁 | 金黄色/橘棕色 | 肝脏直接分泌 |
| 胆囊胆汁 | 深棕色 | 经胆囊储存浓缩 |
