# MacBook Air M5 AI应用学习课程规划

> 创建时间：2026-06-30
> 设备：MacBook Air M5（16GB统一内存 / 512GB SSD）
> 目标：掌握本地AI模型部署，将AI融入银行业务管理与研究写作

---

## 第一阶段：工具熟悉（7月1日-7日）

### Day 1（7/1 周三）—— 环境搭建

**目标**：完成本地AI运行的基础环境配置

**学习内容**：
1. **安装 Homebrew**（Mac包管理器）
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. **安装 Ollama**（本地大模型运行框架）
   ```bash
   brew install ollama
   ollama --version  # 验证安装
   ```

3. **下载第一个模型：Qwen2.5 7B**（通义千问，中文能力最强）
   ```bash
   ollama pull qwen2.5:7b
   ollama run qwen2.5:7b  # 启动对话
   ```

4. **基础体验**：跟模型对话，感受响应速度和本地运行特点

**预期产出**：能在终端与本地AI流畅对话

---

### Day 2（7/2 周四）—— 模型选型与对比

**目标**：了解不同模型的能力差异，建立"什么场景用什么模型"的认知

**学习内容**：
1. **下载2-3个模型做对比**
   ```bash
   ollama pull deepseek-r1:7b      # 推理能力强，适合分析
   ollama pull gemma4:12b           # Google最新，综合能力
   ```

2. **场景测试**：用同一组问题测试不同模型
   - 公文润色："帮我润色这段会议纪要…"
   - 数据分析："从这组数据中找出趋势…"
   - 政策解读："用通俗语言解释这个监管文件…"
   - 写作辅助："帮我写一份普惠金融业务通报的框架…"

3. **了解量化概念**：Q4_K_M vs Q5_K_M vs Q8_0
   - 7B模型Q4约4.7GB，16GB内存绰绰有余
   - 12B模型Q4约7.9GB，M5 Air也能跑

**预期产出**：形成个人"模型-场景"对照表

---

### Day 3（7/3 周五）—— Web界面部署

**目标**：搭建类ChatGPT的本地交互界面，告别命令行

**学习内容**：
1. **安装 Open WebUI**（图形化对话界面）
   ```bash
   # 方法一：Docker方式（推荐）
   docker run -d -p 3000:8080 -v open-webui:/app/backend/data --restart always ghcr.io/open-webui/open-webui:main
   
   # 方法二：如果不想装Docker，可用LM Studio替代（纯图形界面，更简单）
   ```

2. **LM Studio**（零命令行替代方案）
   - 下载：https://lmstudio.ai
   - 一键安装，图形界面选模型、对话、管理
   - 适合不想碰命令行的场景

3. **配置优化**：
   - 创建 `~/.ollama/config.json` 优化M5性能
   ```json
   {
     "num_ctx": 8192,
     "num_thread": 8,
     "num_gpu": 8
   }
   ```

**预期产出**：在浏览器 `http://localhost:3000` 拥有自己的AI对话界面

---

### Day 4（7/4 周六）—— AI写作实战

**目标**：用AI辅助完成一篇真实工作文档

**学习内容**：
1. **Apple Intelligence 开启与使用**
   - 选中文字 → 右键 → 写作工具（润色/改写/摘要/翻译）
   - 快捷键：`Control+Command+空格`
   - 适用场景：邮件润色、会议纪要精简

2. **本地模型写公文**
   - 实战：让Qwen帮你写一份"普惠金融上半年业务通报"
   - 学习Prompt技巧：角色设定 + 背景信息 + 具体要求
   ```
   你是建设银行朔州分行普惠金融部的公文写作专家。
   背景：2026年上半年普惠金融贷款余额增长12%，新拓展小微企业客户85户...
   要求：写一份业务通报，1500字，包含成绩、问题、下步计划...
   ```

3. **对比不同工具的写作质量**
   - Apple Intelligence vs Qwen vs DeepSeek-R1
   - 体会各自强项：润色/创造/逻辑推理

**预期产出**：一篇AI辅助完成的工作文档初稿

---

### Day 5（7/5 周日）—— 数据分析入门

**目标**：学会用AI处理银行业务数据

**学习内容**：
1. **Python + AI 基础**
   ```bash
   brew install python3
   pip3 install pandas openai
   ```

2. **用本地模型分析Excel数据**
   - 将普惠金融/个人信贷业务数据导出为CSV
   - 写简单Python脚本调用本地模型API
   ```python
   import ollama
   response = ollama.chat(model='qwen2.5:7b', messages=[
       {'role': 'user', 'content': '分析这组贷款数据的增长趋势...'}
   ])
   ```

3. **实用场景**：
   - 客户画像分析
   - 业务指标异常检测
   - 自动生成数据分析报告

**预期产出**：一个能分析业务数据的Python脚本原型

**目标**：建立AI驱动的个人知识管理系统

**学习内容**：

3. **会议纪要自动化**

**预期产出**：一套可复用的文档处理流程

### Day 7（7/7 周二）—— 工作流整合

**目标**：把前6天学的工具串联成日常工作流

## M5 Air 16GB 能跑什么模型

| 模型 | 大小(Q4) | 运行流畅度 | 推荐用途 |
|------|---------|-----------|---------|
| Qwen2.5 7B | 4.7GB | ★★★★★ | 中文写作、公文、分析 |
| DeepSeek-R1 7B | 4.7GB | ★★★★★ | 逻辑推理、数据分析 |
| Gemma 4 12B | 7.9GB | ★★★★☆ | 综合能力、英文任务 |
| Qwen2.5 14B | 9.0GB | ★★★☆☆ | 更高质量但稍慢 |
| Llama 3.3 70B(Q3) | ~25GB | ★☆☆☆☆ | 不推荐，内存不足 |

**建议**：日常用7B模型（流畅），重要任务切14B（质量更高但慢一些）
