## 一、Apple Intelligence 写作工具体验（约20分钟）

### 1.1 开启方式
- 任意App中选中文本 → 右键 → 「写作工具」（Writing Tools）
- 或快捷键：`Control + Command + 空格`
- macOS Sequoia 15.1+ 内置，无需安装

### 1.2 测试清单
找一段自己的工作文字（会议纪要/邮件/报告片段都行），依次测试：

| 功能 | 操作 | 测试用文字建议 |
|------|------|---------------|
| 润色 | 选中文本 → 写作工具 → Proofread | 一段口语化的工作记录 |
| 改写 | 选中文本 → 写作工具 → Rewrite | 一段需要调整语气的邮件 |
| 摘要 | 选中文本 → 写作工具 → Summarize | 一段较长的会议纪要 |
| 翻译 | 选中文本 → 写作工具 → Translate | 一段需要翻译成英文的中文段落 |

### 1.3 体会要点
- 润色：改了什么？语气/用词/结构？
- 改写：是否保持了原意？风格变化大吗？
- 摘要：关键信息有没有遗漏？
- 翻译：专业术语处理如何？

## 二、本地模型写公文实战（约60分钟）

### 2.1 实战任务
用 **Qwen2.5 7B** 写一份：
**《建设银行朔州分行2026年上半年普惠金融业务通报》**

### 2.2 Prompt 设计（核心学习点）

好的Prompt = 角色设定 + 背景信息 + 具体要求 + 格式约束

**示范Prompt：**

```
你是建设银行朔州分行普惠金融部的公文写作专家，具有20年银行公文写作经验。

【背景信息】
2026年上半年，朔州分行普惠金融业务主要数据：
- 普惠型小微企业贷款余额较年初增长12%，新增85户小微企业客户
- 涉农贷款余额增长8%，服务覆盖朔州6个县区
- 互联网普惠贷款投放额同比增长15%
- 不良率控制在1.2%以内
- 完成2场银企对接会，对接企业120余家
- 上线"普惠金融数字化风控平台"

【存在问题】
- 部分县区投放不均衡，山阴县、右玉县进度滞后
- 信用贷款占比偏低，仍以抵押担保为主
- 数字化获客能力不足

【下步计划】
- 加大薄弱县域投放力度
- 推广"小微快贷"等信用类产品
- 深化数字化营销，提升线上获客占比

【要求】
1. 按照银行内部通报格式撰写
2. 包含：一、总体情况；二、主要工作及成效；三、存在问题；四、下步工作计划
3. 语言风格：正式、简洁、数据说话
4. 字数：1500字左右
```

### 2.3 执行方式
我已准备好自动化脚本，会用3个模型（Qwen、GLM4、DeepSeek-R1）分别写同一份公文，输出对比报告。
