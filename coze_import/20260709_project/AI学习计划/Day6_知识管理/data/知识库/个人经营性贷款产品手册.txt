个人经营性贷款产品手册

一、个人经营性贷款概述

个人经营性贷款是指银行向从事合法生产经营的个体工商户、小微企业主发放的，用于生产经营周转、购置或更新经营设备、支付租赁经营场所租金等用途的贷款。

二、主要产品

1. 小微快贷
- 适用对象：个体工商户、小微企业主
- 贷款额度：最高300万元
- 贷款期限：最长1年（可循环使用）
- 担保方式：信用
- 利率：年化4.35%起
- 特点：全流程线上办理，最快当天放款
- 准入条件：经营满1年，信用记录良好，近6个月月均流水不低于5万元

2. 云税贷
- 适用对象：纳税信用A、B、M级的个体工商户和小微企业主
- 贷款额度：最高500万元（A级最高500万，B级最高300万，M级最高100万）
- 贷款期限：最长1年（可循环使用）
- 担保方式：信用
- 利率：年化4.15%起
- 特点：基于纳税数据自动授信，线上申请
- 准入条件：纳税满2年，近2年无纳税违章记录

3. 抵押经营贷
- 适用对象：个体工商户、小微企业主
- 贷款额度：最高1000万元
- 贷款期限：最长5年
- 担保方式：房产抵押
- 利率：年化3.95%起
- 特点：额度高、期限长，适合有固定资产的客户
- 准入条件：经营满2年，抵押房产位于本地

4. 农贷通
- 适用对象：从事农业生产经营的农户、家庭农场主
- 贷款额度：最高100万元
- 贷款期限：最长3年
- 担保方式：信用或保证
- 利率：年化4.25%起
- 特点：降低准入门槛，适合传统农业经营户
- 准入条件：从事农业生产经营满1年

三、申请材料

1. 借款人身份证、户口本
2. 营业执照（如有）
3. 近12个月银行流水
4. 经营场所证明
5. 纳税证明（云税贷需提供）
6. 抵押物权属证明（抵押经营贷需提供）

四、办理流程

1. 客户申请：线上（手机银行/微信银行）或线下（网点）提交申请
2. 资料审核：银行审核客户资质和经营情况
3. 授信审批：系统自动审批或人工审批
4. 合同签订：线上签约或线下签约
5. 贷款发放：放款至借款人指定账户

五、还款方式

1. 按月付息到期还本：每月支付利息，到期一次性还本
2. 等额本息：每月等额偿还本息
3. 等额本金：每月偿还固定本金加剩余本金利息
4. 随借随还：按日计息，随时还款
