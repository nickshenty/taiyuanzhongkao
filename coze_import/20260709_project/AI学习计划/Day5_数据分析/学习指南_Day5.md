### 核心知识点：pandas + AI 协作模式

```
┌─────────┐     ┌──────────┐     ┌─────────┐
│ pandas  │ ──→ │ 数据摘要  │ ──→ │ AI模型   │ ──→ 分析报告
│ (算数)  │     │ (统计结果)│     │ (解读)   │
└─────────┘     └──────────┘     └─────────┘
```

**关键原则**：不要把原始数据丢给AI，而是先用pandas统计好，把**统计摘要**喂给AI。

```python
# ❌ 错误做法：把80行原始数据丢给AI
prompt = f"分析这些数据: {df.to_string()}"

# ✅ 正确做法：pandas先统计，AI后解读
summary = f"平均金额{df['金额'].mean()}万元, 逾期率{...}"
prompt = f"你是银行分析师，请解读: {summary}"
```

## ⚠️ 第三部分：业务指标异常检测（20分钟）

### 运行脚本

```bash
python3 03_业务指标异常检测.py
```

### 你会看到什么

四个维度的异常检测：

**检测1：利率异常**（均值±2倍标准差法）
- 偏离正常范围的利率可能意味着定价问题

**检测2：金额异常**（IQR四分位法）
- 超出正常范围的贷款金额需要关注

**检测3：担保方式与逾期关联**
- 哪种担保方式的逾期率异常偏高

**检测4：行业集中度**
- 单一行业贷款占比过高 = 集中度风险

最后AI会综合解读所有异常，给出优先级排序和风控建议。

### 核心知识点：两种异常检测方法

```python
# 方法1：标准差法（适合正态分布数据）
mean = df["利率"].mean()
std = df["利率"].std()
anomaly = df[(df["利率"] > mean + 2*std) | (df["利率"] < mean - 2*std)]

# 方法2：IQR四分位法（更稳健，不受极端值影响）
Q1 = df["金额"].quantile(0.25)
Q3 = df["金额"].quantile(0.75)
IQR = Q3 - Q1
anomaly = df[df["金额"] > Q3 + 1.5 * IQR]
```
