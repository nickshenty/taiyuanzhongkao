## 方式一：一键自动测试（推荐，最省事）

打开终端，粘贴这段命令：

```bash
# 1. 先下载两个新模型
ollama pull deepseek-r1:7b
ollama pull gemma4:12b

# 2. 确认三个模型都在
ollama list

# 3. 逐个测试（每个模型逐个粘贴下面的问题）
```

然后对每个模型执行 `ollama run <模型名>`，依次粘贴4个测试问题。

## 方式二：手动逐个测试（更直观）

### 第一步：下载模型（约15-30分钟）
```bash
# 下载 DeepSeek-R1（推理型）
ollama pull deepseek-r1:7b

# 下载 Gemma4（综合型）
ollama pull gemma4:12b
```

> ⚠️ 如果 gemma4:12b 找不到，试试 `ollama pull gemma3:12b`（版本可能更新到3了）

### 第二步：确认三个模型都OK
```bash
ollama list
```
应该看到：
- qwen2.5:7b
- deepseek-r1:7b
- gemma4:12b（或gemma3:12b）

### 第三步：逐个测试

对每个模型执行以下操作：

```bash
# 启动模型
ollama run qwen2.5:7b
# （粘贴下面的测试问题，等回复完成，记录表现）
# 输入 /bye 退出

ollama run deepseek-r1:7b
# （同样粘贴4个问题）
# 输入 /bye 退出

ollama run gemma4:12b
# （同样粘贴4个问题）
# 输入 /bye 退出
```

### 测试问题（4组，每个模型都要测）

**测试1 - 公文润色：**
```
请帮我润色以下会议纪要：
"今天开了个会，讨论了上半年普惠金融业务的情况。大家觉得现在贷款增长还行，但是风险管控要加把劲。下一步要把小微信贷的流程再优化一下，争取效率更高。还有就是乡村振兴方面的工作要抓紧，上级行催的紧。"
```

**测试2 - 数据分析：**
```
以下是某支行2026年上半年普惠金融贷款数据：
1月新增320万，2月新增280万，3月新增410万，4月新增350万，5月新增520万，6月新增480万。
请分析这组数据的增长趋势，找出规律，并给出下半年的业务建议。
```

**测试3 - 政策解读：**
```
请用通俗易懂的语言解释以下监管要求的核心要点，以及对银行基层行的影响：
"商业银行应当建立健全小微企业授信尽职免责制度，明确尽职认定标准和免责条件，对小微企业授信业务相关人员在职权范围内，按照规定勤勉尽职履行职责的，应当免除相关责任。"
```

**测试4 - 写作辅助：**
```
请帮我拟一份普惠金融业务通报的框架大纲，要求：
- 时间范围：2026年上半年
- 背景：贷款余额增长12%，新拓展小微企业客户85户，不良率控制在0.8%
- 需要包含：成绩总结、存在问题、下半年工作计划
- 风格：正式、简洁、有数据支撑
```

## 学习要点

### 量化概念（了解即可）
- **Q4_K_M**（4-bit）：日常首选，速度快、质量够用
- **Q5_K_M**（5-bit）：质量略高，稍慢
- **Q8_0**（8-bit）：接近原精度，M5 Air跑7B无压力
- 12B模型Q4约7.9GB，16GB内存完全OK

### 观察重点
测试时注意感受：
1. **响应速度**：首字等多久？生成速度如何？
2. **中文能力**：有没有翻译腔？用词是否符合公文习惯？
3. **推理深度**：数据分析是否准确？建议是否靠谱？
4. **格式规范**：公文格式是否标准？框架是否完整？
