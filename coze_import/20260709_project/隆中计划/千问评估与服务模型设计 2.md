# 千问高考志愿AI服务评估 & 我们的服务模型设计

## 一、千问高考志愿Agent深度评估

### 1.1 产品概况
- **上线时间**：2026年6月10日
- **定位**：国内首个全周期高考志愿填报Agent
- **合作方**：新华社、半月谈（官方背书）
- **用户规模**：1400万+用户，800万+份免费报告
- **商业模式**：完全免费（阿里战略性投入）

### 1.2 核心能力矩阵

| 功能模块 | 具体能力 | 技术实现 |
|---------|---------|---------|
| **志愿日历** | 根据省份/选科/估分生成专属时间线，主动推送政策、提醒关键节点 | 规则引擎 + 动态规划 |
| **志愿报告** | 15-40页PDF，冲稳保梯度方案，支持多轮对话动态调整 | 大模型生成 + 实时反馈 |
| **志愿问答** | 7×24在线，引用权威来源，具备记忆能力 | RAG + 记忆引擎 |
| **性格测评** | 内置MBTI测试，匹配性格适配专业 | 心理测评模型 |
| **职业风险** | AI时代专业替代风险分析 | 产业趋势数据 |

### 1.3 技术架构亮点

1. **专门训练的高考垂类大模型**
   - 非通用模型直接套用
   - 300+资深志愿规划师参与训练
   - 提取专家思考链路，转化为推理链训练数据
   - 强化学习建模 + 监督微调

2. **数据底座**
   - 夸克8年高考服务数据（22亿条）
   - 覆盖3000所高校、2000+专业
   - 历年投档线、位次、招生计划、就业去向
   - 转专业政策、在校生评价、食堂质量等非结构化信息

3. **Agent调度体系**
   - 记忆引擎：精准沉淀考生档案
   - 39个Skills与专业工具（搜索引擎、就业信息、志愿匹配等）
   - 反思核验机制：工具返回结果后自我检查

4. **压测体系**
   - 40万种组合空间的"AI考生"体系
   - 反复压测确保各种情况都能应对

### 1.4 竞争优势

| 维度 | 优势 |
|-----|------|
| **权威性** | 新华社、半月谈战略合作 |
| **数据量** | 8年积累，22亿条数据 |
| **免费策略** | 完全免费，无付费门槛 |
| **全周期** | 从估分到录取跟进，7环节覆盖 |
| **个性化** | MBTI + 多轮对话，因人而异 |
| **普惠性** | 老旧机型、弱网环境优化 |

### 1.5 局限性与不足

1. **无法深度个性化**
   - 无法理解家庭经济状况、人脉资源
   - 无法考虑考生特殊理想、单科短板
   - 无法评估"家庭期望 vs 个人兴趣"的深层冲突

2. **数据滞后风险**
   - 每年新增专业、院校更名、招生计划变动可能更新不及时
   - 无法预判当年报考热度、"扎堆效应"

3. **缺乏行业洞察**
   - 就业数据偏统计层面，缺乏真实行业内部视角
   - 无法提供"这个专业毕业后实际做什么"的一手信息

4. **同质化严重**
   - 与百度、腾讯的产品逻辑高度相似
   - 差异化不足，用户黏性有限

## 二、市场格局与机会分析

### 2.1 三强对比

| 平台 | 核心优势 | 梯度风格 | 流量入口 |
|-----|---------|---------|---------|
| **阿里千问** | 全周期陪伴、MBTI、AI职业替代分析 | 中性均衡 | 夸克APP |
| **腾讯元宝** | 微信生态、双方案对比、极简对话 | 冲档多、激进 | 微信小程序 |
| **百度文心** | 就业数据最全、真人专家审核 | 保守稳妥 | 百度APP |

### 2.2 市场痛点（我们的机会）

1. **信息差已缩小，但认知差仍在**
   - AI工具解决了"查数据"问题
   - 但家长仍不知道"怎么判断"、"怎么选"
   - **机会**：提供决策框架，而非只是数据

2. **缺乏"过来人"视角**
   - AI能分析数据，但无法提供真实行业经验
   - 家长需要"这个专业毕业后实际做什么、赚多少钱"的一手信息
   - **机会**：金融高管视角，真实行业洞察

3. **缺乏情感支持与信任建立**
   - AI是冰冷的工具，无法建立情感连接
   - 家长在焦虑时需要"有人懂我"的感觉
   - **机会**：个人IP + 真人出镜，建立信任

4. **缺乏深度定制服务**
   - 免费工具只能做标准化推荐
   - 特殊家庭情况（经济困难、单亲、残疾等）需要深度定制
   - **机会**：付费深度咨询，高客单价

## 三、我们的服务模型设计

### 3.1 定位与差异化

```
千问/百度/腾讯 = 数据工具（查数据、出方案）
我们的服务 = 决策顾问（帮家长想清楚、做判断）
```

**核心差异化**：
1. **金融高管视角**：站在用人单位和资金流向这一端看问题
2. **真实行业洞察**：不是统计数据，是一手经验
3. **个人IP信任**：不是冰冷的工具，是有温度的人
4. **深度定制**：针对特殊家庭情况提供个性化方案

### 3.2 服务分层设计

```
┌─────────────────────────────────────────────────────────────┐
│  第三层：深度定制咨询（高客单价）                              │
│  - 1v1视频咨询（60-90分钟）                                  │
│  - 家庭背景深度分析                                          │
│  - 定制化填报方案 + 后续跟踪                                 │
│  - 定价：3000-5000元/次                                      │
├─────────────────────────────────────────────────────────────┤
│  第二层：AI智能问答（免费/低价）                              │
│  - 基于知识库的自动回复                                      │
│  - 覆盖80%常见问题                                          │
│  - 引流至深度咨询                                            │
│  - 定价：基础免费 / 高级会员99元/年                          │
├─────────────────────────────────────────────────────────────┤
│  第一层：内容引流（免费）                                     │
│  - 短视频（数字人版 + 真人版）                               │
│  - 小红书图文                                                 │
│  - 建立信任、积累粉丝                                        │
│  - 定价：免费                                                 │
└─────────────────────────────────────────────────────────────┘
```

```

  ↓
```

### 3.4 内容生产体系

#### 数字人版（量）
- **日更目标**：3-5条/天
- **内容类型**：
  - 院校介绍（"这所985性价比最高"）
  - 专业解读（"计算机专业毕业后实际做什么"）
  - 数据盘点（"2026年最热门的10个专业"）
  - 热点回应（"今年新高考改革怎么影响填报"）
- **生产流程**：
  1. AI批量生成脚本（10-20个选题/天）
  2. 人工审核（30分钟/天）
  3. 数字人生成视频（自动化）
  4. 发布（定时发布工具）

#### 真人版（质）
- **周更目标**：2-3条/周
- **内容类型**：
  - 深度分析（"为什么我不建议普通家庭学金融"）
  - 行业洞察（"银行高管告诉你，什么专业真正值钱"）
  - 答疑精华（"家长问我最多的3个问题"）
  - 案例分享（"我帮一个县城孩子规划志愿的经历"）
- **生产流程**：
  1. 选题策划（每周一次，AI辅助）
  2. 脚本撰写（AI生成初稿，人工修改）
  3. 真人录制（30-60分钟/周）
  4. 后期剪辑（外包或AI辅助）

### 3.5 技术实现方案

#### 阶段一：MVP（最小可行产品）
- **时间**：2周
- **目标**：跑通基础流程
- **方案**：
  - 知识库：Excel + 向量数据库（Milvus/Qdrant）
  - 问答系统：Coze/Dify搭建，接入大模型API
  - 数字人：硅基智能/腾讯智影（成本优先）
  - 自动回复：微信公众号/抖音私信自动回复

#### 阶段二：产品化
- **时间**：1-2个月
- **目标**：规模化运营
- **方案**：
  - 知识库：专业数据库（MySQL + Elasticsearch）
  - 问答系统：自研Agent框架
  - 数字人：多平台对比，选择效果最好的
  - 自动回复：企业微信 + 小程序

#### 阶段三：商业化
- **时间**：3-6个月
- **目标**：变现闭环
- **方案**：
  - 付费咨询：预约系统 + 视频会议
  - 会员体系：积分、等级、专属服务
  - 课程产品：录播课、直播课

## 六、风险提示

1. **数据合规**：录取数据必须来自官方渠道（各省考试院），不能爬虫非授权数据
2. **内容合规**：不能使用"保录取""100%上岸"等绝对化表述
3. **资质问题**：教育咨询可能需要相关资质，需要咨询工商部门
4. **竞争风险**：大厂免费工具已经很强大，需要找到真正的差异化
