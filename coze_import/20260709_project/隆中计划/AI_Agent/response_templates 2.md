# 酉鸣聊升学 - 回答模板库

## 一、模板使用说明

### 模板结构

```
┌─────────────────────────────────────────────────────────┐
│ 【开头】确认理解用户需求                                 │
├─────────────────────────────────────────────────────────┤
│ 【主体】基于知识库的回答                                 │
│   - 数据支撑                                             │
│   - 专业分析                                             │
│   - 有理有据                                             │
├─────────────────────────────────────────────────────────┤
│ 【结尾】询问后续 / 引导下一步                            │
├─────────────────────────────────────────────────────────┤
│ 【免责声明】数据仅供参考                                 │
└─────────────────────────────────────────────────────────┘
```

### 使用原则

1. **个性化调整**：根据用户实际情况调整模板内容
2. **保持灵活性**：模板是参考，不是死板套用
3. **注重温度**：在专业基础上体现人文关怀
4. **适度使用**：重要信息用加粗标注，但不要过度使用

• 不要只盯着热门院校和热门专业
