# 强基计划政策详解

## 什么是强基计划

### 定义
强基计划是教育部2020年推出的特殊招生政策，旨在选拔培养有志于服务国家重大战略需求且综合素质优秀或基础学科拔尖的学生。主要面向基础学科专业招生。

### 培养目标
- 服务国家重大战略需求
- 培养基础学科拔尖创新人才
- 培养关键领域后备人才

## 报名条件

### 第一类：高考成绩优异
- 高考成绩需达到所在省份一本线/特殊类型招生控制线以上
- 部分高校要求达到一定分数位次（如省排名前1%-5%）

### 第二类：五大学科竞赛金银牌
- 中国数学奥林匹克竞赛
- 全国中学生物理竞赛
- 中国化学奥林匹克竞赛
- 全国中学生生物学竞赛
- 全国青少年信息学奥林匹克竞赛
- **破格入围**：竞赛金银牌考生可破格入围强基计划

## 报名与录取流程（2025年）

### 4月-5月：报名阶段
| 学校 | 报名时间 |
|:---|:---|
| 北京大学 | 4月23日—5月10日 |
| 清华大学 | 4月23日—5月10日 |
| 中国人民大学 | 4月17日—5月10日 |
| 北京航空航天大学 | 4月21日—5月9日 |
| 北京理工大学 | 4月18日—5月10日 |
| 其他院校 | 多数在4月中下旬至5月10日 |

### 5月底前：综合素质材料上报
- 高中负责完善资料或组织填写
- 包括获奖证书、学科特长、实践活动、研究性学习报告等

### 6月7日-10日：参加高考

### 6月10日-20日左右：考前确认
- 多数高校需考生在高考出分前进行校测确认
- 部分高校如南大、浙大仅有初试确认
- 上交大、复旦、同济、中科大仅有复试确认

### 6月12日-22日：部分高校高考出分前校测
- 复旦、上交、南大、浙大、中科大等校测安排在高考后、高考出分前
- 全员参与校测（相当于全员"破格式入围"）

### 6月26日左右：确定入围名单
- 按高考成绩确定入围考生

### 6月底7月初：强基校测
- 笔试+面试+体育测试（多数学校）

### 录取
- 综合成绩=高考成绩（85%）+校测成绩（15%）
- 高考成绩不低于一本线/特殊类型线

## 招生专业

### 主要招生方向
- 数学类
- 物理学类
- 化学类
- 生物科学类
- 历史学类
- 哲学类
- 中国语言文学类
- 基础医学

### 注意事项
- 各校强基计划专业不同，需查阅具体招生简章
- 专业方向以基础学科为主，非热门工科专业
- 培养方式特殊，本硕博衔接

## 校测内容

### 笔试
- 各校自主命题
- 难度高于高考
- 重点考察学科特长和创新能力

### 面试
- 综合素质评价
- 学科兴趣和潜力
- 志愿服务、社会实践等

### 体育测试
- 多数高校将体育测试作为校测环节
- 不合格者不予录取
- 测试项目通常为50米跑、立定跳远等

## 优惠政策

### 破格入围
- 五大学科竞赛金银牌考生可破格入围
- 高考成绩不低于一本线/特殊类型线即可

### 降分录取
- 强基计划录取分数通常低于普通批次
- 可下浮15-20分左右（因校而异）

## 培养模式

### 小班化培养
- 师生比高
- 导师制

### 本硕博衔接
- 多数高校提供本硕博贯通培养
- 缩短培养周期

### 国际化培养
- 海外交流机会多
- 与国际顶尖院校合作

## 优势与劣势

### 优势
1. 入学分数相对较低
2. 基础学科培养体系完善
3. 本硕博衔接，培养周期短
4. 师资力量强

### 劣势
1. 专业选择面窄，以基础学科为主
2. 培养要求高，学习压力大
3. 转专业受限
4. 部分专业就业面相对窄

## 家长常见问题

### Q1：强基计划要不要报？
**A**：如果孩子对基础学科有浓厚兴趣，且高考分数略低于目标院校普通批次录取线，可以尝试强基计划作为降分录取途径。

### Q2：强基计划会影响普通志愿吗？
**A**：不影响。强基计划录取在普通批次之前，如未被录取不影响后续批次录取。

### Q3：竞赛金银牌一定能上吗？
**A**：不一定。金银牌考生可破格入围，但仍需参加校测，且部分高校对竞赛金银牌有具体要求（如国决银牌等）。

### Q4：强基计划转专业容易吗？
**A**：不易。强基计划专业原则上不允许转专业，只能在本校内转相关专业。

### Q5：报名需要准备什么？
**A**：
- 高中三年成绩单
- 综合素质评价档案
- 获奖证书（如有）
- 个人陈述（部分高校要求）
- 学科竞赛成绩（如有）
