# 综合评价政策详解

## 什么是综合评价

### 定义
综合评价是高校在高考成绩基础上，综合考生的高中学业水平考试成绩、综合素质评价、高校考核成绩等多元评价体系进行招生的特殊招生模式。

### 适用省份
- 浙江（三位一体）
- 江苏
- 上海
- 山东
- 广东（部分高校）
- 湖南（部分高校）
- 福建（部分高校）

## 与强基计划区别

| 项目 | 强基计划 | 综合评价 |
|:---|:---|:---|
| 招生院校 | 39所985/部分211 | 省属院校为主，部分211 |
| 专业方向 | 基础学科 | 专业广泛，含热门专业 |
| 录取依据 | 高考85%+校测15% | 高考60%-85%+学考10%-20%+校测10%-30% |
| 报名对象 | 高考优异或竞赛金银牌 | 综合素质优秀学生 |
| 竞争激烈度 | 高 | 中等 |

## 综合评价录取流程

### 1. 报名（4-5月）
- 在高校官网或阳光高考网报名
- 提交报名材料

### 2. 初审
- 高校根据报名材料筛选
- 通过名单公布（5月中下旬）

### 3. 高考
- 参加全国统一高考

### 4. 校测（6月下旬）
- 笔试+面试
- 部分高校仅需面试

### 5. 录取
- 按综合成绩录取
- 通常在提前批

## 报名材料

### 必备材料
1. 报名申请表
2. 高中三年成绩单
3. 学业水平考试成绩
4. 身份证复印件
5. 一寸照片

### 可选加分材料
1. 学科竞赛获奖证书
2. 科技创新成果
3. 文体特长证明
4. 社会实践证明
5. 志愿服务证明
6. 个人陈述
7. 推荐信

## 综合成绩构成（各省略有不同）

### 浙江省（三位一体）
- 高考成绩：60%-80%
- 学业水平考试：10%-20%
- 高校综合素质测试：10%-20%

### 江苏省
- 高考成绩：75%
- 学业水平测试：15%
- 高校面试：10%

### 上海市
- 高考成绩：60%-85%
- 学业水平考试：10%-20%
- 高校测试：10%-20%

## 校测内容

### 笔试
- 部分高校设笔试
- 难度适中
- 主要考察学科基础和综合能力

### 面试
- 无领导小组讨论
- 个人陈述
- 综合素质考察
- 时事热点分析
- 学科潜力评估

## 优势与劣势

### 优势
1. 录取分数低于普通批次（通常低10-30分）
2. 专业选择面广，含热门专业
3. 综合评价更适合全面发展的学生
4. 提前锁定录取机会

### 劣势
1. 需要额外准备校测
2. 报名材料准备繁琐
3. 竞争依然激烈
4. 录取率不高（约5%-10%）

## 报考建议

### 适合人群
1. 综合素质全面发展
2. 高考成绩略低于目标院校普通批次线
3. 有竞赛获奖、社会实践等突出表现
4. 面试能力强

### 不适合人群
1. 仅高考成绩优异，其他方面平平
2. 面试能力弱
3. 不愿投入额外时间准备
4. 目标是清北等顶尖院校（强基计划更合适）

## 家长常见问题

### Q1：综合评价值得报吗？
**A**：如果孩子综合素质优秀且分数略低目标院校，强烈建议报考。以浙江省为例，三位一体录取分数通常比普通批次低10-30分。

### Q2：综合素质材料怎么准备？
**A**：
- 提前三年规划，积累获奖和实践经历
- 真实可信，避免造假
- 突出特长和亮点
- 整理成系统性的档案

### Q3：面试重要吗？
**A**：很重要。部分高校面试占比达30%，面试表现直接影响录取。建议提前练习无领导小组讨论、个人陈述等。

### Q4：报名多少所合适？
**A**：建议2-4所。太多了准备不过来，太少了没有保底。

### Q5：综合评价会影响普通志愿吗？
**A**：不影响。综合评价在提前批录取，如未被录取不影响后续批次录取。
