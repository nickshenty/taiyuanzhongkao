# 平行志愿规则详解

## 什么是平行志愿

### 定义
平行志愿是指考生在同一录取批次中可以填报多个平行但有顺序的院校志愿，录取时按照"分数优先、遵循志愿、一轮投档"的原则进行投档。

### 适用范围
- 新高考省份：本科普通批、专科普通批
- 传统高考省份：本科一批、本科二批、专科批

## 平行志愿特点

### 1. 分数优先
所有考生按高考分数从高到低排序，同分考生按投档规则排序（如语数外成绩、单科成绩等）。

### 2. 遵循志愿
投档时按照考生填报的志愿顺序检索，从第1志愿到第N志愿依次检索。

### 3. 一轮投档
每个考生在本批次只有一次投档机会，投档后未被录取则滑档，不再检索后续志愿。

## 投档规则详解

### 投档流程
1. **排序**：所有考生按分数从高到低排序
2. **检索**：按志愿顺序检索院校
3. **投档**：如院校未满额则投档，满额则检索下一个志愿
4. **录取**：院校进行专业录取或退档
5. **循环**：继续下一个考生

### 示例
```
考生A，600分，志愿顺序：
1. 东南大学（投档线602分，未达到）
2. 南京理工大学（投档线595分，达到，投档成功）
3. 苏州大学（不检索，因为已经投档）
```

## 平行志愿风险点

### 风险一：滑档
**原因**：
- 所有志愿投档线都高于考生分数
- 志愿填报过冲

**防范措施**：
- 设置保底志愿
- 参考近3年投档线和位次

### 风险二：退档
**原因**：
- 投档后专业志愿分数不够
- 不服从专业调剂
- 体检限制专业

**防范措施**：
- 勾选"服从调剂"
- 了解目标院校专业分差
- 提前了解体检限制

### 风险三：专业不理想
**原因**：
- 被调剂到冷门专业
- 填报专业过于集中

**防范措施**：
- 合理分配专业志愿
- 了解专业分差
- 接受可能被调剂

## 志愿填报技巧

### 技巧一：冲稳保梯度
- **冲**：前2-3个志愿，分数略高于投档线
- **稳**：中间5-7个志愿，分数接近投档线
- **保**：后3-5个志愿，分数低于投档线10-20分

### 技巧二：位次优先
不要只看分数，要参考位次（全省排名），因为试题难度不同，分数会有波动，但位次相对稳定。

### 技巧三：院校专业组理解
新高考省份按院校专业组填报，同一院校专业组内专业要求相同选科。

### 技巧四：服从调剂
建议勾选"服从调剂"，避免因专业分数不够被退档。

## 退档后怎么办

### 滑档/退档情况
- 退档后不能在本批次投档
- 进入征集志愿（补录）阶段
- 或进入下一批次录取

### 征集志愿
- 每批次录取结束后公布剩余计划
- 未录取考生可填报征集志愿
- 通常志愿数量较少，竞争激烈

## 与顺序志愿区别

| 项目 | 平行志愿 | 顺序志愿 |
|:---|:---|:---|
| 投档方式 | 多个平行志愿同时检索 | 志愿按顺序依次投档 |
| 投档机会 | 一轮投档 | 多轮投档（如第一志愿未录满） |
| 志愿顺序 | 检索顺序 | 投档顺序 |
| 风险 | 滑档、退档 | 滑档风险更大 |

## 家长常见问题

### Q1：平行志愿是不是所有志愿都看？
**A**：不是。是按志愿顺序检索，一旦投档成功，后续志愿不再检索。但检索时会依次看所有志愿。

### Q2：服从调剂有什么风险？
**A**：调剂的专业可能是冷门专业，但不调剂会被退档。建议勾选服从调剂。

### Q3：冲稳保比例多少合适？
**A**：建议冲3稳6保3，或者根据志愿总数按3:6:1的比例分配。

### Q4：投档线和录取线有什么区别？
**A**：投档线是该院校最低投档分数，录取线是该专业最低录取分数，专业录取线通常高于投档线。

### Q5：滑档了怎么办？
**A**：可以参加征集志愿（补录）或下一批次录取。征集志愿选择较少，要提前关注。

### Q6：平行志愿能改吗？
**A**：填报截止前可以修改，截止后不能修改。

### Q7：为什么说位次比分数更准？
**A**：因为试卷难度不同，分数每年波动，但位次相对稳定。如600分今年和去年的位次可能不同。

### Q8：家长能代替孩子填报吗？
**A**：可以，但建议与孩子充分沟通，尊重孩子的兴趣和发展方向。
