# 哈尔滨工业大学
- 层次：985/211/双一流/C9
- 所在地：黑龙江哈尔滨（另设威海、深圳校区）
- 类型：理工类
- 优势学科：力学、机械工程、材料科学与工程、计算机科学与技术、航天工程、控制科学与工程、焊接工程（亚洲第一）
- 2025录取位次参考：物理组前2000名（本部）/威海深圳校区前5000名
- 特色标签：航天第一校、焊接工程亚洲第一、工科底蕴深、威海深圳有分校
- 适合人群：工科兴趣学生、航天军工志向、分数略低于顶尖985可考虑分校
- 就业去向：航天科技集团、航天科工集团、华为、中兴、各大军工企业
- 家长常见问题：
  - 哈工大本部和深圳校区怎么选？深圳区位好、分数高；本部工科实力最强、分数相对低
  - 哈工大的计算机和电子信息怎么样？计算机学科评估A类，电子信息也是王牌专业
- 数据来源：各省份2025年高考投档数据
