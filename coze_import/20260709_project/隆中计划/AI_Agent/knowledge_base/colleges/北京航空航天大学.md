# 北京航空航天大学
- 层次：985/211/双一流
- 所在地：北京
- 类型：工科类（军工特色）
- 优势学科：航空宇航科学与技术（全国第一）、材料科学与工程、仪器科学与技术、控制科学与工程、计算机科学与技术
- 2025录取位次参考：物理组前3000名
- 特色标签：航天航空第一校、军工背景、信息技术强、北京区位
- 适合人群：航天航空志向学生、计算机电子信息兴趣、国防科技就业
- 就业去向：航天科技集团、航天科工集团、航空工业集团、华为、中科院、选调生
- 家长常见问题：
  - 北航和北理工怎么选？北航航空航天最强，北理工兵器科学与技术最强，都是军工强校
  - 北航毕业后能进民航吗？可以，但航空航天集团是主要去向
- 数据来源：各省份2025年高考投档数据

## 就业特点
- 国防科技主导：约50%毕业生进入国防科技工业体系
- 计算机热门：软件工程、计算机科学与技术是近年最热专业
- 北京优势：地处北京，有机会参与重大科研项目
