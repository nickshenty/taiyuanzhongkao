# 北京师范大学
- 层次：985/211/双一流
- 所在地：北京
- 类型：师范类
- 优势学科：教育学（全国第一）、心理学、中国语言文学、地理学、数学、戏剧影视文学
- 2025录取位次参考：物理组前5000名/历史组前1500名
- 特色标签：师范第一、教育学顶尖、综合类大学、北京区位
- 适合人群：教育志向学生、文科兴趣学生、北京就业
- 就业去向：中小学校、教育机构、出版社、政府教育部门、选调生
- 家长常见问题：
  - 北师大和华东师大怎么选？北师大北京、地域优势；华东师大上海、商科更强，都是师范顶尖
  - 师范生毕业后必须当老师吗？不强制，但90%以上毕业生进入教育系统
- 数据来源：各省份2025年高考投档数据

## 特殊招生
- 公费师范生：免学费、有编制，但需回生源地任教6年
- 强基计划：招收数学、物理、化学等基础学科
- 综合评价：北京、上海等地有综评招生
