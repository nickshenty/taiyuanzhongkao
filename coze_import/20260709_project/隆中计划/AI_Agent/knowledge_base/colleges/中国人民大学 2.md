# 中国人民大学
- 层次：985/211/双一流
- 所在地：北京
- 类型：人文社科类
- 优势学科：法学（全国第一）、金融学、新闻传播学、社会学、马克思主义理论、统计学、工商管理、哲学
- 2025录取位次参考：物理组前1000名/历史组前200名
- 特色标签：文科顶尖、法学第一、金融黄埔、社会科学全国领先
- 适合人群：文科拔尖学生、法学金融志向、北京就业
- 就业去向：金融机构、律所、咨询公司、四大部委、媒体、选调生
- 家长常见问题：
  - 人大的法学和北大法学怎么选？北大法学综合更强，人大法学实务方向更突出，都是顶尖
  - 人大理工科怎么样？人大以人文社科见长，理工科相对薄弱，不建议理科生以理工专业为目的报考
- 数据来源：各省份2025年高考投档数据
