# 上海交通大学
- 层次：985/211/双一流/C9
- 所在地：上海
- 类型：工科类
- 优势学科：船舶与海洋工程、机械工程、电气工程、计算机科学与技术、临床医学、工商管理、材料科学与工程
- 2025录取位次参考：物理组前500名
- 特色标签：工科第二、交大密歇根学院、人工智能顶尖、医学发展快
- 适合人群：工科兴趣学生、上海就业导向、国际化培养
- 就业去向：华为、国家电网、上汽集团、互联网大厂、投行金融、选调生
- 家长常见问题：
  - 上交的工科和清华怎么选？清华工科最强，但上交在船舶、机械、电气领域不逊清华，且地处上海
  - 上交密歇根学院怎么样？与密歇根大学合作，费用高但国际化程度高，适合有留学计划学生
- 数据来源：各省份2025年高考投档数据
