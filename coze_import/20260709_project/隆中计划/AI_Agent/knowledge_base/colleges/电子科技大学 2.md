# 电子科技大学
- 层次：985/211/双一流
- 所在地：四川成都（另设清水河校区、沙河校区）
- 类型：工科类
- 优势学科：电子科学与技术（全国第一）、信息与通信工程、计算机科学与技术、光学工程、微电子
- 2025录取位次参考：物理组前8000名
- 特色标签：电子信息第一校、华为校招大户、成渝电子信息产业核心、四川小清华
- 适合人群：电子信息志向学生、计算机兴趣、成都及西南就业
- 就业去向：华为、中兴、腾讯、阿里、研究所、电子信息企业
- 家长常见问题：
  - 电子科大沙河校区和清水河怎么选？沙河主要是中外合作办学，学费高；清水河是主校区
  - 电子科大转专业好转吗？相对灵活，但热门专业竞争激烈
- 数据来源：各省份2025年高考投档数据

## 就业特点
- 华为校招重镇：每年向华为输送大量毕业生
- 电子信息行业认可度高：与电子科学与技术、信息与通信工程两个A+学科相关
- 西南地区电子信息人才供给核心
