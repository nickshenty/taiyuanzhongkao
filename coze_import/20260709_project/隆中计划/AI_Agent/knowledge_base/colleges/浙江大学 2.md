# 浙江大学
- 层次：985/211/双一流/C9
- 所在地：浙江杭州
- 类型：综合类
- 优势学科：计算机科学与技术、农业工程、软件工程、光学工程、材料科学与工程、控制科学与工程、临床医学、农学
- 2025录取位次参考：物理组前1000名/历史组前500名
- 特色标签：互联网黄埔军校、浙江第一学府、农学顶尖、综合实力强
- 适合人群：计算机/互联网方向、浙江本地及长三角就业
- 就业去向：阿里系、腾讯、字节跳动、网易、浙江本地企业、选调生
- 家长常见问题：
  - 浙大和复交怎么选？浙大综合实力强、规模大；复交在上海区位优势明显，商科更强
  - 浙大农学类专业怎么样？浙大农学全国前三，但就业面相对窄，适合真正对农业科学有兴趣的学生
- 数据来源：浙江省2025年高考投档数据
