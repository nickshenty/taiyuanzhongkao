# 大连理工大学
- 层次：985/211/双一流
- 所在地：辽宁大连（另设盘锦校区）
- 类型：工科类
- 优势学科：化学工程与技术、机械工程、力学、船舶与海洋工程、环境工程
- 2025录取位次参考：物理组前12000名（本部）
- 特色标签：化工实力强、港口与海洋特色、东北工科强校、大连区位
- 适合人群：化工志向学生、海洋工程兴趣、东北及沿海就业
- 就业去向：中石油中石化、船舶企业、大连港口、东北制造业
- 家长常见问题：
  - 大工盘锦校区和本部怎么选？盘锦校区分数低10-20分，专业不同，毕业证相同
  - 大工化工和天大化工怎么选？天大化工更强，但大工化工也属顶尖
- 数据来源：各省份2025年高考投档数据
