# 同济大学
- 层次：985/211/双一流
- 所在地：上海
- 类型：工科类
- 优势学科：土木工程（全国第一）、建筑学、城乡规划、风景园林学、环境科学与工程、设计学
- 2025录取位次参考：物理组前5000名/历史组前2000名
- 特色标签：土木建筑第一、校址在上海、中德合作、国际交流多
- 适合人群：建筑土木志向学生、上海就业、设计艺术兴趣
- 就业去向：建筑设计院、房地产企业、中建中铁、国际工程公司、选调生
- 家长常见问题：
  - 同济土木和清华土木怎么选？同济土木全国第一，超过清华；除非分数够清华，否则同济是首选
  - 同济医学院怎么样？同济医学院是后来重建的，临床医学不如老牌医学院，但发展较快
- 数据来源：各省份2025年高考投档数据

## 注意事项
- 土木工程热门专业，但近年房地产行业下行，就业面有所收窄
- 建筑学需加试美术基础，不适合无美术基础学生
- 中德合作专业：机械类、汽车方向有德语要求
