# 华东师范大学
- 层次：985/211/双一流
- 所在地：上海
- 类型：师范类
- 优势学科：教育学（全国前三）、地理学、心理学、中国语言文学、软件工程、统计学
- 2025录取位次参考：物理组前8000名/历史组前2000名
- 特色标签：师范前三、教育信息化强、上海区位、设计学新兴
- 适合人群：教育志向学生、心理学兴趣、上海就业
- 就业去向：中小学校、教育科技公司、出版社、上海教育系统、选调生
- 家长常见问题：
  - 华东师大和北师大怎么选？北师大北京、师范第一；华东师大地处上海、商科更强
  - 师范生和非师范生区别？师范生有师范技能培训，但非师范生也可从事教育行业
- 数据来源：各省份2025年高考投档数据

## 非师范专业
- 软件工程：计算机专业较强，与教育信息化结合
- 心理学：结合师范特色，发展教育心理学方向
- 金融学：经济管理方向，上海金融中心就业有优势
