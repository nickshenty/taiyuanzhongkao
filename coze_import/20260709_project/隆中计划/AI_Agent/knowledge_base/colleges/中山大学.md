# 中山大学
- 层次：985/211/双一流
- 所在地：广东广州（另设深圳校区）
- 类型：综合类
- 优势学科：临床医学（华南第一）、工商管理、生态学、哲学、公共管理、马克思主义理论
- 2025录取位次参考：物理组前8000名/历史组前2500名
- 特色标签：华南第一学府、医学顶尖、广州深圳双校区、商科强势
- 适合人群：医学志向学生、广东就业、文理均衡
- 就业去向：广东省人民医院等三甲医院、华为腾讯、广深金融业、选调生
- 家长常见问题：
  - 中大医学和华南理工医学怎么选？中山医学院是华南医学最高学府，远超华南理工
  - 中大深圳校区和本部怎么选？毕业证相同，深圳校区以医科和新兴工科为主
- 数据来源：各省份2025年高考投档数据
