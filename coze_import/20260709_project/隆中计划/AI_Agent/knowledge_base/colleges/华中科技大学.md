# 华中科技大学
- 层次：985/211/双一流
- 所在地：湖北武汉
- 类型：工科类
- 优势学科：机械工程（全国前三）、光学工程、电气工程、计算机科学与技术、临床医学、公共卫生与预防医学
- 2025录取位次参考：物理组前5000名
- 特色标签：光电信息第一、工科实力强、武汉光谷依托、华科系创业氛围浓
- 适合人群：工科兴趣学生、光电信息志向、湖北及华中就业
- 就业去向：华为、腾讯、阿里、国家电网、医疗器械企业、光谷科技企业
- 家长常见问题：
  - 华科和武大怎么选？华科工科更强，武大文理更全面；同分数下华科专业选择更多
  - 华科的临床医学怎么样？与武汉协和医院合作，医学实力华中第二，仅次于同济医学院
- 数据来源：各省份2025年高考投档数据
