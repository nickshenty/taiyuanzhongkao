# 四川大学
- 层次：985/211/双一流
- 所在地：四川成都
- 类型：综合类
- 优势学科：口腔医学（全国前三）、高分子材料、数学、文学、新闻传播学、轻工技术与工程
- 2025录取位次参考：物理组前10000名/历史组前3000名
- 特色标签：口腔医学顶尖、综合规模大、川渝第一学府、高分子材料强
- 适合人群：口腔医学志向学生、川渝就业、文理均衡
- 就业去向：华西医院等三甲医院、材料企业、新闻媒体、川渝地区企业
- 家长常见问题：
  - 川大口腔和北大口腔怎么选？北大口腔第一、川大口腔前三，都是顶尖；北大分数更高
  - 川大高分子材料怎么样？全国前三，但就业方向偏传统
- 数据来源：各省份2025年高考投档数据

## 王牌专业
- 口腔医学：5+3一体化和8年制都有，录取分逼近浙大同济
- 高分子材料：全国前三，与川大高分子国家重点实验室相关
- 文学：巴蜀文化研究特色，中国语言文学是传统优势
