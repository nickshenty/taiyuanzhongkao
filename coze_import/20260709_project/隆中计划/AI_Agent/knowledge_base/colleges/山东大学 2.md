# 山东大学
- 层次：985/211/双一流
- 所在地：山东济南（另设青岛、威海校区）
- 类型：综合类
- 优势学科：数学（全国前三）、材料科学与工程、临床医学、中国语言文学、控制科学与工程
- 2025录取位次参考：物理组前12000名/历史组前3500名
- 特色标签：数学顶尖、山东第一学府、专业门类齐全、齐鲁文化底蕴
- 适合人群：数学兴趣学生、山东本地就业、文理均衡
- 就业去向：华为、金融机构、山东电网、三甲医院、山东省内企业
- 家长常见问题：
  - 山大数学和北大数院怎么选？山大数学全国前三，仅次于北大；分数不够北大时，山大是最好选择
  - 山大威海校区怎么样？毕业证与本部相同，海洋、经济学专业为主
- 数据来源：各省份2025年高考投档数据

## 数学特色
- 潘承洞院士创建的数学学科
- 金融数学特色：山大是金融数学的发源地之一
- 与山东大学数学学院相关的金融行业校友资源丰富
