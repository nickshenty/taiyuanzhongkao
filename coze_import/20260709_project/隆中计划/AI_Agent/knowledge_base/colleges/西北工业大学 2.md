# 西北工业大学
- 层次：985/211/双一流
- 所在地：陕西西安
- 类型：工科类（军工特色）
- 优势学科：航空宇航科学与技术（全国前三）、材料科学与工程、计算机科学与技术、机械工程
- 2025录取位次参考：物理组前8000名
- 特色标签：三航之一（航空/航天/航海）、材料顶尖、军工背景、西安区位
- 适合人群：航空航天志向学生、材料科学兴趣、西部军工就业
- 就业去向：航天科技集团、航天科工集团、航空工业集团、华为西安研究所
- 家长常见问题：
  - 西工大和西交怎么选？西工大三航顶尖，西交电气管理更强；航空航天选西工大
  - 西工大毕业后能进民航吗？可以，但更多进入军工集团
- 数据来源：各省份2025年高考投档数据

## 三航特色
- 航空：歼击机、无人机研究方向
- 航天：火箭发动机、卫星技术
- 航海：水下航行器、海洋工程
