# 厦门大学
- 层次：985/211/双一流
- 所在地：福建厦门（另设漳州校区）
- 类型：综合类
- 优势学科：会计学（全国第一）、统计学、经济学、海洋科学、化学、新闻传播学
- 2025录取位次参考：物理组前10000名/历史组前2500名
- 特色标签：会计第一校、校园环境最美、经济学强项、海峡西岸龙头
- 适合人群：财经志向学生、南方就业、校园环境要求高
- 就业去向：四大会计师事务所、投行基金、华为、厦门及福建本地企业
- 家长常见问题：
  - 厦大会计和央财、上财怎么选？厦大会计全国第一，但地域不如北京上海；留福建选厦大
  - 厦大漳州校区怎么样？与本部同等学历，嘉庚学院是独立学院注意区分
- 数据来源：各省份2025年高考投档数据

## 会计特色
- 会计学连续多年全国第一
- CPA考试通过率高
- 厦门国家会计学院依托厦大资源
