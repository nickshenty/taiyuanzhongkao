# 吉林大学
- 层次：985/211/双一流
- 所在地：吉林长春
- 类型：综合类
- 优势学科：车辆工程（全国前三）、法学、数学、化学、地质资源与地质工程
- 2025录取位次参考：物理组前15000名/历史组前4000名
- 特色标签：汽车工程摇篮、法学强项、东北第一学府、规模庞大
- 适合人群：车辆工程志向学生、法学兴趣、东北就业
- 就业去向：一汽集团、大众汽车、律所、长春及东北企业
- 家长常见问题：
  - 吉大法学和五院四系怎么选？吉大法学是五院四系之一，传统法学强校，但地域不占优势
  - 吉大车辆工程和同济汽车怎么选？吉大车辆历史悠久，同济汽车依托上海汽车产业
- 数据来源：各省份2025年高考投档数据

## 注意事项
- 招生规模大：全国招生超万人，是985中招生规模最大的
- 专业冷热分化明显：车辆、法学、数学是热门，其他专业分数较低
- 东北区位：就业以东北为主，南方就业认可度一般
