# 北京大学
- 层次：985/211/双一流/C9
- 所在地：北京
- 类型：综合类
- 优势学科：数学、物理学、化学、计算机科学与技术、口腔医学、哲学、经济学、法学、文学、历史学、公共管理
- 2025录取位次参考：物理组前100名/历史组前50名（全国卷省份约670+）
- 特色标签：文理医工全面顶尖、状元摇篮、顶级资源
- 适合人群：文理科顶尖学生、学术研究导向、出国深造
- 就业去向：金融投行、互联网大厂、科研院所、部委公务员、出国深造
- 家长常见问题：
  - 北大医学部和北大本部怎么选？北大医学部录取分略低，但毕业证相同，适合想学医但分数稍低的考生
  - 强基计划怎么报？北大强基招收数学、物理、化学、生物等基础学科，入围后需校测
- 数据来源：浙江省2025年高考投档数据、北京教育考试院2025年数据
