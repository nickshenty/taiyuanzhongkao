# 南京大学
- 层次：985/211/双一流/C9
- 所在地：江苏南京
- 类型：综合类
- 优势学科：天文学、地质学、图书情报与档案管理、中国语言文学、计算机科学与技术、环境科学与工程、哲学、社会学
- 2025录取位次参考：物理组前800名/历史组前300名
- 特色标签：文理基础学科强、南京第一学府、天文学全国第一
- 适合人群：基础学科兴趣学生、文理均衡发展、南京及华东就业
- 就业去向：互联网大厂、金融机构、高校科研、选调生、江苏本地企业
- 家长常见问题：
  - 南大和浙大怎么选？南大规模小而精，文理更强；浙大规模大、工科更强，视专业兴趣选择
  - 南大苏州校区怎么样？2022年新设，与本部同等招生代码，文科专业为主
- 数据来源：各省份2025年高考投档数据
