# 南开大学
- 层次：985/211/双一流
- 所在地：天津
- 类型：综合类
- 优势学科：化学（全国前五）、数学、金融学、经济学、历史学、统计学、环境科学
- 2025录取位次参考：物理组前8000名/历史组前2000名
- 特色标签：周恩来母校、文理基础学科强、金融经济强项、天津第一
- 适合人群：文理基础学科兴趣、金融志向、天津及华北就业
- 就业去向：金融机构、咨询公司、华为、天津本地企业、选调生
- 家长常见问题：
  - 南开和天大怎么选？南开文理更强，天大工科更强；金融经济选南开，工程建筑选天大
  - 南开数学和北大数院怎么选？北大数院全国第一，南开数学也很有实力，差距较大
- 数据来源：各省份2025年高考投档数据

## 金融特色
- 金融学是传统优势学科，与天津金融中心定位相关
- 经济学院、历史学院、数学学院是南开三大王牌
- 伯苓班：理科基础学科拔尖人才培养
