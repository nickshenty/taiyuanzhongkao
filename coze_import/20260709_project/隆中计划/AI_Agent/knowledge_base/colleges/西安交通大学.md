# 西安交通大学
- 层次：985/211/双一流/C9
- 所在地：陕西西安
- 类型：理工类
- 优势学科：电气工程（全国第一）、动力工程与工程热物理、机械工程、管理科学与工程、核科学与技术
- 2025录取位次参考：物理组前3000名
- 特色标签：老交大嫡传、电气工程全国第一、管理学顶尖、西北工科龙头
- 适合人群：工科兴趣学生、电力系统志向、西北及西部地区就业
- 就业去向：国家电网、南方电网、华为、电力设计院、航天航空企业
- 家长常见问题：
  - 西交和哈工大怎么选？西交电气、管理最强；哈工大航天、机械更强，根据专业兴趣选择
  - 西交在西部就业认可度如何？在西北地区，西交是除清北复交外最受认可的高校
- 数据来源：各省份2025年高考投档数据

## 王牌专业
- 电气工程：全国排名第一，有"电气四虎"之首之称
- 能源动力工程：与电气工程密切相关，行业认可度高
- 管理科学与工程：全国前三，工商管理也很强
