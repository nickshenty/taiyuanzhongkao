# 中国科学技术大学
- 层次：985/211/双一流/C9
- 所在地：安徽合肥
- 类型：理工类
- 优势学科：物理学、化学、数学、计算机科学与技术、量子信息科学、地球物理学、核科学与技术、安全科学与工程
- 2025录取位次参考：物理组前500名
- 特色标签：量子通信第一、基础科学顶尖、小而精办学、留学率高
- 适合人群：热爱基础科学研究、理工科拔尖学生、有志出国深造
- 就业去向：科研院所、高校任教、半导体行业、华为阿里、留学深造
- 家长常见问题：
  - 中科大和中科院什么关系？中科大由中科院创办，资源共享，科研氛围浓厚
  - 中科大出国率为什么这么高？学校重视基础学科培养，与海外顶尖院校联系密切
- 数据来源：各省份2025年高考投档数据

## 办学特色
- 精英教育：本科招生规模小（约1900人/年），师生比高
- 出国深造：QS百强深造率超过30%
- 合肥优势：依托合肥微尺度物质科学国家研究中心等大科学装置
