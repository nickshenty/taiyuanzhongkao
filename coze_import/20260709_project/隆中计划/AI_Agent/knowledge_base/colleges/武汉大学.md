# 武汉大学
- 层次：985/211/双一流
- 所在地：湖北武汉
- 类型：综合类
- 优势学科：测绘工程（亚洲第一）、水利工程、马克思主义理论、法学、图书馆情报与档案管理、遥感科学与技术
- 2025录取位次参考：物理组前6000名/历史组前2000名
- 特色标签：校园最美、综合实力强、测绘水利顶尖、珞珈山樱花园
- 适合人群：文理均衡学生、测绘水利志向、武汉及华中就业
- 就业去向：测绘局、水利部门、规划设计院、地产企业、选调生
- 家长常见问题：
  - 武大和华科怎么选？武大文理全面，华科工科更强；法学、遥感、水利方向选武大
  - 武大樱花季游客多会影响学习吗？不会，学校有分流管理，校园生活正常
- 数据来源：各省份2025年高考投档数据
