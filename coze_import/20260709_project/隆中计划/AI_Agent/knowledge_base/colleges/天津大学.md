# 天津大学
- 层次：985/211/双一流
- 所在地：天津
- 类型：工科类
- 优势学科：化学工程与技术（全国第一）、建筑学、水利工程、力学、机械工程、仪器科学与技术
- 2025录取位次参考：物理组前7000名
- 特色标签：化工第一校、建筑老八校、天津工业龙头、港口与海岸工程特色
- 适合人群：化工志向学生、建筑工程兴趣、天津及华北就业
- 就业去向：中石油中石化、建筑设计院、港口工程企业、天津本地企业
- 家长常见问题：
  - 天大和南开怎么选？天大工科更强，南开文理更强；理科生想学工科选天大
  - 天津大学建筑和同济建筑怎么选？天大建筑全国前五，但整体实力稍弱于同济
- 数据来源：各省份2025年高考投档数据

## 王牌专业
- 化学工程与技术：A+学科，与天津石化产业紧密结合
- 建筑学：建筑老八校之一，建筑设计院就业有优势
- 水利工程：港口海岸方向特色，与天津港相关
