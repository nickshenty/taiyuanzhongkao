# 重庆大学
- 层次：985/211/双一流
- 所在地：重庆
- 类型：综合类
- 优势学科：电气工程（全国前五）、建筑学、土木工程、机械工程、矿业工程
- 2025录取位次参考：物理组前12000名/历史组前3500名
- 特色标签：建筑老八校、电气工程强项、重庆第一学府、川渝地区认可度高
- 适合人群：电气建筑志向学生、川渝就业、文理均衡
- 就业去向：国家电网、西南建筑设计院、长安汽车、重庆本地企业
- 家长常见问题：
  - 重大电气和西交电气怎么选？西交电气全国第一，重大电气全国前五；分数够西交优先
  - 重大建筑和同济建筑怎么选？同济建筑最强，重大建筑前五但差距明显
- 数据来源：各省份2025年高考投档数据

## 建筑老八校之一
- 建筑城规学院：山城特色，规划设计方向有优势
- 电气工程学院：电力系统方向，与西南电网相关
- 机械工程学院：汽车工程方向，与长安汽车有合作
