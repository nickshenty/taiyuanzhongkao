# 东南大学
- 层次：985/211/双一流
- 所在地：江苏南京
- 类型：工科类
- 优势学科：建筑学（全国前三）、土木工程、生物医学工程（全国第一）、交通运输工程、电子科学与技术
- 2025录取位次参考：物理组前6000名
- 特色标签：建筑老八校、生物医学工程第一、工科实力强、南京区位
- 适合人群：建筑土木志向学生、医学工程交叉、南京及长三角就业
- 就业去向：建筑设计院、地产企业、华为、医疗器械企业、南京本地企业
- 家长常见问题：
  - 东南建筑和同济建筑怎么选？同济建筑全国第一，东南建筑全国前三，都是建筑老八校
  - 东南医工交叉怎么样？生物医学工程全国第一，适合想做医疗器械的学生
- 数据来源：各省份2025年高考投档数据
