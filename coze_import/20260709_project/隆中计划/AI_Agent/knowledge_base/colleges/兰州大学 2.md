# 兰州大学
- 层次：985/211/双一流
- 所在地：甘肃兰州
- 类型：综合类
- 优势学科：草学（全国第一）、生态学、化学、大气科学、历史学、数学
- 2025录取位次参考：物理组前18000名/历史组前5000名
- 特色标签：草业科学第一、西北综合最强、基础学科底蕴深、留学率高
- 适合人群：农学志向学生、基础学科兴趣、分数偏低想上985
- 就业去向：科研院所、高校任教、环保部门、西北地区企业
- 家长常见问题：
  - 兰大是不是很偏远？兰州位置偏远，但学校是985，学历含金量不减
  - 兰大草学和农学有什么区别？草学主要研究草原生态，与畜牧、环境保护相关
- 数据来源：各省份2025年高考投档数据

## 特色学科
- 草业科学：全国第一，与西北草原生态相关
- 生态学：西北生态研究重镇
- 化学：有机化学方向有特色，诺贝尔奖获得者从这里走出
- 大气科学：兰大气象学科有区域优势
