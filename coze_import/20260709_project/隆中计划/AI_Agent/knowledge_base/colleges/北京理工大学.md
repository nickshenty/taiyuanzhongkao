# 北京理工大学
- 层次：985/211/双一流
- 所在地：北京
- 类型：工科类（军工特色）
- 优势学科：兵器科学与技术（全国第一）、机械工程、材料科学与工程、光学工程、信息与通信工程
- 2025录取位次参考：物理组前5000名
- 特色标签：兵器第一校、军工背景、北京区位、计算机实力上升快
- 适合人群：军工志向学生、计算机兴趣、北京就业
- 就业去向：航天科技集团、兵器工业集团、华为、互联网大厂、选调生
- 家长常见问题：
  - 北理工和北航怎么选？北航航空航天最强，北理工兵器最强；分数相近，专业方向不同
  - 北理工计算机怎么样？计算机科学与技术评估A类，工信部重点支持
- 数据来源：各省份2025年高考投档数据

## 兵器特色
- 车辆工程：坦克、装甲车研究特色
- 机电学院：弹药、爆炸研究方向
- 信息与电子学院：雷达、通信对抗方向
