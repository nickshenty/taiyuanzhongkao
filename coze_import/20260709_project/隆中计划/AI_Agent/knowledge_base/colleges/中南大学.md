# 中南大学
- 层次：985/211/双一流
- 所在地：湖南长沙
- 类型：综合类
- 优势学科：冶金工程（全国第一）、矿业工程（全国第一）、护理学、材料科学与工程、土木工程
- 2025录取位次参考：物理组前12000名/历史组前3500名
- 特色标签：有色金属第一校、冶金矿业顶尖、湘雅医学院、铁路交通特色
- 适合人群：工科兴趣学生、材料冶金志向、湖南及中部就业
- 就业去向：中国铝业、中国五矿、中建集团、中南大学湘雅医院
- 家长常见问题：
  - 中南冶金和北京科技大学怎么选？中南冶金全国第一，但传统行业薪资一般；北科大地域更好
  - 中南湘雅医学院和湘雅医学院怎么选？中南湘雅就是原湘雅医学院，合并后仍是湖南医学最高学府
- 数据来源：各省份2025年高考投档数据

## 湘雅医学院
- 湘雅医学院：原卫生部直属，与北京协和齐名
- 临床医学：湖南省第一，全国前十五
- 护理学：全国前三，中南大学特色专业
