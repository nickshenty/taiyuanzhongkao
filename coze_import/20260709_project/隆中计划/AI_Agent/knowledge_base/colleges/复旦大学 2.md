# 复旦大学
- 层次：985/211/双一流/C9
- 所在地：上海
- 类型：综合类
- 优势学科：数学、哲学、新闻传播学、临床医学、经济学、金融学、计算机科学与技术、公共管理
- 2025录取位次参考：物理组前500名/历史组前200名
- 特色标签：江南第一学府、上海金融中心、经管法学强、文理医全面发展
- 适合人群：文理均衡发展学生、上海及长三角就业导向
- 就业去向：投行基金、咨询公司、互联网大厂、上海本地优质企业、选调生
- 家长常见问题：
  - 复旦和上交怎么选？复旦文理医见长，上交工科强势；金融方向复旦更优，工程方向上交更强
  - 复旦在上海就业认可度如何？复旦在上海与清北齐名，是上海本地最好的高校
- 数据来源：各省份2025年高考投档数据
