# 法学
- 学科门类：法学
- 学制：4年
- 选科要求：不限（部分院校要求政治）
- 学什么：民法、刑法、宪法、行政法、商法、知识产权法、民事诉讼法、刑事诉讼法、法理学
- 就业方向：律师事务所、法院、检察院、企业法务、公证处、仲裁机构
- 典型岗位：律师（实习期5-8k，资深年薪30-100万+）、法官检察官（体制内薪资）、企业法务
- 考研率：约25-35%
- 红绿牌：红牌（连续多年红牌，法考通过率约15%）
- 开设院校TOP10：人大、法大、北大、清华、武大、华政、吉大、复旦、对外经贸、中南财经政法
- 家长常见问题：
  - 法考难吗？通过率约15%，需要系统复习
  - 法学是不是红牌专业？是，但顶尖法学院和通过法考的毕业生仍然抢手
  - 律师收入怎么样？两极分化，顶尖律师收入极高，普通律师起步艰难
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
