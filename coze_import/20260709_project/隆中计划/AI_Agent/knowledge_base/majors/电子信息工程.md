# 电子信息工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：信号与系统、数字信号处理、通信原理、电磁场与电磁波、微波技术、天线原理、雷达原理
- 就业方向：通信设备制造（华为、中兴）、电子信息企业、研究所、航空航天、军工
- 典型岗位：通信工程师（15-30k）、硬件工程师（12-28k）、射频工程师（15-35k）、嵌入式工程师
- 考研率：约45-55%
- 红绿牌：绿牌（电子信息是国家战略方向）
- 开设院校TOP10：成电、西电、清华、北大、浙大、上交、东南、北邮、哈工大、华科
- 家长常见问题：
  - 电子信息和通信工程有什么区别？电子信息更广，涵盖电子系统和信息处理；通信工程专注于通信领域
  - 女生适合学吗？适合，行业内男女比例虽有差距但并非男生专属
  - 就业去向主要是哪里？华为中兴等通信企业、研究所、军工单位
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
