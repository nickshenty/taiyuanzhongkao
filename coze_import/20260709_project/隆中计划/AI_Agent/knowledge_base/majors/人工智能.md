# 人工智能
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起普遍要求）
- 学什么：机器学习、深度学习、自然语言处理、计算机视觉、机器人学、知识图谱、强化学习
- 就业方向：AI算法工程师、机器学习工程师、NLP工程师、CV工程师、AI产品经理、研究院
- 典型岗位：AI算法工程师（30-60k）、机器学习工程师（25-50k）、深度学习工程师（30-55k）
- 考研率：约60-70%（高学历需求）
- 红绿牌：绿牌（2025年就业落实率96.5%，最高薪专业之一）
- 开设院校TOP10：清华、北大、浙大、上交、哈工大、南大、电子科大、北航、华科、中科大
- 家长常见问题：
  - 人工智能是不是泡沫？技术仍在快速发展期，需求持续增长，但竞争也在加剧
  - 本科直接就业还是考研？建议考研，AI岗位普遍要求硕士以上
  - 和计算机专业有什么区别？AI更侧重算法和模型，计算机更侧重系统开发
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
