# 电气工程及其自动化
- 学科门类：工学
- 学制：4年
- 选科要求：物理（部分院校要求物理+化学）
- 学什么：电路原理、模拟电子技术、数字电子技术、自动控制原理、电力系统分析、高电压技术、电机学
- 就业方向：国家电网、南方电网、电力设计院、发电厂、电气设备企业、新能源汽车
- 典型岗位：电网运维工程师（10-20k）、电力设计工程师（12-25k）、电气研发工程师（15-30k）
- 考研率：约35-45%
- 红绿牌：绿牌（连续多年绿牌，国家电网招聘大户）
- 开设院校TOP10：清华、西交、华科、浙大、华电、哈工大、上交、天大、东南、重大
- 家长常见问题：
  - 进了电网是不是一辈子稳定？相对稳定，但需要从基层做起，晋升需要时间和考试
  - 女生适合学电气吗？适合，电力系统工作环境对女生友好
  - 和自动化有什么区别？电气偏电力系统，自动化偏工业控制
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
