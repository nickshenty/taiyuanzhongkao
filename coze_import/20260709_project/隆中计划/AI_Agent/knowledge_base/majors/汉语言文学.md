# 汉语言文学
- 学科门类：文学
- 学制：4年
- 选科要求：不限
- 学什么：现代汉语、古代汉语、中国现当代文学、中国古代文学、外国文学、文学理论、写作
- 就业方向：中学语文教师、出版社/报社/杂志社、政府机关文秘、新媒体编辑、考公
- 典型岗位：语文教师（6-12k，有编制更稳定）、编辑记者（8-15k）、文案策划（8-15k）、公务员
- 考研率：约30-40%
- 红绿牌：绿牌（考公热门专业）
- 开设院校TOP10：北大、北师大、复旦、南大、华东师大、武大、川大、浙大、南开、山大
- 家长常见问题：
  - 毕业后只能当老师吗？不是，还可以考公、编辑、新媒体等
  - 考公有哪些岗位？办公室文员、宣传部门、党委系统等
  - 写作能力差能学吗？写作可以培养，主要还是文学研究
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
