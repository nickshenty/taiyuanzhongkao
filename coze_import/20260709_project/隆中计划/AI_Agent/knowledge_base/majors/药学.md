# 药学
- 学科门类：医学
- 学制：4年（临床药学5年）
- 选科要求：物理+化学（部分要求生物）
- 学什么：药物化学、药理学、药剂学、药物分析、临床药学、药事管理、天然药物化学
- 就业方向：制药企业（恒瑞、齐鲁等）、医院药剂科、药品监管部门、药店、CRO公司
- 典型岗位：药物研发（12-25k）、临床监查员CRA（10-20k）、药剂师（8-15k）、药品注册
- 考研率：约45-55%
- 红绿牌：绿牌（医药行业刚需）
- 开设院校TOP10：北京协和医学院、北大、复旦、上交、浙大、中山大学、四川大学、山东大学、沈阳药科
- 家长常见问题：
  - 药学和临床医学区别？药学偏药物研发和用药，临床医学偏诊断治疗
  - 临床药师就业如何？医院临床药师需求增加，需要临床药学专业
  - 药店工作怎么样？门槛低但发展有限，执业药师有前途
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
