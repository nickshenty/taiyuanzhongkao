# 机器人工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：机器人学、机器人机构学、电机与拖动、单片机原理、机器视觉、ROS机器人操作系统、人工智能
- 就业方向：工业机器人企业、服务机器人公司、智能制造企业、科研院所
- 典型岗位：机器人算法工程师（25-50k）、机器人应用工程师（15-30k）、机械设计工程师（12-25k）
- 考研率：约55-65%
- 红绿牌：绿牌（智能制造核心专业）
- 开设院校TOP10：哈工大、清华、上交、北航、华科、浙大、东南、成电、西交、北理工
- 家长常见问题：
  - 机器人工程是不是新专业？是的，2015年后大量开设，选择时要看学校背景
  - 毕业能做什么？工业机器人调试、服务机器人研发、自动化集成
  - 和自动化有什么区别？机器人工程更专注于机器人本体，自动化更宽泛
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
