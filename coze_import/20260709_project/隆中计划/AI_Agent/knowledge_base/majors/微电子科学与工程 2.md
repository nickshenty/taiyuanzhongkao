# 微电子科学与工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：半导体物理、集成电路设计、微电子器件、芯片制造工艺、封装技术、模拟集成电路、数字集成电路
- 就业方向：芯片设计公司（华为海思、寒武纪等）、晶圆代工厂（中芯国际）、半导体设备企业
- 典型岗位：芯片设计工程师（25-50k）、工艺工程师（15-30k）、版图工程师（12-25k）、验证工程师
- 考研率：约55-65%
- 红绿牌：绿牌（芯片国产化带动需求爆发）
- 开设院校TOP10：清华、北大、复旦、上交、浙大、电子科大、西电、成电、东南、北航
- 家长常见问题：
  - 芯片卡脖子问题严重吗？严重，国家大力投入，就业前景好
  - 设计比制造好吗？设计薪资更高，但制造也是重要环节
  - 需要读研吗？需要，芯片行业普遍要求硕士以上
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
