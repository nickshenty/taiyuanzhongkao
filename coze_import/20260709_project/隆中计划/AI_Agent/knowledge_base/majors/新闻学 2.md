# 新闻学
- 学科门类：文学
- 学制：4年
- 选科要求：不限
- 学什么：新闻采访与写作、新闻编辑、新闻摄影、传播学概论、新媒体运营、融媒体制作、新闻伦理
- 就业方向：传统媒体（报社、电视台）、新媒体（自媒体、平台）、企业品牌公关、政府宣传
- 典型岗位：记者编辑（8-15k）、新媒体运营（10-20k）、内容策划（10-18k）、品牌公关（12-22k）
- 考研率：约25-35%
- 红绿牌：黄牌（传统媒体萎缩，新媒体竞争激烈）
- 开设院校TOP10：人大、复旦、清华、北大、暨大、武大、华中科技、川大、中传、上大
- 家长常见问题：
  - 记者是不是夕阳职业？传统媒体在萎缩，但新媒体、内容创业兴起
  - 毕业后只能当记者吗？不是，企业的品牌公关、内容运营都需要
  - 需要口才好吗？不一定，文字能力更重要
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
