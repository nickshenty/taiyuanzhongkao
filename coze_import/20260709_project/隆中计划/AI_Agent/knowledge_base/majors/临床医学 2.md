# 临床医学
- 学科门类：医学
- 学制：5年/5+3一体化/8年制（本博连读）
- 选科要求：物理+化学+生物（多数院校要求物化生）
- 学什么：人体解剖学、生理学、病理学、内科学、外科学、妇产科学、儿科学、诊断学
- 就业方向：各级医院（住院医师→主治医师→主任医师）、医学研究机构、医药企业（临床监查员）
- 典型岗位：住院医师（8-15k）、主治医师（15-30k）、主任医师（30k+）、医学研究员
- 考研率：基本100%（必须深造才有出路）
- 红绿牌：绿牌（稳定但培养周期长）
- 开设院校TOP10：协和、北大、复旦、上交、浙大、川大华西、中山、同济、武汉大学、华科同济
- 家长常见问题：
  - 5年制、5+3、8年制怎么选？8年制最高可直接博士，但录取分最高；5+3本硕连读性价比高
  - 医生收入怎么样？初级医生收入一般，主任医师收入可观，但需要熬10-15年
  - 医患矛盾严重吗？确实存在，但可通过良好沟通缓解，大多数患者是理解的
- 数据来源：教育部《普通高等学校本科专业目录》
