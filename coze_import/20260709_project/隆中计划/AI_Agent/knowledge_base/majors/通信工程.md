# 通信工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：通信原理、信号与系统、数字信号处理、电磁场理论、微波技术、移动通信、光纤通信
- 就业方向：华为、中兴等通信设备商、运营商、通信规划设计院、研究所
- 典型岗位：通信工程师（15-30k）、网络优化工程师（12-22k）、硬件工程师（15-28k）、研发工程师
- 考研率：约45-55%
- 红绿牌：绿牌（5G/6G建设带动需求）
- 开设院校TOP10：成电、西电、清华、北大、浙大、上交、东南、北邮、哈工大、华科
- 家长常见问题：
  - 华为招聘多吗？通信工程专业是华为招聘的重点专业之一
  - 5G建设完了会不会失业？不会，6G、卫星通信等新技术持续发展中
  - 和电子信息有什么区别？通信工程专注通信领域，电子信息更宽泛
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
