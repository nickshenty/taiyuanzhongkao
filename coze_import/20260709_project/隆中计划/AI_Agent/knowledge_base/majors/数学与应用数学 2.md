# 数学与应用数学
- 学科门类：理学
- 学制：4年
- 选科要求：物理（部分院校要求化学）
- 学什么：数学分析、高等代数、解析几何、概率论与数理统计、常微分方程、数值计算方法、金融数学
- 就业方向：金融机构（银行、证券、基金）、互联网公司（算法、数据分析）、高校/科研机构、IT行业
- 典型岗位：量化分析师（25-50k）、数据分析师（12-25k）、算法工程师（25-50k）、精算师
- 考研率：约45-55%（深造后薪资更高）
- 红绿牌：绿牌（基础学科，就业面广）
- 开设院校TOP10：北大、复旦、山大、浙大、清华、南开、中科大、上交、北师大、武大
- 家长常见问题：
  - 数学难学吗？难，需要抽象思维能力和大量练习
  - 毕业只能当老师吗？不是，金融、IT、科研都是方向
  - 和统计学有什么区别？数学更理论，统计更应用
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
