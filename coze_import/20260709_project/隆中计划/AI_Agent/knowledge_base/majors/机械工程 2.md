# 机械工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：机械制图、理论力学、材料力学、机械原理、机械设计、制造技术基础、数控技术
- 就业方向：汽车制造、机械装备、航空航天、工业机器人、智能制造企业
- 典型岗位：机械设计工程师（10-20k）、工艺工程师（10-18k）、项目经理（15-30k）、研发工程师
- 考研率：约40-50%
- 红绿牌：绿牌（制造业复苏带动需求）
- 开设院校TOP10：清华、上交、哈工大、北航、华科、浙大、天津大学、大连理工、重大、西安交大
- 家长常见问题：
  - 机械是不是夕阳专业？不是，智能制造、新能源汽车带动机械转型升级
  - 女生适合吗？适合程度因方向而异，设计类适合，工厂类较辛苦
  - 和车辆工程区别？机械更通用，车辆更专注汽车领域
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
