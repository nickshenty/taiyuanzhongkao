# 英语
- 学科门类：文学
- 学制：4年
- 选科要求：不限
- 学什么：基础英语、高级英语、英美文学、语言学概论、翻译理论与实践、口译、英语教学法
- 就业方向：翻译（口译/笔译）、外贸/外企、英语教师、涉外导游、国际组织
- 典型岗位：翻译（8-20k，同传日薪可达3000-10000）、英语教师（6-15k）、外贸业务员（8-15k+提成）
- 考研率：约30-40%
- 红绿牌：黄牌（开设院校多，竞争激烈）
- 开设院校TOP10：北大、北外、上外、广外、复旦、上交、华东师大、外经贸、南大、武大
- 家长常见问题：
  - 英语专业还有前途吗？有，但需要"英语+技能"复合发展
  - 需要专八证书吗？需要，是英语专业学生的重要资质证明
  - 翻译会被AI取代吗？基础翻译可能受影响，高端翻译仍需要人工
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
