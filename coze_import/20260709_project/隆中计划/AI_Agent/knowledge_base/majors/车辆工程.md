# 车辆工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：汽车构造、汽车理论、汽车设计、发动机原理、车辆动力学、新能源汽车技术、智能网联汽车
- 就业方向：汽车制造企业（大众、丰田、比亚迪、蔚来等）、汽车零部件企业、汽车研究院
- 典型岗位：汽车设计工程师（12-22k）、底盘工程师（12-25k）、新能源汽车工程师（15-30k）、项目管理
- 考研率：约40-50%
- 红绿牌：绿牌（新能源汽车带动行业复苏）
- 开设院校TOP10：清华、同济、吉大、复旦、上交、华南理工、北理、重大、湖大、哈工大
- 家长常见问题：
  - 传统汽车不行了？燃油车在萎缩，但新能源汽车、智能汽车快速发展
  - 新能源汽车前景如何？国家战略方向，电池、电驱、电控人才需求大
  - 女生适合吗？设计类适合，现场工程师较辛苦
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
