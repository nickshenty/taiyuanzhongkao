# 能源与动力工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：工程热力学、流体力学、传热学、燃烧学、锅炉原理、汽轮机原理、制冷与低温工程
- 就业方向：发电厂（中电投、华能等）、电力设备企业、汽车企业、制冷空调企业
- 典型岗位：热动工程师（10-20k）、暖通工程师（12-22k）、系统工程师（15-28k）、项目经理
- 考研率：约40-50%
- 红绿牌：绿牌（能源安全战略）
- 开设院校TOP10：清华、西安交大、华中科技大学、浙大、哈工大、上海交通大学、天津大学、东南大学
- 家长常见问题：
  - 是不是传统工科？是的，但正在向新能源方向转型
  - 就业辛苦吗？电厂工作可能需要倒班，其他方向正常
  - 和新能源专业有什么区别？能动偏传统能源，新能源是新方向
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
