# 金融学
- 学科门类：经济学
- 学制：4年
- 选科要求：不限（部分院校要求物理或历史）
- 学什么：货币银行学、国际金融、证券投资学、公司金融、金融工程、风险管理、保险学
- 就业方向：银行、证券、基金、保险等金融机构、投资银行、资产管理公司、金融监管部门
- 典型岗位：银行柜员/客户经理（6-12k）、券商分析师（15-30k）、基金经理（50k+）、风险管理师
- 考研率：约35-45%
- 红绿牌：绿牌（金融行业仍是高薪，但竞争激烈）
- 开设院校TOP10：北大、清华、复旦、上交、人大、厦大、南开、中山、央财、上财
- 家长常见问题：
  - 金融是不是很看重背景？确实存在，但能力同样重要
  - 普通学校学金融有出路吗？有，但需要考取CPA、CFA等证书提升竞争力
  - 金融和会计怎么选？金融偏投资融资，会计偏核算记账
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
