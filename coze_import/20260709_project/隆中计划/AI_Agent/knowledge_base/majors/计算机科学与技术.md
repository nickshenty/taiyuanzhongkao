# 计算机科学与技术
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起多数院校要求物化捆绑）
- 学什么：数据结构、算法设计、操作系统、计算机网络、数据库原理、编译原理、软件工程、人工智能导论
- 就业方向：互联网开发、算法工程师、数据科学家、人工智能、产品经理、测试工程师
- 典型岗位：后端开发工程师（15-30k）、算法工程师（25-50k）、数据分析师（12-25k）、前端开发（12-28k）
- 考研率：约30-40%
- 红绿牌：绿牌（2025年就业落实率96.5%，薪资排名前三）
- 开设院校TOP10：清华、北大、浙大、国防科大、上交、北航、哈工大、华科、电子科大、西电
- 家长常见问题：
  - 女生适合学计算机吗？完全适合，编程能力与性别无关
  - 35岁会被淘汰吗？互联网行业确实存在年龄压力，但可以在技术深耕或转向管理
  - 普通学校学计算机有出路吗？有，大厂招聘看技术能力，ACM竞赛获奖、项目经验更重要
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
