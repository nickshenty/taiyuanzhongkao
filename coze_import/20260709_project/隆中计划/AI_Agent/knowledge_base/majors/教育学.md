# 教育学
- 学科门类：教育学
- 学制：4年
- 选科要求：不限（部分院校要求政治或历史）
- 学什么：教育学原理、教育心理学、课程与教学论、教育管理学、教育经济学、教育研究方法
- 就业方向：高校/研究机构、教育行政部门、教育培训机构、出版社/教育媒体
- 典型岗位：高校教师（需要博士）、教育研究员（10-20k）、教育机构产品经理（12-25k）、考公
- 考研率：约50-60%
- 红绿牌：绿牌（稳定，但薪资不高）
- 开设院校TOP10：北师大、华东师大、东北师大、华中师大、陕西师大、南京师大、华南师大、浙江大学
- 家长常见问题：
  - 毕业只能当老师吗？不是，但主要是教育相关行业
  - 薪资待遇怎么样？体制内稳定但薪资一般，教育机构可能更高
  - 和师范类专业有什么区别？教育学偏理论，师范专业偏教学技能
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
