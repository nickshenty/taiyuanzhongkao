# 口腔医学
- 学科门类：医学
- 学制：5年/5+3一体化/8年制
- 选科要求：物理+化学+生物（多数院校要求物化生）
- 学什么：口腔颌面外科学、口腔内科学、口腔修复学、口腔正畸学、口腔解剖生理学、牙体牙髓病学
- 就业方向：口腔医院、综合医院口腔科、口腔诊所（自主创业）、口腔医疗器械企业
- 典型岗位：口腔住院医师（8-15k）、主治医师（15-25k）、口腔科主任（25k+）、口腔诊所创业者
- 考研率：约70-80%
- 红绿牌：绿牌（收入可观，创业门槛相对较低）
- 开设院校TOP10：北大、川大华西、空军军医大、上海交大、复旦、武大、中山、浙大、南医大、首医大
- 家长常见问题：
  - 口腔医学比临床医学好吗？各有优势，口腔医患关系更简单，可自主创业
  - 分低能学口腔吗？可以考虑地方医学院，但就业竞争力不同
  - 正畸和种植牙收入高吗？是的，专科医生收入可达50万+
- 数据来源：教育部《普通高等学校本科专业目录》
