# 土木工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理（部分院校要求化学）
- 学什么：土木工程材料、理论力学、材料力学、结构力学、混凝土结构设计、钢结构设计、土力学与地基基础
- 就业方向：建筑设计院、施工企业（中建中铁中交）、房地产企业、监理单位、考公
- 典型岗位：结构工程师（10-20k）、施工员（8-15k）、造价工程师（10-20k）、项目经理
- 考研率：约30-40%
- 红绿牌：黄牌（房地产下行，竞争加剧）
- 开设院校TOP10：同济、东南、清华、浙大、重大、天大、华南理工、哈工大、中南大学、湖南大学
- 家长常见问题：
  - 土木是不是夕阳专业？传统房建在萎缩，但基建、新基建仍有需求
  - 工资怎么样？施工企业起步还行，但工作环境艰苦
  - 女生适合吗？不建议，施工一线工作环境对女生不友好
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
