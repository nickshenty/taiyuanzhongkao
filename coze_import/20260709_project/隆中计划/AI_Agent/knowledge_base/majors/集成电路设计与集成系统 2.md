# 集成电路设计与集成系统
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：数字集成电路设计、模拟集成电路设计、Verilog HDL硬件描述语言、芯片版图设计、FPGA开发
- 就业方向：华为海思、寒武纪、平头哥等芯片设计企业、中芯国际等晶圆厂、研究所
- 典型岗位：数字IC设计工程师（30-60k）、模拟IC设计工程师（30-55k）、版图工程师（15-25k）
- 考研率：约60-70%
- 红绿牌：绿牌（芯片国产化核心专业）
- 开设院校TOP10：清华、北大、复旦、上交、浙大、电子科大、西电、成电、东南大学、北航
- 家长常见问题：
  - 和微电子有什么区别？集成电路更侧重设计，微电子更侧重器件和工艺
  - 需要读研吗？强烈建议，芯片设计需要硕士以上
  - 薪资为什么这么高？芯片是国家战略，人才供不应求
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
