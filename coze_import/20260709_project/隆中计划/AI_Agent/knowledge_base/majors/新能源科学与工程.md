# 新能源科学与工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：新能源原理、太阳能光伏技术、风力发电技术、生物质能、储能技术、新能源材料
- 就业方向：新能源企业（隆基绿能、宁德时代、比亚迪）、电网公司、电力设计院、研究院
- 典型岗位：光伏系统工程师（12-25k）、储能工程师（15-30k）、风电工程师（12-25k）、研发工程师
- 考研率：约45-55%
- 红绿牌：绿牌（双碳战略带动发展）
- 开设院校TOP10：清华、浙大、西安交大、华中科技大学、东南大学、北京理工大学、厦门大学、河海大学
- 家长常见问题：
  - 新能源是不是朝阳产业？是，国家双碳战略推动行业发展
  - 女生适合吗？适合，研发和设计岗位男女皆可
  - 就业地区集中吗？集中在西部（光伏、风电）和东部沿海
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
