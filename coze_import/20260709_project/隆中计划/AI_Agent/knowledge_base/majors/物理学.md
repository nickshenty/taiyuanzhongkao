# 物理学
- 学科门类：理学
- 学制：4年
- 选科要求：物理
- 学什么：力学、热学、光学、电磁学、原子物理学、理论力学、量子力学、电动力学、数学物理方法
- 就业方向：高校/科研院所、半导体/电子行业、新能源行业、光电技术企业、华为/中兴等
- 典型岗位：高校研究员（需要博士）、半导体工程师（15-30k）、光学工程师（12-25k）、物理教师
- 考研率：约55-65%
- 红绿牌：绿牌（深造后出路广）
- 开设院校TOP10：北大、清华、复旦、中科大、上交、浙大、南京大学、中山大学、南开大学、武大
- 家长常见问题：
  - 物理学难吗？难，需要数学基础和抽象思维
  - 毕业只能当老师吗？不是，半导体、光电、新能源都需要物理人才
  - 光学工程方向怎么样？光学设计、光纤通信、激光技术等方向就业不错
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
