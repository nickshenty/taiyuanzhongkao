# 软件工程
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：软件工程导论、面向对象程序设计、软件架构、数据库系统、Web开发、移动应用开发、云计算
- 就业方向：互联网企业、软件开发公司、金融科技企业、政府机关IT部门
- 典型岗位：Java开发工程师（15-30k）、前端工程师（12-28k）、全栈工程师（18-35k）、测试工程师
- 考研率：约25-35%
- 红绿牌：绿牌（就业率高，但初级岗位竞争激烈）
- 开设院校TOP10：清华、北大、浙大、国防科大、北航、哈工大、电子科大、华科、复旦、同济
- 家长常见问题：
  - 软件工程和计算机区别？软件工程更侧重软件开发过程和管理，计算机更侧重理论和底层
  - 学费为什么贵？部分高校有高收费专业，注意区分
  - 培训班出来能找到工作吗？能，但学历是敲门砖，大厂普遍要求本科以上
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
