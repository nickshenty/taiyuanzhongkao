# 自动化
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：自动控制原理、现代控制理论、PLC编程、过程控制、运动控制、机器人技术、人工智能
- 就业方向：工业自动化、智能制造、机器人企业、电力系统、航空航天、石油化工
- 典型岗位：自动化工程师（12-25k）、控制算法工程师（20-40k）、机器人工程师（18-35k）、PLC工程师
- 考研率：约40-50%
- 红绿牌：绿牌（智能制造是国家战略方向）
- 开设院校TOP10：清华、浙大、北航、华科、哈工大、上交、西交、成电、东南、东北大学
- 家长常见问题：
  - 自动化和电气有什么区别？自动化侧重控制算法和系统集成，电气侧重电力系统
  - 自动化是不是万金油？是的，专业覆盖面广，但不够精深
  - 就业前景如何？智能制造、工业4.0带动需求持续增长
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
