# 信息安全
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：网络安全基础、密码学、计算机病毒防治、防火墙技术、入侵检测技术、Web安全、网络攻防
- 就业方向：网络安全企业（360、奇安信等）、银行金融IT、互联网企业安全部门、政府机关网安部门
- 典型岗位：安全工程师（15-30k）、渗透测试工程师（20-40k）、安全运维工程师（12-25k）、安全研究员
- 考研率：约40-50%
- 红绿牌：绿牌（网络安全法实施带动需求）
- 开设院校TOP10：信工大（国家特色网安学院）、北大、清华、复旦、上交、浙大、北航、电子科大、西电
- 家长常见问题：
  - 黑客是不是这个专业？是，但正向黑客指的是白帽子，网络安全需要
  - 会不会很容易被抓？不，正当的网络安全工作是合法的
  - 女生适合吗？适合，安全岗位男女比例相对均衡
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
