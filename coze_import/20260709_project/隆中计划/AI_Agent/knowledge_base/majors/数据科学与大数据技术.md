# 数据科学与大数据技术
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起要求）
- 学什么：概率论与数理统计、数据结构与算法、机器学习、数据挖掘、大数据技术架构、Hadoop、Spark
- 就业方向：互联网企业、金融机构、咨询公司、政府机关数据部门
- 典型岗位：数据分析师（12-25k）、数据工程师（18-35k）、数据科学家（30-60k）、算法工程师
- 考研率：约50-60%
- 红绿牌：绿牌（数字化转型带动需求）
- 开设院校TOP10：清华、北大、浙大、复旦、上交、华科、电子科大、北航、哈工大、中科大
- 家长常见问题：
  - 数据科学和大数据有什么区别？数据科学更偏向算法和建模，大数据偏向技术架构
  - 需要编程能力吗？需要，Python、SQL是基础
  - 金融行业需要吗？需要，金融科技正在大量招聘数据人才
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
