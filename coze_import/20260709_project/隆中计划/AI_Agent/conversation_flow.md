## 特殊流程处理

### 流程A：信息不完整时的追问

```
用户提问 → 检测信息缺失 → 针对性追问

例如：
用户: "我能上什么大学？"
系统: "好的！为了给您更准确的建议，请告诉我："
     "1. 您孩子是哪个省份？"
     "2. 是文科还是理科/物理类还是历史类？"
     "3. 高考分数或省排名是多少？"
     
用户回复后 → 继续流程
```

### 流程B：问题过于复杂

```
用户问题 → 识别为复杂问题 → 分步处理或引导付费

例如：
用户: "帮我分析一下我孩子适合什么专业和学校，要考虑到就业前景..."

系统: "您提出了一个很好的问题！专业和学校的选择确实需要综合考虑多方面因素。
      让我先帮您梳理一下核心思路：
      1. 首先需要了解孩子的兴趣和性格特点
      2. 然后结合分数确定可选的院校层次
      3. 最后根据专业实力和就业情况筛选
      
      方便的话，我们可以一步步来：
      您孩子有哪些学科比较擅长？或者对哪些领域比较感兴趣？"
```

### 流程C：用户情绪波动

```
检测用户情绪 → 情绪应对 → 调整回复策略

焦虑型:
"我很担心滑档..."
→ "我理解您的心情...让我们一起来制定一个合理的志愿方案，降低风险。"

急切型:
"快点告诉我！"
→ "好的，马上为您查询！先告诉您最关键的结论：..."

质疑型:
```
