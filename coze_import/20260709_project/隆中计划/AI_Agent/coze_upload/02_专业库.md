# 专业知识库

# 临床医学
- 学科门类：医学
- 学制：5年/5+3一体化/8年制（本博连读）
- 选科要求：物理+化学+生物（多数院校要求物化生）
- 学什么：人体解剖学、生理学、病理学、内科学、外科学、妇产科学、儿科学、诊断学
- 就业方向：各级医院（住院医师→主治医师→主任医师）、医学研究机构、医药企业（临床监查员）
- 典型岗位：住院医师（8-15k）、主治医师（15-30k）、主任医师（30k+）、医学研究员
- 考研率：基本100%（必须深造才有出路）
- 红绿牌：绿牌（稳定但培养周期长）
- 开设院校TOP10：协和、北大、复旦、上交、浙大、川大华西、中山、同济、武汉大学、华科同济
- 家长常见问题：
  - 5年制、5+3、8年制怎么选？8年制最高可直接博士，但录取分最高；5+3本硕连读性价比高
  - 医生收入怎么样？初级医生收入一般，主任医师收入可观，但需要熬10-15年
  - 医患矛盾严重吗？确实存在，但可通过良好沟通缓解，大多数患者是理解的
- 数据来源：教育部《普通高等学校本科专业目录》

# 人工智能
- 学科门类：工学
- 学制：4年
- 选科要求：物理+化学（2025年起普遍要求）
- 学什么：机器学习、深度学习、自然语言处理、计算机视觉、机器人学、知识图谱、强化学习
- 就业方向：AI算法工程师、机器学习工程师、NLP工程师、CV工程师、AI产品经理、研究院
- 典型岗位：AI算法工程师（30-60k）、机器学习工程师（25-50k）、深度学习工程师（30-55k）
- 考研率：约60-70%（高学历需求）
- 红绿牌：绿牌（2025年就业落实率96.5%，最高薪专业之一）
- 开设院校TOP10：清华、北大、浙大、上交、哈工大、南大、电子科大、北航、华科、中科大
- 家长常见问题：
  - 人工智能是不是泡沫？技术仍在快速发展期，需求持续增长，但竞争也在加剧
  - 本科直接就业还是考研？建议考研，AI岗位普遍要求硕士以上
  - 和计算机专业有什么区别？AI更侧重算法和模型，计算机更侧重系统开发
- 数据来源：麦可思研究院《2025年中国本科生就业报告》

# 会计学
- 学科门类：管理学
- 学制：4年
- 选科要求：不限（部分院校要求物理或历史）
- 学什么：基础会计、财务会计、成本会计、管理会计、财务管理、审计学、税法、会计信息系统
- 就业方向：会计师事务所（四大、八大）、企业财务部门、银行、税务机关、考公
- 典型岗位：审计员（6-12k）、会计（6-12k）、财务分析师（10-20k）、CPA持证人（15-50k）
- 考研率：约20-30%
- 红绿牌：绿牌（企业刚需，稳定）
- 开设院校TOP10：厦大、人大、上财、中山、央财、复旦、北大、清华、上交、西南财经
- 家长常见问题：
  - 会计是不是会被人工智能取代？基础核算可能受影响，但财务分析、管理会计难以取代
  - CPA很难考吗？通过率约20%，需要3-5年才能考完
  - 女生学会计好吗？适合，工作稳定，适合细心的人
- 数据来源：麦可思研究院《2025年中国本科生就业报告》
