## 一、哲学（01）

### 核心专业
| 专业代码 | 专业名称 | 修业年限 |
|:---:|:---|:---:|
| 010101 | 哲学 | 四年 |
| 010102 | 逻辑学 | 四年 |
| 010103K | 宗教学 | 四年 |
| 010104 | 伦理学 | 四年 |

### 核心课程
- 中国哲学史、西方哲学史、马克思主义哲学原理
- 逻辑学、宗教学、伦理学、美学原理

### 就业方向
- 党政机关（公务员）
- 教育机构（高校、中学）
- 媒体与出版
- 企业管理/咨询

### 典型岗位
| 岗位类型 | 占比 |
|:---|:---:|
| 公务员/事业单位 | 35% |
| 教育科研 | 25% |
| 媒体出版 | 15% |
| 企业管理 | 20% |
| 其他 | 5% |

### 平均薪资范围
- 应届生：5000-7000元/月
- 5年经验：8000-15000元/月

### 考研率
- 约40%-50%（较高）

### 特色标签
> 冷门高雅、深造率高、考公优势

## 三、法学（03）

### 核心专业
| 专业代码 | 专业名称 | 修业年限 | 就业预警 |
|:---:|:---|:---:|:---:|
| 030101K | 法学 | 四年 | 🔴红牌 |
| 030102T | 知识产权 | 四年 | 绿牌 |
| 030301 | 社会学 | 四年 | |
| 030302 | 社会工作 | 四年 | |
| 030601K | 治安学 | 四年 | |

### 各专业详解

#### 📌 法学
**学什么：** 民法、刑法、宪法、行政法、商法、知识产权法、民事诉讼法、刑事诉讼法

**就业方向：**
- 律师事务所（律师）
- 法院、检察院（法官、检察官）
- 公安机关、监狱
- 企业法务部门
- 公证处、仲裁机构

**平均薪资：** 应届生5000-8000元/月（实习律师）；资深律师年薪30-100万+

**⚠️ 就业预警：** 连续5年红牌专业
- 法考通过率低（约15%）
- 开设院校多（600+所），毕业生规模庞大（10万+/年）
- 就业竞争激烈

**考研率：** 25%-35%

---

#### 📌 知识产权
**学什么：** 知识产权法、专利法、商标法、著作权法、知识产权管理、知识产权诉讼

**就业方向：**
- 知识产权局、专利局
- 律师事务所知识产权部
- 企业知识产权部门
- 知识产权代理机构

**平均薪资：** 应届生6000-10000元/月
