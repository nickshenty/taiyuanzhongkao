# 山西省中考政策汇总

> **数据截止日期**：2026年6月  
> **数据来源**：山西省教育厅、山西省招生考试管理中心、太原市教育局、朔州市教育局

---

## 一、山西省中考制度概述

### 1.1 考试科目与分值（2025年）

2025年是山西省中考改革落地年，中考总分由原来的730分调整为**850分**。

| 考试科目 | 初二年级考试 | 初三年级考试 | 分值 |
|---------|------------|------------|-----|
| 语文 | - | ✓ | 120分 |
| 数学 | - | ✓ | 120分 |
| 外语 | - | ✓ | 120分 |
| 道德与法治 | - | ✓ | 75分 |
| 历史 | - | ✓ | 75分 |
| 物理 | - | ✓ | 80分 |
| 化学 | - | ✓ | 70分 |
| 体育（统一测试） | - | ✓ | 60分 |
| 生物学 | ✓ | - | 50分 |
| 地理 | ✓ | - | 50分 |
| 信息技术 | ✓ | - | 15分 |
| 生物实验操作 | ✓ | - | 4分 |
| 物理实验操作 | - | ✓ | 6分 |
| 化学实验操作 | - | ✓ | 5分 |
| **总分** | - | - | **850分** |

### 1.2 2026年起考试科目调整

根据山西省教育厅2025年9月发布的《关于调整初中学业水平考试部分事项的通知》，从**2025年秋季学期升入初二年级的学生**开始实施新政策：

| 科目类型 | 科目 | 分值 | 成绩呈现 | 升学使用 |
|---------|------|------|---------|---------|
| **考试科目** | 语文、数学、外语、物理、化学、历史、道德与法治、体育 | 不变 | 分数 | 用于毕业和升学 |
| **考查科目** | 生物学、地理 | 不变 | A/B/C/D等级 | 毕业认定，升学参考 |
| **考核科目** | 信息科技、理化生实验操作、艺术 | - | 合格/不合格 | 毕业，升学参考 |

**调整后总分**：720分

### 1.3 考试方式变化

- **历史**：由闭卷改为**开卷考试**，与道德与法治同场合卷进行
- **外语听力**：鼓励有条件的市逐步实施机考
- **体育**：统一测试60分不变，各市可增加过程性测试分值

## 四、近年政策变化

### 4.1 2024年变化

- 中考总分维持730分
- 太原普高最低录取控制线：523分
- 继续实施定向生政策

### 4.2 2025年变化

- **中考总分调整为850分**（改革落地年）
- 太原普高最低录取控制线：615分
- 朔州普高最低录取控制线：420分
- 生物学、地理、信息科技等科目纳入总分计算

### 4.3 2026年变化（预计）

- **中考总分调整为839分**（总分不变，科目调整）
- 8个考试计分科目（语文、数学、外语、物理、化学、历史、道德与法治、体育）
- 历史开卷考试
- 生物学、地理改为考查科目
- 信息科技、理化生实验操作、艺术改为考核科目

### 5.2 注意事项

1. **收费标准较高**：民办高中收费普遍高于公办，需提前了解学费标准

4. **学籍管理**：被录取后统一注册学籍

## 八、注意事项

1. **志愿填报系统关闭后不得更改**：以网上填报的志愿为准
2. **录取后不得退档**：被录取后不能参加其他学校录取
3. **未参加中考不能录取**：必须参加中考并填报志愿
4. **谨防诈骗**：不要轻信任何承诺，录取以官方公布为准
5. **保护密码**：妥善保管报名号、登录密码，防止被篡改志愿
