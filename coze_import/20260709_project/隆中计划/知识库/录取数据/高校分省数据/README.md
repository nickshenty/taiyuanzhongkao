## 文件命名规范

- 文件命名格式：`学校简称_分省录取数据.md`
- 每校一个独立文件

## 数据格式说明

每个数据文件包含以下统一结构：

1. **标题**：`# [学校全称] 分省录取分数线数据`
2. **数据来源**：列出数据来源的URL链接
3. **数据年份**：数据对应的高考年份
4. **覆盖省份**：数据覆盖的省份数量
5. **数据表格**：
   - `一、传统高考地区录取分数线`：适用于河南、四川、山西等未实施新高考的省份
   - `二、新高考3+3模式省份录取分数线`：适用于北京、上海、浙江、山东、天津、海南
   - `三、新高考3+1+2模式省份录取分数线`：适用于河北、辽宁、江苏、广东等省份
6. **表格列**：省份 | 批次 | 科类/选科要求 | 最低分 | 最低位次

## 注意事项

- 数据以各高校官方招生网发布为准，本文件仅供参考
- 部分省份2024年已实施新高考改革，传统高考与新模式数据可能并行存在
- 位次数据部分省份官方未公布，标注为"-"
- 2025年高考录取数据陆续发布中，后续将更新
