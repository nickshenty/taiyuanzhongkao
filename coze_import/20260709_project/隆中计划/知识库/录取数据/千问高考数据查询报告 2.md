# 千问高考数据查询报告

> 调研日期：2026-07-02
> 调研目标：评估通义千问（Qwen）高考志愿填报功能作为录取数据源的可行性

---

## 一、千问高考功能概述

### 1.1 产品定位
千问高考志愿填报 Agent 是阿里巴巴旗下千问（原通义千问）于 2026年6月10日正式上线的**全周期高考志愿填报智能体**，面向全国考生**完全免费**开放。

- **联合发布方**：千问 + 新华社 + 半月谈
- **技术底座**：千问高考志愿大模型（基于 Qwen 大模型微调）
- **数据积淀**：融合夸克 8 年高考服务经验（2017-2024），累计服务超 1.6 亿考生和家长
- **2026年规模**：上线 5 天生成 1500 万份免费报告，超 1400 万用户使用

### 1.2 功能入口

| 终端 | 入口方式 |
|------|---------|
| **PC 网页端** | 访问 `qianwen.com`，搜索框输入"高考志愿填报"触发 |
| **手机 App** | 千问 App 首页底部"千问高考"按钮 |
| **PC 旧入口** | `tongyi.aliyun.com`（旧域名，逐步迁移至 qianwen.com） |

### 1.3 三大核心功能

1. **AI 志愿日历**：根据省份、选科、估分、兴趣，定制专属填报时间线，拆解为每日待办
2. **AI 志愿报告**：生成 15-40 页 PDF 报告，含冲稳保三梯度院校推荐、历年分数线、录取概率、就业前景
3. **AI 志愿问答**：多轮对话式咨询，支持逐步细化需求

## 三、数据获取方式评估

### 3.1 交互方式：纯对话式，无结构化 API

千问高考功能**不提供公开的结构化数据 API**，数据获取方式仅有：

1. **对话式查询**（主要方式）
   - 通过自然语言提问获取信息
   - 支持多轮对话、上下文记忆
   - 输出为非结构化文本 + 可视化卡片

2. **PDF 报告导出**
   - 生成 15-40 页完整志愿报告
   - 包含院校、专业、分数线等结构化内容
   - 但输出格式为 PDF，需额外解析才能获取结构化数据

3. **可视化数据卡片**
   - 院校对比表、专业薪资排名、位次趋势图等
   - 仅在前端展示，无法直接导出

### 3.2 无公开 API 的原因
- 千问定位为**面向 C 端考生的免费服务**，非数据供应商
- 数据来源为夸克积累 + 各省考试院公开数据 + 合作机构数据
- 数据使用受到合作方约束，不适合以 API 形式对外开放
- 阿里夸克曾有第三方高考数据 API（阿里云市场），但与千问高考 Agent 非同一产品

### 3.3 可能的数据获取路径

| 方式 | 可行性 | 难度 | 说明 |
|------|--------|------|------|
| 对话式查询 | ✅ 可行 | 低 | 逐校逐专业查询，效率极低 |
| PDF 报告解析 | ⚠️ 有限 | 中 | 需自动化生成+OCR/解析 |
| 批量自动化爬取 | ❌ 不可行 | 极高 | 需登录态，有反爬机制 |
| 第三方数据 API | ⚠️ 可探索 | 中 | 阿里云市场有类似高考数据 API（如咕咕数据等），非千问官方 |

## 四、示例查询结果

### 4.1 典型查询场景

**查询示例**："我是山东考生，高考 620 分，位次 8000 左右，想学计算机相关专业"

**千问输出内容**：
- 冲档院校 3-5 所：标注往年最低录取分、位次
- 稳妥院校 3-5 所：同上
- 保底院校 3-5 所：同上
- 每所院校附：专业选科限制、学科评估、就业方向
- 风险提示：调剂风险、单科要求等

### 4.2 数据粒度评估

| 查询层级 | 数据粒度 | 可用性 |
|---------|---------|--------|
| 院校级投档线 | ✅ 精确 | 985/211 准确率高 |
| 分专业录取分 | ✅ 可查 | 热门专业较准确 |
| 分省分专业 | ✅ 可查 | 需指定省份+院校+专业 |
| 趋势数据 | ✅ 可查 | 多年位次变化趋势 |
| 招生计划变动 | ⚠️ 有限 | 最新年度可能未及时更新 |

## 五、作为长期数据源的评估

### 5.1 优势

| 优势 | 详细说明 |
|------|---------|
| **数据积累深** | 8 年连续数据，覆盖 2017-2024，趋势分析价值高 |
| **覆盖面广** | 近 3000 所高校、2000+ 专业，全国 31 省全覆盖 |
| **权威背书** | 新华社、半月谈合作，数据来源为各省考试院公开数据 |
| **持续更新** | 阿里专门投资数据治理公司维护，每年持续更新 |
| **免费稳定** | 连续 8 年免费，承诺不收费，产品稳定性高 |
| **多维数据** | 除分数线外，还含就业、考研、考公等延伸数据 |

### 5.2 劣势

| 劣势 | 详细说明 |
|------|---------|
| **无结构化 API** | 仅对话式交互，无法批量获取数据 |
| **数据偏差风险** | 地方院校/长尾数据准确性不足，位次可差数千 |
| **更新时效性** | 最新年度招生计划可能延迟同步 |
| **不可编程化** | 无法通过 API 自动查询，需人工交互或解析 PDF |
| **使用限制** | 非填报季（高考前后）功能可能降级或入口不明显 |
| **数据不可直接导出** | PDF 报告需二次解析才能获取结构化数据 |

### 5.3 可行性结论

| 评估维度 | 评分 | 说明 |
|---------|------|------|
| 数据质量 | ⭐⭐⭐⭐ | 985/211 数据准确，长尾数据有偏差 |
| 数据维度 | ⭐⭐⭐⭐⭐ | 覆盖分数线、位次、专业、就业等多维度 |
| 获取便利性 | ⭐⭐ | 无 API，仅对话式查询，难以批量化 |
| 长期稳定性 | ⭐⭐⭐⭐ | 阿里持续投入，免费策略稳定 |
| 自动化可行性 | ⭐⭐ | 无公开接口，自动化采集难度大 |
| 数据权威性 | ⭐⭐⭐⭐ | 官方合作背书，但非第一手数据源 |

### 5.4 综合评估

**千问高考作为数据源的总体评价：辅助验证渠道，非主力数据源**

- ✅ **适合做**：数据交叉验证、补充就业/考研等延伸信息、趋势分析参考
- ❌ **不适合做**：主力结构化数据源（无法批量获取）、权威数据引用（需二次核实）
- 💡 **建议用法**：
  1. 作为**辅助验证渠道**，与阳光高考平台、各省考试院数据交叉比对
  2. 利用其**就业、考研、考公**等延伸数据补充知识库
  3. 对于 985/211 高校数据可直接参考，地方院校数据需核实
  4. 如需结构化数据，建议探索阿里云市场的第三方高考数据 API
