### ⚗️ 化学：巩固1-2(正式)：氧化还原反应规律

**概念复习**

氧化还原反应的规律总结：①守恒规律（得失电子总数相等）；②强弱规律（强氧化剂+强还原剂→弱氧化剂+弱还原剂）；③归中规律（同种元素不同价态反应趋向中间价态）；④歧化规律（中间价态→高价+低价）。掌握常见氧化剂和还原剂的强弱顺序，能判断反应能否发生。

**化学方程式**

1. 归中反应：2H₂S + SO₂ → 3S↓ + 2H₂O
2. 歧化反应：Cl₂ + 2NaOH → NaCl + NaClO + H₂O
3. 强弱判断：Fe + CuSO₄ → FeSO₄ + Cu（Fe还原性>Cu）
4. 电子守恒配平：3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

**关键要点**

1. 守恒规律：失电子总数 = 得电子总数
2. 强弱规律：强氧化剂+强还原剂→弱氧化产物+弱还原产物
3. 归中规律：同元素高低价态→中间价态（不交叉）
4. 歧化反应：Cl₂+H₂O→HCl+HClO（同元素自身氧化还原）
5. 常见氧化剂：KMnO₄、HNO₃、Cl₂、O₂；常见还原剂：Na、H₂、C、CO

**作业练习指导**

今日正式完成巩固1-2后半部分（氧化还原反应规律）。做题步骤：①守恒规律——得失电子总数相等；②强弱规律——强氧化剂+强还原剂→弱产物；③归中规律——同元素不同价态趋向中间价态（不交叉）；④歧化反应——中间价态→高价+低价。重点练习：氧化还原配平、反应方向判断。建议限时完成。

**易错提醒**

1. 归中反应中价态'交叉'：产物价态不会超过反应物价态范围
2. 歧化反应中同种元素既是氧化剂又是还原剂
3. 判断反应方向时忘记使用强弱规律

### ⚡ 物理：抛体运动2：平抛运动进阶

**概念复习**

平抛运动进阶讨论更复杂的情境：不同抛出点的平抛比较、半圆环上的平抛碰撞、跳台滑雪中的平抛运动等。关键要点：两个平抛物体同时抛出时，落地时间差由高度差决定；落到斜面上时，运动时间与斜面角度和初速度有关；在半圆环上的平抛，小球落点位置与初速度大小有关，v₀越大可能落到更高位置。分析时要善于利用几何关系建立方程。平抛进阶问题的核心在于灵活运用几何关系，将曲面、圆环等约束转化为运动方程。半圆环上平抛时v₀越大落点越高，但小球不可能垂直撞击圆环。

**公式**

1. 落到斜面：tanθ = ½gt² / (v₀t) = gt/(2v₀)
2. 圆环碰撞条件：x² + (R-y)² = R²

**关键要点**

1. 同时抛出的平抛，时间差由高度差决定
2. 落到斜面上的平抛，利用tanθ=y/x建立方程
3. 半圆环平抛：v₀不同落点不同，落到最低点C时间最长
4. 小球不可能垂直撞击半圆环（速度方向不沿半径）
5. v₀足够大时小球可能不落在圆环上

**作业练习指导**

今日做物理作业2的单选题部分。做题要点：①比较两个平抛运动时，先确定时间关系（由高度决定）；②落到圆环或曲面上的问题，利用几何方程（圆方程）联立运动方程；③注意"不可能"类题目可用极端情况分析。重点练习半圆环平抛和跳台滑雪问题。

**易错提醒**

1. 认为v₀越大运动时间越长（在斜面上时间与v₀有关，但在水平面上无关）
2. 半圆环问题中忽略圆的几何约束
3. 忘记验证物理量的合理性

## 📜 语文古诗文

### 蜀相
**唐　· 杜甫**

**原文**

> 丞相祠堂何处寻？锦官城外柏森森。
> 映阶碧草自春色，隔叶黄鹂空好音。
> 三顾频烦天下计，两朝开济老臣心。
> 出师未捷身先死，长使英雄泪满襟。

**译文**

> 诸葛丞相的祠堂到哪里去寻找？在锦官城外柏树茂密的地方。
> 映照台阶的碧草独自焕发着春色，隔着树叶的黄鹂空有美妙的啼叫。
> 刘备三顾茅庐频繁地请教天下大计，辅佐两朝开创基业是老臣的一片忠心。
> 出师还没有取得胜利就先去世了，长久地使英雄们泪湿衣襟。

**注释**

- **锦官城** → 成都的别称
- **柏森森** → 柏树茂盛高大的样子
- **自春色** → 独自焕发春色
- **空好音** → 徒然发出美妙的叫声
- **三顾** → 刘备三顾茅庐请诸葛亮出山
- **频烦** → 多次烦劳、频繁地请教
- **两朝** → 刘备、刘禅两朝
- **开济** → 开创基业、匡济艰危
- **出师未捷** → 出师伐魏还没有取得胜利
- **满襟** → 沾满衣襟

**背诵要点**

1."出师未捷身先死，长使英雄泪满襟"——千古名句，咏叹诸葛亮壮志未酬；2."三顾频烦天下计，两朝开济老臣心"——高度概括诸葛亮一生功业；3."映阶碧草自春色，隔叶黄鹂空好音"——"自""空"二字为诗眼，写祠堂冷落；4.注意"频烦"不要写成"频繁"
