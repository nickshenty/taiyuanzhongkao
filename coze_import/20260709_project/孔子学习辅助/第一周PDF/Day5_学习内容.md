### 🔢 数学：平面向量：向量应用（综合应用）

**概念复习**

向量的应用主要包括：①几何应用——证明平行、垂直、共线等问题；②物理应用——力的合成与分解、速度的合成等；③坐标应用——利用坐标运算解决距离、角度问题。常见题型：利用向量证明三角形中线、高线性质，利用数量积求面积，用向量解决物理中的力/速度问题。关键是将几何/物理问题转化为向量语言。

**公式**

1. 三角形面积：S = ½|a||b|sinθ
2. 重心坐标：G = (A+B+C)/3
3. 中线向量：若D为BC中点，则AD→ = (AB→+AC→)/2

**关键要点**

1. 几何应用：证平行(a∥b)、证垂直(a·b=0)、证共线(b=λa)
2. 物理应用：力的合成(平行四边形)、速度分解
3. 利用数量积求三角形面积：S=½|a||b|sinθ=½√(|a|²|b|²-(a·b)²)
4. 重心公式：G = (A+B+C)/3
5. 向量法证明几何题：设向量→运算→得出结论

**作业练习指导**

今日做平面向量专题的「向量应用」综合题。做题步骤：①几何应用先设向量再运算；②物理应用注意力的合成用平行四边形；③面积公式S=½|a||b|sinθ。重点练习：三角形应用（中线、重心）、坐标综合题。建议：先做教材例题，再做课外提升题。

**易错提醒**

1. 向量证明时设坐标不当导致计算复杂
2. 应用题中向量方向搞反
3. 忘记验证向量非零的前提条件

### ⚡ 物理：平抛运动计算与综合练习

**概念复习**

平抛运动的计算需要灵活运用水平和竖直两个方向的分运动公式。常见题型包括：从斜面上抛出落到斜面上（利用tanθ=y/x建立方程）、平抛打到竖直墙面（水平距离=水平速度×时间）、空中相遇问题（两物体同时到达同一位置）。关键技巧：遇到斜面问题时，用tanθ=y/x=gt/(2v₀)建立角度与运动参数的关系；遇到相遇问题时，利用等时性和位置重合条件列方程。计算题中遇到斜面、墙面、相遇等情境时，关键是找到几何约束条件并转化为运动方程。

平抛运动综合练习涵盖多种情境：渡河问题（船速与水速合成）、投靶问题（箭的水平射出与靶的命中条件）、无人机加速度传感器分析等。渡河问题中，船的实际运动是船速和水速的合成，最短渡河时间条件是船头垂直于河岸，此时t=d/v船；最短渡河路径条件是合速度垂直于河岸。投靶问题需要同时满足水平方向到达靶位和竖直方向到达靶高的条件。渡河问题和投靶问题都需要分解为两个独立方向的运动，利用等时性联立求解。加速度传感器图像题要逐时间段分析各轴加速度方向，判断超重失重状态。

**公式**

1. 斜面角度关系：tanθ = gt/(2v₀)
2. 合速度大小：v = √(v₀² + (gt)²)
3. 落地点到抛出点距离：s = √(x² + y²)
4. 最短渡河时间：t_min = d / v船
5. 合速度：v合 = √(v船² + v水² - 2v船·v水·cosα)

**关键要点**

1. 斜面问题：用tanθ=y/x=gt/(2v₀)建立方程
2. 竖直墙面问题：水平距离=v₀×t
3. 相遇问题：利用等时性+位置重合条件
4. 速度反向延长线交于水平位移中点
5. 烟花弹爆炸后碎片做平抛运动
6. 渡河最短时间：船头垂直河岸，t=d/v船
7. 渡河最短路径：合速度垂直河岸（需v船>v水）
8. 投靶命中条件：水平到达+竖直到达同时满足
9. 加速度传感器：分解到各轴分析运动状态
10. 失重条件：加速度方向竖直向上为超重，向下为失重

**作业练习指导**

今日做物理作业1的解答题。计算题解题步骤：①建立坐标系（水平x、竖直y）；②分别列水平和竖直方向方程；③利用题目约束（斜面角度、墙面距离、相遇条件）联立求解。重点练习：斜面平抛、空中拦截、风洞问题。注意保留有效数字。；今日做物理作业1的综合练习题。做题策略：①渡河问题先画速度平行四边形，判断最短时间或最短路径条件；②投靶问题分别列水平方程和竖直方程联立；③传感器图像题逐时间段分析加速度方向。建议计时完成，提高解题速度。

**易错提醒**

1. 斜面上平抛问题时，误用斜面角度等于速度方向角
2. 相遇问题中忘记检查时间是否合理（t>0）
3. 计算合速度时忘记平方和开方
4. 渡河最短时间误认为合速度垂直河岸时
5. v船<v水时不可能垂直渡河（合速度不可能垂直于河岸）
6. 加速度方向判断超重失重时弄反

## 📜 语文古诗文

### 登高
**唐　· 杜甫**

**原文**

> 风急天高猿啸哀，渚清沙白鸟飞回。
> 无边落木萧萧下，不尽长江滚滚来。
> 万里悲秋常作客，百年多病独登台。
> 艰难苦恨繁霜鬓，潦倒新停浊酒杯。

**译文**

> 风急天高猿猴啼叫显得十分悲凉，水清沙白的江洲上有鸟儿在盘旋。
> 无边无际的树叶纷纷落下，无穷无尽的长江滚滚奔流而来。
> 离乡万里悲叹秋天我常常客居他乡，一生多病独自登临高台。
> 历尽艰难困苦只恨白发长满了双鬓，穷困潦倒连浊酒杯也新近停下了。

**注释**

- **啸哀** → 指猿的叫声凄厉悲凉
- **渚** → 水中的小块陆地
- **鸟飞回** → 鸟在急风中盘旋
- **落木** → 落叶
- **萧萧** → 草木摇落的声音
- **作客** → 客居他乡
- **百年** → 借指一生
- **繁霜鬓** → 白发增多
- **潦倒** → 衰颓、失意
- **新停** → 新近停止（因肺病戒酒）

**背诵要点**

1."无边落木萧萧下，不尽长江滚滚来"——千古名句，景象壮阔；2.全诗八句皆对仗，被称为"古今七言律诗第一"；3."万里悲秋常作客，百年多病独登台"——空间（万里）与时间（百年）对仗；4.注意"萧萧""滚滚"叠词的运用
