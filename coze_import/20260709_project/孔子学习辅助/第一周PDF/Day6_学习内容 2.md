### 🔢 数学：平面向量：向量综合应用与专题总结

**概念复习**

**公式**

1. 重心：G = (A+B+C)/3
2. 面积：S = ½|a×b| = ½|a||b|sinθ
3. 数量积范围：-|a||b| ≤ a·b ≤ |a||b|

**关键要点**

1. 三角形应用：中线向量、重心坐标、面积公式
2. 坐标综合：利用坐标将几何问题代数化
3. 最值问题：利用数量积的取值范围求最值
4. 知识体系：概念→运算→坐标→应用
5. 解题策略：设向量→列方程→求解

**作业练习指导**

### ⚗️ 化学：巩固1-2(正式)：电解质与非电解质、离子共存

**概念复习**

电解质是在水溶液中或熔融状态下能导电的化合物（如酸、碱、盐），非电解质是不能导电的化合物（如蔗糖、酒精）。强电解质完全电离（强酸、强碱、大部分盐），弱电解质部分电离（弱酸、弱碱、水）。离子共存判断：①发生复分解反应（生成沉淀/气体/水）不能共存；②发生氧化还原反应不能共存；③发生络合反应不能共存。

**化学方程式**

1. 强电解质电离：HCl → H⁺ + Cl⁻（完全电离）
2. 弱电解质电离：CH₃COOH ⇌ H⁺ + CH₃COO⁻（部分电离）
3. 离子不能共存示例：H⁺ + CO₃²⁻ → H₂O + CO₂↑
4. 氧化还原不共存：Fe³⁺与I⁻不能共存（Fe³⁺+3I⁻→Fe²⁺+I₂）

**关键要点**

1. 电解质：能导电的化合物（酸、碱、盐）
2. 非电解质：不能导电的化合物（蔗糖、酒精、CO₂等）
3. 强电解质：完全电离（强酸、强碱、大部分盐）
4. 弱电解质：部分电离（弱酸H₂CO₃/CH₃COOH、弱碱NH₃·H₂O、H₂O）
5. 离子不能共存的原因：复分解/氧化还原/络合/双水解

**作业练习指导**

今日正式完成巩固1-2前半部分（电解质与非电解质、离子共存）。做题步骤：①电解质判断：能导电的化合物（酸碱盐），CO₂/蔗糖是非电解质；②强弱判断：完全电离=强，部分电离=弱；③离子共存：先看是否生成沉淀/气体/水，再看氧化还原/双水解。重点练习：离子共存判断。建议限时完成。

**易错提醒**

1. 把CO₂、SO₂当成电解质（它们是非电解质，溶于水后的酸是电解质）
2. 混淆'难溶盐'与'非电解质'：BaSO₄难溶但仍是强电解质
3. 离子共存题忘记考虑pH条件（如酸性/碱性环境）

### ⚡ 物理：抛体运动1：检测复习

**概念复习**

抛体运动1检测复习：回顾曲线运动条件、运动合成与分解的平行四边形定则、平抛运动的两个分运动规律。重点梳理：平抛运动时间只由高度决定、速度方向角与位移方向角的关系、斜面上平抛的角度方程、渡河问题的两种最优策略。实验部分回顾探究平抛运动特点的实验要点：斜槽末端水平、坐标原点选球心、用频闪照相或Tracker软件记录轨迹。复习时要重点关注平抛实验的操作要点和误差分析，这是考试中的高频考点。实验中坐标原点应选球心位置，斜槽末端必须保持水平，这是保证实验准确的关键条件。

**公式**

1. 平抛全套公式：x=v₀t, y=½gt², v=√(v₀²+(gt)²)
2. 斜面角度：tanθ=gt/(2v₀)

**关键要点**

1. 曲线运动条件：合外力与速度不共线
2. 平抛时间t=√(2h/g)，与v₀无关
3. 速度角tanθ=gt/v₀，位移角tanα=gt/(2v₀)
4. 渡河最短时间t=d/v船，最短路径需v船>v水
5. 实验：斜槽末端水平、坐标原点选球心

**作业练习指导**

今日复习物理作业1全部内容。复习策略：①先回顾曲线运动和平抛运动的核心概念和公式；②重做错题，特别是计算题中的斜面问题和相遇问题；③检查实验题中常犯的错误（坐标原点选择、斜槽水平调节）。建议做一套检测题自测，查漏补缺。

**易错提醒**

1. 平抛时间与初速度无关，但水平射程与v₀有关
2. 实验中坐标原点应选球心而非球的上端或下端
3. 合运动与分运动等时性在相遇问题中的应用

## 📜 语文古诗文

### 客至
**唐　· 杜甫**

**原文**

> 舍南舍北皆春水，但见群鸥日日来。
> 花径不曾缘客扫，蓬门今始为君开。
> 盘飧市远无兼味，樽酒家贫只旧醅。
> 肯与邻翁相对饮，隔篱呼取尽余杯。

**译文**

> 房前屋后都被春水环绕，只见成群的鸥鸟天天飞来。
> 长满花草的小路还不曾因为客人到来而打扫过，柴门今天才第一次为你打开。
> 离集市远盘中的菜肴没有多种味道，家境贫寒杯中只有自家酿的旧酒。
> 你若愿意和隔壁老翁对饮，我就隔着篱笆呼唤他来喝尽剩余的酒。

**注释**

- **但见** → 只见到
- **缘客扫** → 因为客人到来而打扫。缘，因为
- **蓬门** → 用柴草编的门，指贫苦人家的门
- **盘飧** → 盘中的菜肴。飧，熟食
- **兼味** → 多种美味的菜肴
- **旧醅** → 隔年陈酒。醅，未过滤的酒
- **肯** → 能否，表询问
- **呼取** → 呼唤过来

**背诵要点**

1."花径不曾缘客扫，蓬门今始为君开"——名句，表现好客之情；2."盘飧市远无兼味，樽酒家贫只旧醅"——对仗工整，写待客简朴；3.注意"飧"字的写法（不要写成"餐"）；4.全诗表现诗人在草堂待客的真诚与随和
