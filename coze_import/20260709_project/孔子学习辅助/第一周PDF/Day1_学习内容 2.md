### 🔢 数学：平面向量：向量的概念与表示

**概念复习**

向量是既有大小又有方向的量，与标量（只有大小没有方向）不同。向量的表示方法有：用有向线段表示（起点→终点）、用字母表示（如a、b或AB→）。向量的大小称为向量的模，记作|a|或|AB→|。模为0的向量叫零向量（0），模为1的向量叫单位向量。平行向量（共线向量）指方向相同或相反的非零向量。相等向量要求大小和方向都相同。

**公式**

1. 向量的模：|AB→| = √((x₂-x₁)² + (y₂-y₁)²)（坐标表示）
2. 单位向量：a₀ = a / |a|（方向相同，模为1）

**关键要点**

1. 向量 = 大小 + 方向，标量只有大小
2. 向量的模|a|表示向量的大小
3. 零向量方向任意，单位向量模为1
4. 平行向量 = 共线向量（方向相同或相反）
5. 相等向量：大小和方向都相同

**作业练习指导**

今日做平面向量专题的「向量概念」部分。做题步骤：①先判断题目涉及的是向量还是标量；②画图辅助理解——用有向线段表示向量；③注意零向量方向任意、单位向量模为1的特殊性。重点练习：向量模的计算、平行向量判断、相等向量辨析。建议先完成教材例题，再做练习题。

**易错提醒**

1. 混淆向量与标量：速度是向量，速率是标量
2. 零向量方向不是'没有方向'，而是'方向任意'
3. 平行向量不一定是相等向量，方向可以相反

### ⚗️ 化学：预习巩固1-1：物质分类与分散系

**概念复习**

物质的分类是化学学习的基础。按组成可将物质分为纯净物和混合物，纯净物又分为单质和化合物。分散系是物质以微小颗粒分散到另一物质中形成的混合物，按分散质粒子大小分为溶液（<1nm）、胶体（1-100nm）和浊液（>100nm）。胶体有丁达尔效应（光束通过时形成光路），这是鉴别胶体与溶液的常用方法。

**化学方程式**

1. Fe(OH)₃胶体制备：FeCl₃ + 3H₂O △→ Fe(OH)₃(胶体) + 3HCl
2. 分类示例：Na₂O + H₂O → 2NaOH（碱性氧化物→碱）

**关键要点**

1. 物质分类：纯净物→单质/化合物→氧化物/酸/碱/盐
2. 分散系三分类：溶液、胶体、浊液（按粒子大小）
3. 胶体粒子直径：1-100nm
4. 丁达尔效应是胶体的特性，可鉴别胶体
5. 常见的胶体：Fe(OH)₃胶体、淀粉溶液、豆浆

**作业练习指导**

今日预习巩固1-1前半部分。先通读教材中物质分类和分散系内容，然后做预习练习。做题注意：①物质分类题先判断纯净物/混合物，再细分单质/化合物；②分散系判断看粒子大小——溶液<1nm，胶体1-100nm；③胶体鉴别首选丁达尔效应。建议整理物质分类思维导图后再做题。

**易错提醒**

1. 胶体不是一种物质，而是一种分散系
2. 丁达尔效应不是胶体独有的，但最常用于鉴别
3. Fe(OH)₃胶体制备时不能用NaOH，否则会生成沉淀

### 🧬 生物：选必一第1章：细胞生活的环境

**概念复习**

细胞生活的环境即内环境，主要由血浆、组织液和淋巴组成。血浆是血细胞的直接生活环境，组织液是体内绝大多数细胞的直接生活环境，淋巴是淋巴细胞和吞噬细胞的直接生活环境。三者之间的关系：血浆⇌组织液→淋巴→血浆。内环境的作用是细胞与外界环境进行物质交换的媒介。

**关键要点**

1. 内环境 = 细胞外液 = 血浆 + 组织液 + 淋巴
2. 血浆⇌组织液→淋巴→血浆（物质交换循环）
3. 血细胞生活在血浆中，大多数细胞生活在组织液中
4. 内环境是细胞与外界物质交换的媒介
5. 细胞内液≠内环境（细胞内液在细胞内部）

**作业练习指导**

今日学习选必一第1章「细胞生活的环境」。做题步骤：①先画出血浆、组织液、淋巴三者关系图；②判断物质是否属于内环境时，排除细胞内成分（如血红蛋白、呼吸酶）；③注意淋巴→血浆是单向的。重点练习：内环境成分判断、三者关系图分析。建议先完成教材课后练习。

**易错提醒**

1. 血红蛋白在红细胞内，不属于内环境成分
2. 淋巴→血浆是单向的（通过左右锁骨下静脉）
3. 消化液、尿液、汗液不属于内环境

### 📝 语文：组合练习(一)：诗歌用典理论

**概念复习**

用典是古诗词中常见的修辞手法，指在诗词中引用历史故事、神话传说或前人语句来表达思想感情。用典分为明典（直接引用，读者一看便知）和暗典（化用前人语意，不露痕迹）。用典的作用：以古证今、含蓄表达、增加文采、引发联想。分析用典时要注意：典故的出处、典故的原意、诗人的化用意图。

**关键要点**

1. 用典 = 引用历史故事/神话/前人语句来表达情感
2. 明典：直接引用，暗典：化用不露痕迹
3. 用典作用：以古证今、含蓄表达、增加文采
4. 分析步骤：找出处→明原意→析化用→悟情感
5. 用典是高考诗歌鉴赏的高频考点

**作业练习指导**

今日做组合练习(一)的用典理论部分。做题步骤：①先理解用典的定义和分类（明典/暗典）；②做选择题时先排除明显错误项；③分析题要按「手法+分析+效果+情感」模板答题。注意：用典必须有出处，区别于比喻。建议先做理论选择题，再读《喜雨》初步感知。

**易错提醒**

1. 只说出典故内容，不分析诗人化用意图
2. 混淆用典与比喻：用典必须有'出处'
3. 忽略典故与诗歌主题的关联

### ⚡ 物理：力学基础：匀变速直线运动基本概念

**概念复习**

匀变速直线运动是加速度恒定的直线运动。基本物理量：位移x、速度v、加速度a、时间t。加速度是速度变化率，a=Δv/Δt，方向与速度变化方向相同。当a与v同向时加速，反向时减速。

**关键要点**

1. 匀变速直线运动：加速度a恒定
2. 加速度a = Δv/Δt，单位m/s²
3. a与v同向→加速，a与v反向→减速
4. 位移、速度、加速度都是矢量

**作业练习指导**

今日补充学习匀变速直线运动基本概念。做练习时：①先判断运动类型（匀加速/匀减速）；②明确已知量和未知量，选择合适公式；③注意各量方向（正负号）。重点练习：加速度计算、速度方向判断。建议做2-3道基础练习题即可。

**易错提醒**

1. 加速度为负不一定代表减速
2. 速度为零时加速度不一定为零

## 📜 语文古诗文

### 静女
**先秦　· 佚名**

**原文**

> 静女其姝，俟我于城隅。爱而不见，搔首踟蹰。
> 静女其娈，贻我彤管。彤管有炜，说怿女美。
> 自牧归荑，洵美且异。匪女之为美，美人之贻。

**译文**

> 文静的姑娘真美丽，约我在城角相见。她藏起来不让我看见，我急得抓耳挠腮徘徊不前。
> 文静的姑娘真娇艳，送我一根红色的管箫。红色管箫光彩闪耀，我真喜爱你的美丽。
> 从郊野采来初生的茅草，确实美丽又奇异。并非你这茅草本身美，只因是美人送给我的。

**注释**

- **姝** → 美丽
- **俟** → 等待
- **城隅** → 城墙的角落
- **爱** → 通"薆"，隐藏、遮蔽
- **踟蹰** → 徘徊不前的样子
- **娈** → 美好
- **贻** → 赠送
- **彤管** → 红色的管箫（一说红色茅草）
- **炜** → 红色鲜亮的样子
- **说怿** → "说"通"悦"，喜爱；怿，喜爱
- **女** → 通"汝"，你
- **牧** → 野外、郊外
- **归** → 通"馈"，赠送
- **荑** → 初生的茅草
- **洵** → 确实
- **匪** → 通"非"，不是

**背诵要点**

1."说怿女美"中"说"通"悦"，"女"通"汝"；2."爱而不见"的"爱"通"薆"，意为隐藏；3."自牧归荑"的"归"通"馈"；4."匪女之为美"的"匪"通"非"；5.注意"彤管""踟蹰""搔首"等词的写法
