### 🔢 数学：平面向量：向量的线性运算

**概念复习**

向量的线性运算包括加法、减法和数乘。向量加法遵循三角形法则（首尾相接）或平行四边形法则（共起点）。减法可转化为加法：a-b = a+(-b)。数乘：实数λ与向量a的乘积λa，当λ>0时同向，λ<0时反向，λ=0时为零向量。线性运算满足交换律、结合律和分配律。

**公式**

1. 三角形法则：AB→ + BC→ = AC→
2. 坐标运算：a+b = (x₁+x₂, y₁+y₂)，λa = (λx, λy)
3. 共线定理：a∥b ↔ x₁y₂ - x₂y₁ = 0

**关键要点**

1. 加法：三角形法则（首尾相接）或平行四边形法则
2. 减法：a-b = a+(-b)，共起点连终点指向被减数
3. 数乘λa：|λa|=|λ|·|a|，λ>0同向，λ<0反向
4. 共线定理：b=λa (a≠0) ↔ a与b共线
5. 运算律：交换律a+b=b+a，分配律λ(a+b)=λa+λb

**作业练习指导**

今日做平面向量专题的「线性运算」部分。做题步骤：①加法用三角形法则或平行四边形法则，先画图再计算；②减法转化为加法a-b=a+(-b)，注意方向；③数乘注意λ正负对方向的影响。重点练习：坐标运算、共线向量判断（x₁y₂=x₂y₁）。建议先做例题掌握方法，再练综合题。

**易错提醒**

1. 减法方向搞反：a-b是从b的终点指向a的终点
2. 数乘时忘记判断λ正负对方向的影响
3. 共线判断时忘记a≠0的前提条件

### ⚗️ 化学：预习巩固1-1：离子方程式与氧化还原反应

**概念复习**

离子方程式是用实际参加反应的离子符号表示化学反应的方程式。书写步骤：一写（写化学方程式）、二拆（拆易溶于水的强电解质）、三删（删两边相同的离子）、四查（检查质量和电荷守恒）。氧化还原反应的实质是电子转移，特征是化合价变化。被氧化（化合价升高、失电子）的是还原剂，被还原（化合价降低、得电子）的是氧化剂。

**化学方程式**

1. 离子方程式示例：Ag⁺ + Cl⁻ → AgCl↓
2. 氧化还原示例：2Na + Cl₂ → 2NaCl（Na失电子被氧化）
3. 电子转移表示：2Al + 6HCl → 2AlCl₃ + 3H₂↑

**关键要点**

1. 离子方程式四步法：写→拆→删→查
2. 拆分规则：强酸、强碱、可溶盐拆，弱电解质/气体/沉淀不拆
3. 氧化还原本质：电子转移；特征：化合价变化
4. 还原剂→失电子→化合价升高→被氧化→发生氧化反应
5. 氧化剂→得电子→化合价降低→被还原→发生还原反应

**作业练习指导**

今日预习巩固1-1后半部分：离子方程式与氧化还原。做题步骤：①离子方程式严格按四步法（写→拆→删→查）；②拆分时记住：强酸强碱可溶盐拆，弱电解质/气体/沉淀不拆；③氧化还原先标化合价，再找电子转移。重点练习：离子方程式书写、氧化还原判断。建议整理常见沉淀和气体。

**易错提醒**

1. 拆分时把弱电解质（如H₂O、CH₃COOH）也拆了
2. 忘记检查离子方程式的电荷守恒
3. 混淆'被氧化'与'氧化剂'：被氧化的是还原剂

### 🧬 生物：选必一第1章：内环境的成分与理化性质

**概念复习**

内环境的成分包括血浆中的各种物质：水（约90%）、蛋白质、无机盐、营养物质（葡萄糖、氨基酸等）、代谢废物（尿素、尿酸等）。内环境的理化性质包括：渗透压（主要决定于溶质微粒数目，血浆渗透压主要来自Na⁺和Cl⁻）、pH（正常
7.35-
7.45，靠缓冲对维持）、温度（约37℃）。

**关键要点**

1. 内环境成分：水90%、蛋白质、无机盐、营养物质、代谢废物
2. 渗透压：主要决定于溶质微粒数目，血浆中主要为Na⁺和Cl⁻
3. pH：7.35-7.45，由缓冲对（H₂CO₃/NaHCO₃）维持
4. 温度：约37℃，是酶催化反应的适宜温度
5. 血浆蛋白减少→组织液增多→组织水肿

**作业练习指导**

今日学习「内环境成分与理化性质」。做题步骤：①成分题先排除细胞内物质；②渗透压题注意是所有溶质微粒数目决定的；③pH题记住缓冲对H₂CO₃/NaHCO₃。重点练习：渗透压分析、组织水肿原因判断。建议结合实例理解（如大量出汗补盐水）。

**易错提醒**

1. 渗透压不是只由Na⁺决定，而是所有溶质微粒总数
2. 血浆pH不是7.0，而是7.35-7.45
3. 组织水肿的原因是血浆蛋白减少或淋巴回流受阻

### 📝 语文：组合练习(一)：古诗杨万里《喜雨》阅读

**概念复习**

杨万里的《喜雨》描写久旱逢雨的喜悦之情。杨万里是南宋'诚斋体'的代表，诗风活泼自然、通俗浅近。阅读古诗时要注意：解题（'喜'字点明情感）、知人论世（杨万里田园诗特色）、分析意象（雨、田、禾等）、品味语言（通俗生动）。理解'喜'字贯穿全诗，从盼望→喜悦→感恩的情感线索。

**关键要点**

1. 杨万里：南宋诗人，'诚斋体'代表，诗风活泼自然
2. 解题：'喜'字直接点明全诗情感基调
3. 情感线索：盼望→喜悦→感恩
4. 意象分析：雨、田、禾→丰收的期盼
5. 语言特色：通俗浅近但不失诗意

**作业练习指导**

今日读《喜雨》并做初步鉴赏。做题步骤：①先通读全诗，标注「喜」字出现的位置；②分析意象（雨、田、禾）与情感的关系；③注意杨万里「诚斋体」活泼自然的风格。建议先做课后理解题，再尝试鉴赏分析题。背诵任务：熟读全诗。

**易错提醒**

1. 只分析字面意思，忽略'喜'背后的深层情感
2. 不了解杨万里诗风，分析时套用其他诗人风格
3. 忽略诗歌的社会背景（农耕社会对雨的重视）

### ⚡ 物理：力学基础：匀变速直线运动基本公式

**概念复习**

匀变速直线运动的基本公式：速度公式v=v₀+at，位移公式x=v₀t+½at²，速度-位移公式v²-v₀²=2ax。使用时注意：各量均为矢量，取正方向后用正负号表示方向。初速度为零时公式简化：v=at，x=½at²，v²=2ax。

**公式**

1. v = v₀ + at（速度公式）
2. x = v₀t + ½at²（位移公式）
3. v² - v₀² = 2ax（速度-位移公式）

**关键要点**

1. 速度公式：v = v₀ + at
2. 位移公式：x = v₀t + ½at²
3. 速度-位移公式：v² - v₀² = 2ax（不含时间t）
4. 所有物理量必须统一单位（SI制）
5. 注意各量的方向（正负号）

**作业练习指导**

今日补充学习匀变速直线运动公式。做练习时：①统一单位（km/h→m/s）；②取正方向后用正负号表示方向；③已知v₀,v,t用速度公式；已知v₀,v,a用速度-位移公式。建议做3-4道基础计算题，注意单位换算。

**易错提醒**

1. 忘记统一单位（如km/h未换算成m/s）
2. 矢量方向搞混：取正方向后未正确使用正负号

## 📜 语文古诗文

### 无衣
**先秦　· 佚名**

**原文**

> 岂曰无衣？与子同袍。王于兴师，修我戈矛。与子同仇！
> 岂曰无衣？与子同泽。王于兴师，修我矛戟。与子偕作！
> 岂曰无衣？与子同裳。王于兴师，修我甲兵。与子偕行！

**译文**

> 谁说没有衣服穿？我愿和你同穿一件长袍。君王起兵出征，修整好我们的戈和矛，我和你共同面对敌人！
> 谁说没有衣服穿？我愿和你同穿一件内衣。君王起兵出征，修整好我们的矛和戟，我和你一同行动！
> 谁说没有衣服穿？我愿和你同穿一件战裙。君王起兵出征，修整好我们的铠甲和兵器，我和你一同前行！

**注释**

- **袍** → 长衣
- **王于兴师** → 君王起兵出征。于，语助词
- **戈矛** → 古代兵器名
- **同仇** → 共同面对敌人
- **泽** → 通"襗"，贴身内衣
- **戟** → 古代兵器，戈和矛的合体
- **偕作** → 一同行动起来
- **裳** → 下衣，裙子
- **甲兵** → 铠甲和兵器
- **偕行** → 一同前行

**背诵要点**

1."与子同泽"的"泽"通"襗"，指贴身内衣；2.三章结构递进：同袍→同泽→同裳，同仇→偕作→偕行；3.注意"戈矛""矛戟""甲兵"三组兵器的递进；4.体现秦国军民团结、同仇敌忾的尚武精神
