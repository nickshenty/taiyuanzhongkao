### 🔢 数学：平面向量：数量积的坐标运算

**概念复习**

在直角坐标系中，设a=(x₁,y₁)，b=(x₂,y₂)，则a·b=x₁x₂+y₁y₂。由此可得重要结论：|a|=√(x₁²+y₁²)，cosθ=(x₁x₂+y₁y₂)/(√(x₁²+y₁²)·√(x₂²+y₂²))，a⊥b的充要条件是x₁x₂+y₁y₂=0。利用坐标运算可以解决夹角、垂直、长度等问题，比几何方法更直接。

**公式**

1. a·b = x₁x₂ + y₁y₂
2. \|a| = √(x₁² + y₁²)
3. cosθ = (x₁x₂ + y₁y₂) / (√(x₁²+y₁²) · √(x₂²+y₂²))

**关键要点**

1. 坐标数量积：a·b = x₁x₂ + y₁y₂
2. 向量模的坐标表示：|a| = √(x₁² + y₁²)
3. 夹角公式：cosθ = (x₁x₂+y₁y₂)/(|a||b|)
4. 垂直条件：a⊥b ↔ x₁x₂ + y₁y₂ = 0
5. 平行条件：a∥b ↔ x₁y₂ - x₂y₁ = 0

**作业练习指导**

今日做平面向量专题的「数量积坐标运算」部分（方法练习Day2）。做题步骤：①坐标运算用a·b=x₁x₂+y₁y₂；②求模用|a|=√(x²+y²)；③求夹角用cosθ=(a·b)/(|a||b|)，注意分母不能忘；④垂直条件x₁x₂+y₁y₂=0。重点练习：坐标运算综合、夹角与垂直判断。建议先做基础坐标运算，再做综合题。

**易错提醒**

1. 夹角公式中忘记分母的模
2. 混淆垂直条件(=0)和平行条件(=0)，但表达式不同
3. 计算cosθ时不化简，直接判角度

### ⚗️ 化学：巩固1-1(正式)：离子方程式与氧化还原反应

**概念复习**

今日完成巩固1-1后半部分。离子方程式的关键：正确拆分强电解质（强酸HCl/H₂SO₄/HNO₃、强碱NaOH/KOH/Ba(OH)₂、可溶盐），保留弱电解质（弱酸CH₃COOH/H₂CO₃、弱碱NH₃·H₂O、水）和气体、沉淀不拆。氧化还原反应配平步骤：标化合价→找电子转移→配平电子得失→配平其他原子→查守恒。

**化学方程式**

1. 离子方程式：2H⁺ + CO₃²⁻ → H₂O + CO₂↑（碳酸根与强酸反应）
2. 离子方程式：Ag⁺ + Cl⁻ → AgCl↓（银离子检验氯离子）
3. 氧化还原配平：MnO₂ + 4HCl(浓) △→ MnCl₂ + Cl₂↑ + 2H₂O
4. 电子转移：2Cl⁻→Cl₂↑（失2e⁻被氧化），Mn⁴⁺→Mn²⁺（得2e⁻被还原）

**关键要点**

1. 拆分原则：强酸、强碱、可溶盐拆；弱电解质、气体、沉淀不拆
2. 六大强酸：HCl、H₂SO₄、HNO₃、HClO₄、HBr、HI
3. 四大强碱：NaOH、KOH、Ca(OH)₂、Ba(OH)₂（可溶部分）
4. 氧化还原配平：电子守恒→原子守恒→电荷守恒
5. 双线桥法标电子转移方向和数目

**作业练习指导**

今日正式完成巩固1-1后半部分（离子方程式与氧化还原）。做题步骤：①离子方程式严格四步法，拆分时注意六大强酸四大强碱拆，其余不拆；②配平氧化还原：标价态→找电子→配得失→配原子→查守恒；③双线桥法标电子转移。重点练习：离子方程式书写、氧化还原配平。建议限时完成。

**易错提醒**

1. 把CaCO₃（难溶盐）拆了，应该保留不拆
2. 把NH₃·H₂O（弱碱）拆成NH₄⁺+OH⁻
3. 配平时只看原子守恒，忘了电荷守恒

### ⚡ 物理：抛体运动1：平抛运动基础

**概念复习**

平抛运动是将物体以一定初速度水平抛出，只受重力作用的运动。平抛运动可分解为水平方向的匀速直线运动和竖直方向的自由落体运动。水平方向：vx=v₀，x=v₀t；竖直方向：vy=gt，y=½gt²。任意时刻速度方向与水平方向的夹角满足tanθ=vy/vx=gt/v₀，位移方向与水平方向的夹角满足tanα=y/x=gt/(2v₀)，即速度方向与位移方向不同。运动时间由抛出高度决定，与初速度无关。平抛运动的核心是两个独立的分运动，水平方向匀速、竖直方向自由落体，两者通过时间t联系。

**公式**

1. 水平位移：x = v₀t
2. 竖直位移：y = ½gt²
3. 合速度：v = √(v₀² + (gt)²)
4. 运动时间：t = √(2h/g)

**关键要点**

1. 平抛=水平匀速+竖直自由落体，只受重力
2. 水平：vx=v₀，x=v₀t；竖直：vy=gt，y=½gt²
3. 运动时间t=√(2h/g)，由高度决定，与v₀无关
4. 速度方向角tanθ=gt/v₀，位移方向角tanα=gt/(2v₀)
5. 速度方向与位移方向不同，θ≠α

**作业练习指导**

今日做物理作业1的多选题和实验题。多选题注意：①平抛运动时间只取决于高度；②速度方向和位移方向不同。实验题（探究平抛运动特点）：注意斜槽末端必须水平、坐标原点选球心、用重垂线确定y轴方向。重点练习轨迹方程分析和实验误差判断。

**易错提醒**

1. 认为初速度越大运动时间越长（时间只与高度有关）
2. 混淆速度方向角与位移方向角
3. 斜抛分解时忘记分解初速度

## 📜 语文古诗文

### 山居秋暝
**唐　· 王维**

**原文**

> 空山新雨后，天气晚来秋。
> 明月松间照，清泉石上流。
> 竹喧归浣女，莲动下渔舟。
> 随意春芳歇，王孙自可留。

**译文**

> 空旷的群山沐浴了一场新雨，傍晚的天气显得格外清凉秋爽。
> 皎洁的月光透过松林洒落，清冽的泉水在石头上淙淙流淌。
> 竹林中传来喧闹声是洗衣女归来，莲叶摇动是渔舟顺流而下。
> 任凭春天的芳花凋谢消歇，这秋天的山中王孙自可留居。

**注释**

- **暝** → 日落，天色将晚
- **空山** → 幽静的山
- **竹喧** → 竹林中笑语喧哗
- **浣女** → 洗衣的女子
- **春芳歇** → 春天的芳花凋谢
- **王孙** → 原指贵族子弟，此处诗人自指
- **随意** → 任凭

**背诵要点**

1.名句"明月松间照，清泉石上流"——动静结合，以动衬静；2."竹喧归浣女，莲动下渔舟"——因果倒装句式；3."王孙自可留"反用《楚辞·招隐士》"王孙兮归来，山中兮不可久留"之意；4.体现王维"诗中有画"的特点
