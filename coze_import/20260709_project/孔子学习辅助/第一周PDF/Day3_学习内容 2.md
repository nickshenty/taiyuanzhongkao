### 🔢 数学：平面向量：数量积的概念与运算

**概念复习**

数量积（点积）是两个向量的乘法运算，结果是一个标量。定义：a·b = |a||b|cosθ，其中θ为两向量的夹角。几何意义：a·b等于a的模与b在a方向上的投影的乘积。当θ=0时同向最大，θ=90°时垂直为零，θ=180°时反向最小。数量积满足交换律a·b=b·a和分配律a·(b+c)=a·b+a·c，但不满足结合律。

**公式**

1. a·b = |a||b|cosθ
2. 坐标运算：a·b = x₁x₂ + y₁y₂
3. \|a| = √(x²+y²)，cosθ = (a·b)/(|a||b|)
4. 投影：b在a上的投影 = (a·b)/|a|

**关键要点**

1. 数量积定义：a·b = |a||b|cosθ，结果为标量
2. θ=0°：同向，a·b=|a||b|（最大）
3. θ=90°：垂直，a·b=0
4. θ=180°：反向，a·b=-|a||b|（最小）
5. a⊥b的充要条件：a·b=0

**作业练习指导**

今日做平面向量专题的「数量积」部分（方法练习Day1）。做题步骤：①先判断题目是求数量积、夹角还是判断垂直；②几何法用a·b=|a||b|cosθ，坐标法用x₁x₂+y₁y₂；③垂直判断用a·b=0。重点练习：数量积计算、夹角求解。注意：数量积结果是标量不是向量。建议先做基础题再提升难度。

**易错提醒**

1. 数量积结果不是向量而是标量（数值）
2. 误以为数量积满足结合律：(a·b)·c ≠ a·(b·c)
3. 垂直条件用错：a⊥b ↔ a·b=0，不是a×b=0

### ⚗️ 化学：巩固1-1(正式)：物质分类与胶体

**概念复习**

今日完成巩固1-1前半部分。重点复习物质分类的层级关系和胶体的性质与应用。物质分类的核心：根据组成和性质进行系统分类。胶体的关键性质：丁达尔效应（鉴别胶体）、电泳（胶体粒子带电）、聚沉（加电解质或加热使胶体沉淀）。Fe(OH)₃胶体带正电，硅酸胶体带负电。

**化学方程式**

1. Fe(OH)₃胶体制备：将FeCl₃饱和溶液滴入沸水中
2. 明矾净水：KAl(SO₄)₂ → Al³⁺水解形成Al(OH)₃胶体（吸附悬浮颗粒）
3. 分类反应示例：CaO + H₂O → Ca(OH)₂（碱性氧化物+水→碱）

**关键要点**

1. 物质分类体系：纯净物→单质/化合物→金属/非金属、氧化物/酸/碱/盐
2. 胶体三性质：丁达尔效应、电泳、聚沉
3. Fe(OH)₃胶体带正电荷，胶体粒子表面积大
4. 聚沉方法：加电解质、加带相反电荷胶体、加热
5. 胶体应用：净水（明矾）、制豆腐、血液透析

**作业练习指导**

今日正式完成巩固1-1前半部分（物质分类与胶体）。做题步骤：①物质分类题先画分类树再判断；②胶体题注意丁达尔效应是光的散射；③胶体制备题记住FeCl₃滴入沸水的方法。重点练习：分类判断、胶体性质应用。建议限时完成，模拟考试节奏。

**易错提醒**

1. 把胶体粒子等同于分子：胶体粒子是分子的集合体
2. 丁达尔效应原因是光的散射，不是反射
3. 聚沉和沉淀概念混淆：聚沉是胶体变成沉淀的过程

### 🧬 生物：选必一第1章：稳态的概念与机制

**概念复习**

稳态是指正常机体通过调节作用，使各器官系统协调活动，共同维持内环境的相对稳定状态。稳态的调节机制是神经-体液-免疫调节网络。稳态的实质是内环境理化性质的动态平衡，不是静止不变。维持稳态的能力是有一定限度的，当外界变化超出调节能力时，就会导致稳态失调（如发烧、水肿）。

**关键要点**

1. 稳态定义：内环境的相对稳定状态
2. 调节机制：神经-体液-免疫调节网络
3. 稳态实质：动态平衡，不是静止不变
4. 维持稳态需要各器官系统协调活动
5. 稳态失调的表现：发烧、水肿、酸碱失衡

**作业练习指导**

今日学习「稳态的概念与机制」。做题步骤：①先理解稳态是动态平衡不是静止不变；②调节机制三要素：神经-体液-免疫；③稳态失调实例分析（如糖尿病、水肿）。重点练习：稳态判断、调节机制分析。建议结合实例记忆。

**易错提醒**

1. 误认为稳态是静止不变的，实际是动态平衡
2. 忽略免疫系统在维持稳态中的作用
3. 混淆'稳态'与'平衡'：稳态是调节的结果

### ⚡ 物理：抛体运动1：曲线运动与运动合成分解

**概念复习**

曲线运动是指物体运动轨迹为曲线的运动。做曲线运动的条件是物体所受合外力方向与速度方向不在同一直线上。曲线运动中速度方向始终沿轨迹切线方向，合外力方向指向轨迹凹侧。运动的合成与分解遵循平行四边形定则：合运动是分运动的矢量和，合运动与分运动具有等时性。两个分运动均为匀速直线运动时，合运动一定是匀速直线运动；若一个分运动为匀速、另一个为匀变速，合运动为曲线运动。掌握运动合成分解是理解抛体运动的基础，做题时要养成画速度/位移矢量图的习惯。

**公式**

1. 合速度：v合 = √(vx² + vy²)，tan θ = vy/vx
2. 合位移：s合 = √(x² + y²)

**关键要点**

1. 曲线运动条件：合外力方向与速度方向不在同一直线上
2. 速度方向沿轨迹切线，合外力指向轨迹凹侧
3. 运动合成遵循平行四边形定则，合运动与分运动等时
4. 两匀速直线运动合成必为匀速直线运动
5. 一个匀速+一个匀变速合成曲线运动

**作业练习指导**

今日做物理作业1的单选题部分。做题步骤：①先判断物体是否做曲线运动——看合外力与速度方向是否共线；②运动合成分解时画好平行四边形，注意矢量运算；③利用等时性建立方程。重点：曲线运动条件判断、合速度计算、渡河问题分析。

**易错提醒**

1. 认为合速度一定大于分速度（矢量和不一定大于分量）
2. 混淆合运动时间与分运动时间（两者相等）
3. 误认为曲线运动中合外力方向与速度方向垂直

## 📜 语文古诗文

### 涉江采芙蓉
**汉代　· 佚名**

**原文**

> 涉江采芙蓉，兰泽多芳草。采之欲遗谁？所思在远道。
> 还顾望旧乡，长路漫浩浩。同心而离居，忧伤以终老。

**译文**

> 渡过江水去采撷芙蓉花，兰花丛生的沼泽里长满了芳草。采了花想送给谁呢？我所思念的人在遥远的地方。
> 回头眺望故乡，长路漫漫无边无际。我们心心相印却分隔两地，只能怀着忧伤度过余生。

**注释**

- **芙蓉** → 荷花
- **兰泽** → 兰花丛生的沼泽
- **遗** → 赠送
- **远道** → 遥远的地方
- **还顾** → 回头看
- **旧乡** → 故乡
- **漫浩浩** → 形容路途遥远无边无际
- **同心** → 心心相印
- **离居** → 分隔两地居住
- **终老** → 度过晚年直到死亡

**背诵要点**

1."采之欲遗谁"的"遗"读wèi，意为赠送；2."还顾望旧乡"的"还"通"环"，意为回头；3.注意"漫浩浩"三字叠用的效果；4.此诗出自《古诗十九首》，表现游子思乡之情
