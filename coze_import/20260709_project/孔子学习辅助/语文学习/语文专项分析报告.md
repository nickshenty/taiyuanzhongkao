## 一、高考必背古诗文篇目清单

### 1.1 总体概况

根据《普通高中语文课程标准（2017年版2020年修订）》，高中阶段推荐背诵古诗文共 **72篇**，其中：

- **文言文32篇**（必修10篇 + 选择性必修10篇 + 选修12篇）
- **诗词曲40首**

实际高考使用中，多数省份采用 **60篇**（72篇减去选修12篇），选修12篇学有余力者可拓展背诵。

## 二、古诗文高效记忆方法

### 2.1 理解记忆法（核心基础）

**原理**：理解是记忆的前提，脱离理解的背诵难以持久。

**操作步骤**：
1. **疏通字词**：结合注释和工具书，逐字逐句理解诗文含义，特别关注一词多义、古今异义、词类活用、通假字等文言现象
2. **把握文脉**：梳理文章的层次结构（总分总/并列/递进/对比），理解段落之间的逻辑关系
3. **体悟情感**：了解作者生平和创作背景，走进作者内心世界，体会喜怒哀乐

**示例**：背诵《赤壁赋》时，先理解苏轼情感从"乐"→"悲"→"喜"的转变脉络，再按此主线串联各段

> 来源：[人人文库 - 高考必背古诗文快速记忆方法](https://www.renrendoc.com/paper/496725203.html)

### 2.2 联想/画面记忆法

**原理**：将抽象文字转化为生动画面，利用视觉形象强化记忆（情境依存性记忆）。

**操作方法**：
- **情境联想**：将诗词内容与具体画面、场景联系
- **动态演绎**：在脑海中"播放"诗文描绘的画面，像看短视频一样
- **角色代入**：把自己当作作者或诗中人物，感受当时情境

**示例**：背诵《琵琶行》"浔阳江头夜送客，枫叶荻花秋瑟瑟"——想象秋夜江边，枫叶飘零、荻花瑟瑟，主客下马登船饯别

> 来源：[原创力文档 - 高中古诗文背诵技巧与推荐目录](https://m.book118.com/html/2025/1224/5221014340013041.shtm)

### 2.3 韵律节奏记忆法

**原理**：古诗文的平仄、押韵、对仗是天然的记忆线索，大脑对有节奏的信息处理效率更高。

**操作方法**：
1. **划分节拍**：五言按"2+3"、七言按"2+2+3"或"4+3"切分
2. **利用对仗**：找出句内、句间的对仗关系，通过"上句推下句"
3. **强调韵脚**：朗读时刻意强调韵脚，感受韵律循环，形成"语音闭环"

**示例**：《登高》"风急/天高/猿啸哀，渚清/沙白/鸟飞回"——"风急"对"天高"，"猿啸哀"对"鸟飞回"

> 来源：[人人文库 - 高考必背古诗文快速记忆方法](https://www.renrendoc.com/paper/496725203.html)

### 2.4 关键词/提纲挈领法

**原理**：抓住每句或每段的核心关键词作为"记忆钉子"，以点带面。

**操作方法**：
- 圈出人名、地名、时间词、转折词、情感词、典故词
- 概括每段大意，形成简明提纲
- 先记"骨架句"（总领句、中心句、转折句），再补细节

### 2.5 分段击破+整体串联法

**原理**：将长篇诗文分解为小段落逐一攻克，降低记忆压力。

**操作方法**：
1. 将整篇按内容层次分为若干小段
2. 每天背一小段，先逐句攻破再连句成段
3. 段落背熟后定期整合，逐步扩大记忆单元

### 2.6 间隔复习法（对抗遗忘）

**原理**：遵循艾宾浩斯遗忘曲线规律，在遗忘高峰前及时复习。

**推荐复习周期**：

| 时间节点 | 复习方式 |
|----------|----------|
| 初次记忆 | 完整记忆1篇，标记难点句 |
| 1小时后 | 不看原文回忆全文，卡壳处重点标记 |
| 1天后 | 默写+回忆结合，对比原文修正 |
| 3天后 | 再次默写，强化难点 |
| 1周后 | 完整默写检验 |
| 1个月后 | 最终巩固 |

### 2.7 默写纠错法

**操作方法**：
1. 拿A4纸对折，左边默写，右边红笔纠错
2. 圈出错字，睡前重写5遍
3. 第二天先写昨天的错字，再开始新内容
4. 准备"易错本"，记录常写错的字和混淆的句子

> 来源：[长沙市芙蓉高级中学 - 语文古诗文背诵高效记忆方法](https://mingdazhongxue.com/news/1875.html)

### 3.2 命题趋势分析

#### 趋势一：思辨层级持续升级

- 从简单的二元对立（得与失）走向多元系统辩证
- 三组及以上关联概念考查增多（如"本手/俗手/妙手"、"专—转—传"）
- 命题不再预设单一最优观点，允许多元合理立意
- **区分高分与低分的关键不在素材文采，而在思辨深度**

#### 趋势二：小切口观照大时代

- 以个体生活、学习小事、文化细节、科技现象为切入点
- 引申至社会、国家、文明层面宏大议题
- 2026年全国I卷以"一个词语"为切口，联通时代变迁与个人成长
- 避免"宏大叙事空泛化"，强调"大处着眼、小处落笔"

#### 趋势三：反模板、反押题力度达到顶峰

- 摒弃套路化写作，呼唤"真思考、真表达"
- 阅卷老师对反复出现的历史人物、老旧典故产生审美疲劳
- 更加青睐贴合时代、结合个人体验、紧扣主题的鲜活素材
- 生硬套用排比句式、堆砌华丽辞藻却言之无物的文章难得高分

#### 趋势四：价值引领一以贯之

- "立德树人"始终是作文命题的灵魂
- 高频恒定主题：青年使命（个人理想与民族复兴）、文化根基（传统文化传承与创新）、品格修养（坚守、务实、包容、坚韧）
- 构建"小我—大我—时代"的统一叙事逻辑

#### 趋势五：情境任务与跨域融合

- 任务驱动常态化：限定写作身份、交际场景、文体
- 科技人文交叉：2024年AI、2026年科技与想象
- 传统文化现代转化：古诗名句、经典文本入题

> 来源：[美篇 - 历年全国高考作文题共性、发展趋势及写作备考对策](https://www.meipian.cn/5n0g7jp1)；[新华网 - 2026高考作文上新](http://www.xinhuanet.com/20260607/21537b75b9154a9480b7218fd9edd414/c.html)

### 3.3 高考作文评分标准

高考作文评分采用 **"内容、表达、发展等级"三维标准**：

| 维度 | 核心要求 | 说明 |
|------|----------|------|
| **内容**（基础等级） | 立意贴合材料、中心明确、紧扣价值导向 | 偏题、跑题为致命失分点 |
| **表达**（基础等级） | 逻辑清晰、结构完整、语言流畅规范 | 书面表达基本功是保底分；错别字、语病累计扣3-5分 |
| **发展等级**（高分关键） | 深刻、丰富、有文采、有创意 | 对应思辨深度、素材厚度、语言质感、独立思考 |

**扣分细则**：
- 缺标题扣2分
- 错别字每个扣1分（重复不累计）
- 标点错误酌情扣分
- 不足800字每少50字扣1分

> 来源：[美篇 - 历年全国高考作文题共性及发展趋势](https://www.meipian.cn/5n0g7jp1)

### 3.4 优秀作文的核心特点

1. **思辨深刻**：能厘清矛盾双方的依存、转化、平衡关系，拒绝非黑即白
2. **素材鲜活**：贴合时代、结合个人体验，而非堆砌历史人物和老旧典故
3. **语言有质感**：通顺准确的基础上有亮点语句，杜绝语病和错别字
4. **结构清晰**：逻辑层次分明，论证层层递进
5. **真情实感**：真诚面对个人成长经历，讲自己的故事和思考
6. **格局开阔**：从"小我"走向"大我"，将个人经验与时代背景结合

## 五、现代文阅读答题技巧与高频考点

### 5.1 现代文阅读三大文体及考查重点

高考现代文阅读通常占 **25-35分**，包含三大类文本：

| 文体类型 | 考查重点 | 常见题型 |
|----------|----------|----------|
| **论述类文本**（学术论文、时评、政论文） | 理解概念与句子、筛选整合信息、分析论证特点、评价观点态度 | 选择题为主 |
| **实用类文本**（新闻、传记、报告、科普） | 提取关键信息、概括内容要点、分析图表数据、评价文本价值 | 选择题+主观题，多为非连续性文本 |
| **文学类文本**（小说、散文） | 分析人物形象、赏析语言手法、理解标题含义、探究主旨情感 | 主观题为主 |

### 5.2 通用答题技巧

#### （一）答题核心原则

1. **文本为王**：所有答案必须基于原文，避免主观臆断
2. **分点作答**：按"①②③"分条列点，逻辑清晰（阅卷按点给分）
3. **审题定向**：先明确问题类型（作用题/含义题/手法题/概括题），再针对性调用模板
4. **专业术语**：用规范术语答题，避免口语化

#### （二）信息类文本快速阅读法（金字塔阅读法）

1. **扫标题和出处**（30秒）：预判主题和文章类型
2. **读每段首尾句**（2分钟）：搭起整体框架，抓住中心论点
3. **做题时回原文定位**：带着问题回找，不必逐字通读全文

> 来源：[头条 - 2026高考语文现代文阅读高分攻略](http://m.toutiao.com/group/7655446559014699555/)

### 5.3 选择题常见陷阱与破解方法

| 陷阱类型 | 表现 | 破解方法 |
|----------|------|----------|
| **偷换概念** | 把A换成B，看似相近实则不同 | 逐字比对选项与原文 |
| **以偏概全** | 把部分说成全部 | 注意"某些""所有""多数"等范围词 |
| **混淆时态** | 把未来说成已实现 | 注意"有望""已经""正在"等时态词 |
| **混淆因果** | 因果倒置或强加因果 | 核对因果逻辑是否成立 |
| **无中生有** | 原文未提及 | 回原文查找依据 |
| **绝对化表述** | 出现"全部""一定""唯一""只有…才…" | 优先警惕，回原文核对 |

### 5.4 主观题分层答题法

**四步走**：

1. **审题**：问什么？范围在哪？有几问？（圈出题干关键词）
2. **定位**：回原文找到答案出处，划出相关句子
3. **分点**：按角度分层作答（原因题分主观/客观，作用题分内容/结构/表达效果）
4. **术语**：用专业表达，避免大白话

**分值与点数参考**：6分一般3个点，4分一般2个点

### 5.5 文学类文本高频题型答题模板

#### （1）人物形象分析题

**答题格式**：性格特点 + 原文事例分析

> 例："主人公是一个倔强执着的人，从他多次失败仍坚持尝试的行为中可以看出"

**切入角度**：言行举止、心理描写、环境烘托、情节发展

#### （2）情节/段落作用分析题

从四个维度作答：

| 维度 | 思考方向 |
|------|----------|
| **人物** | 塑造或丰富人物形象 |
| **情节** | 推动情节发展、形成转折、照应前文 |
| **环境** | 渲染氛围、交代故事背景 |
| **主旨** | 揭示或深化主题 |

#### （3）句子/标题含义题

分三层作答：
- **字面义**：本义是什么
- **语境义**：在文中指什么（结合上下文）
- **情感/主旨义**：表达了什么情感或突出了什么主题

#### （4）手法赏析题

**答题格式**：手法 + 内容分析 + 情感效果

> 例："运用了比喻的修辞手法，将'风'比作'锋利的刀'，生动形象地写出了寒风的凛冽刺骨，烘托了人物在寒风中行走的艰难"

**常见手法**：
- 修辞：比喻、拟人、夸张、排比、反问
- 描写：人物描写（外貌/语言/动作/心理）、环境描写、细节描写
- 表现手法：对比、衬托、象征、抑扬、虚实结合

#### （5）论证思路题（三步走）

1. **先说观点**：文章开篇提出了什么中心论点
2. **梳理层次**：作者从哪些角度、用什么论证方法展开论述
3. **收尾总结**：最后得出什么结论

> 来源：[原创力文档 - 高考语文现代文阅读答题模板及技巧](https://m.book118.com/html/2025/1123/5301114021013021.shtm)；[头条 - 高考语文阅读理解高分策略](http://m.toutiao.com/group/7596889092428661282/)

### 5.6 新高考热点题型

| 题型 | 特点 | 答题要点 |
|------|------|----------|
| **文学短评/点评** | 2023年起新高考首创，情境化，6分 | 亮观点→扣文本（人物/情节/语言各举1例）→升主旨 |
| **教考结合类** | 链接教材课文/课标理论 | 引理论→找印证→析特色 |
| **叙事效果题** | 分析叙述视角、顺序、节奏 | 从结构脉络、人物塑造、叙事节奏、整体氛围四维度作答 |
| **跨材料综合题** | 多则材料对比分析 | 先分别概括每则材料核心内容，再比异同 |

### 6.2 文言虚词（18个必考虚词）

**18个必考虚词**：之、其、以、于、而、则、乃、若、且、所、为、焉、也、乎、者、何、因、与

#### 重点虚词用法速查

| 虚词 | 主要用法 | 典型例句 |
|------|----------|----------|
| **之** | ①代词（他/它/这） ②助词"的" ③取消句子独立性 ④宾语前置标志 ⑤动词"到…去" | 古之学者必有师（的）；何陋之有（宾前标志）；吾欲之南海（到…去） |
| **其** | ①代词（他的/那） ②语气副词（大概/难道） | 其皆出于此乎（大概）；其孰能讥之乎（难道） |
| **以** | ①介词（用/凭/把/因为/在） ②连词（来/而） ③动词（认为） | 以刀劈狼首（用）；不以物喜（因为）；作《师说》以贻之（来） |
| **而** | ①并列（又） ②递进（而且） ③承接（就） ④转折（却） ⑤修饰（地） ⑥假设（如果） | 青取之于蓝而青于蓝（却）；吾尝终日而思矣（地） |
| **于** | ①在 ②比 ③被 ④向/对 ⑤从 | 寒于水（比）；不拘于时（被）；青取之于蓝（从） |
| **为** | ①动词（做/成为） ②介词（被/替） ③语气词（呢） | 为天下笑（被） |
| **乃** | ①于是、就 ②竟然 ③才 ④是 | 今其智乃反不能及（竟然） |
| **因** | ①于是 ②凭借 ③趁着 ④因为 | 因拔刀斫前奏案（于是）；因击沛公于坐（趁着） |

### 6.3 文言特殊句式

#### （一）判断句

| 句式 | 例句 |
|------|------|
| ……者，……也 | 廉颇者，赵之良将也 |
| ……，……也 | 夫战，勇气也 |
| 乃/即/则/为/皆/诚 | 此则岳阳楼之大观也 |
| 非 | 非臣陨首所能上报 |

#### （二）被动句

| 句式 | 例句 |
|------|------|
| ……于…… | 而君幸于赵王 |
| ……见…… | 信而见疑 |
| ……见……于…… | 臣诚恐见欺于王 |
| ……为……所…… | 不者，若属皆且为所虏 |
| ……被…… | 信而见疑，忠而被谤 |

#### （三）倒装句

| 类型 | 标志 | 例句 |
|------|------|------|
| 宾语前置 | 否定句代词宾语前置 | 古之人不余欺也 |
| | 疑问句疑问代词宾语前置 | 沛公安在 |
| | "之/是"提宾标志 | 何陋之有、唯利是图 |
| 定语后置 | 中心词+之+定语+者 | 蚓无爪牙之利 |
| 状语后置 | 动+于+宾 / 动+以+宾 | 青，取之于蓝；战于长勺 |
| 主谓倒装 | 感叹/疑问倒装 | 甚矣，汝之不惠也 |

#### （四）省略句

省主语、省谓语、省宾语、省介词（尤省"于"）、省兼语

#### （五）固定句式

| 句式 | 含义 | 例句 |
|------|------|------|
| 得无……乎 | 莫非……吧 | 得无教我猎虫所耶 |
| 无乃……乎 | 恐怕……吧 | 无乃尔是过与 |
| 不亦……乎 | 不也是……吗 | 不亦说乎 |
| 何……为 | 为什么……呢 | 何辞为 |
| 岂……哉 | 难道……吗 | 岂人力也哉 |

### 6.4 文言断句技巧

1. **句首发语词前断开**：夫、盖、若夫、且、凡
2. **句末语气词后断开**：也、矣、焉、耳、乎、哉、耶
3. **关联词前断开**：虽、苟、故、是故、况、而况
4. **对称句式依结构断**：对偶句、排比句按结构对等断句
5. **人名/地名/官职作主谓分界**

### 6.6 文言文翻译答题技巧

**翻译原则**：信（准确）、达（通顺）、雅（优美）

**六字诀**：留、删、换、调、补、意

| 方法 | 说明 | 举例 |
|------|------|------|
| **留** | 保留人名、地名、官名、年号等专有名词 | "沛公"保留不动 |
| **删** | 删去无实义的虚词 | "之""乎""者""也"等 |
| **换** | 将单音节词换成现代双音节词 | "走"→"跑"、"去"→"离开" |
| **调** | 调整倒装句语序为现代汉语语序 | "何陋之有"→"有何陋" |
| **补** | 补出省略成分 | "（公）度我至军中" |
| **意** | 意译比喻、借代等修辞 | "布衣"→"平民" |

### 7.1 学情分析

### 7.2 各板块提分优先级

| 优先级 | 板块 | 提分空间 | 建议 |
|--------|------|----------|------|
| ★★★★★ | 古诗文默写 | 6分（容易拿满） | 高二上学期集中攻克必修10篇+选择性必修10篇，用间隔复习法，确保一字不差 |
| ★★★★★ | 文言文阅读 | 15-20分提升空间 | 每日精读《古文观止》1篇，积累120实词+18虚词，练翻译 |
| ★★★★☆ | 作文 | 10-15分提升空间 | 每周写1篇限时作文，重点训练思辨能力和素材积累；阅读优秀范文 |
| ★★★★☆ | 现代文阅读 | 10分提升空间 | 掌握答题模板，练"分点作答+专业术语"，减少主观题失分 |
| ★★★☆☆ | 课外阅读 | 长期积累 | 寒暑假集中读《红楼梦》《乡土中国》，平时读散文和社科类 |
| ★★★☆☆ | 古诗文鉴赏 | 6-8分提升空间 | 结合必背篇目学习，掌握意象分析、手法鉴赏方法 |

### 7.3 高二阶段时间规划建议

| 时间段 | 重点任务 |
|--------|----------|
| **高二上学期** | 攻克必修10篇文言文背诵默写；系统学习120实词+18虚词；每周限时作文训练 |
| **高二下学期** | 攻克选择性必修10篇+诗词曲40首；现代文阅读专项训练；开始精读《红楼梦》 |
| **暑假/寒假** | 集中阅读《乡土中国》《古文观止》；整理作文素材库；查漏补缺 |

### 7.4 日常学习习惯建议

1. **每日古诗文**：早读15分钟背诵/复习古诗文，晚自习前默写自测
2. **每日文言文**：精读1篇《古文观止》短文，积累3-5个实词用法
3. **每周作文**：限时40分钟写1篇800字作文，对照评分标准自评
4. **每周阅读**：至少阅读2小时课外书，做读书笔记和素材摘抄
5. **错题本**：建立语文错题本，分类记录默写错字、文言文翻译错误、现代文答题偏差
6. **素材积累本**：按"青年使命""文化传承""科技人文""品格修养"等主题分类整理素材
