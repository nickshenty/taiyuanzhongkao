### ⚡ 物理：机械能守恒1：动能定理

**概念复习**

动能定理：合外力对物体做的功等于物体动能的变化量，即W合=ΔEk=½mv₂²-½mv₁²。动能定理适用于直线运动、曲线运动、恒力变力等各种情况，不需要知道运动过程的细节，只需知道初末状态的动能和过程中各力做的功。应用步骤：①确定研究对象和过程；②分析受力并计算各力做的功（注意正负）；③求合功W合=ΣWᵢ；④列方程W合=½mv₂²-½mv₁²求解。多个过程可以用全过程法一次列方程。动能定理的优势在于不需要知道运动过程细节，只需知道初末状态动能和各力做功。

**公式**

1. 动能定理：W合 = ½mv₂² - ½mv₁²
2. 动能：Ek = ½mv²
3. 合功：W合 = W₁ + W₂ + ... + Wₙ

**关键要点**

1. 动能定理：W合=ΔEk=½mv₂²-½mv₁²
2. 适用于恒力、变力、直线、曲线各种情况
3. 只需初末状态动能和过程做功，不需过程细节
4. 全过程法：W总=ΔEk（可跨多个阶段）
5. 合功=各力做功的代数和

**作业练习指导**

今日做物理作业7的多选题和实验题。多选题注意动能定理的适用范围。实验题（探究动能定理）：注意纸带数据处理、速度计算方法。重点练习多过程动能定理应用和变力做功问题。

**易错提醒**

1. 计算合功时漏掉某个力做的功
2. 力做负功时忘记取负号
3. 多过程问题中不会用全过程法
