### ⚡ 物理：机械能守恒1：机械能守恒定律

**概念复习**

机械能守恒定律：在只有重力（或弹簧弹力）做功的条件下，物体的动能和势能相互转化，机械能总量保持不变，即Ek₁+Ep₁=Ek₂+Ep₂。机械能包括动能和势能（重力势能Ep=mgh、弹性势能Ep=½kx²）。守恒条件：只有重力或弹力做功（其他力不做功或做功代数和为零）。判断步骤：①分析受力；②判断除重力/弹力外的力是否做功；③若只有重力弹力做功则机械能守恒。重力势能的零点可任意选取，通常选最低点或初态位置。

**公式**

1. 机械能守恒：½mv₁² + mgh₁ = ½mv₂² + mgh₂
2. 重力势能：Ep = mgh
3. 弹性势能：Ep = ½kx²

**关键要点**

1. 机械能守恒条件：只有重力/弹力做功
2. 机械能=动能+势能（重力势能+弹性势能）
3. 守恒方程：Ek₁+Ep₁=Ek₂+Ep₂
4. 重力势能Ep=mgh，弹性势能Ep=½kx²
5. 势能零点可任意选取

**作业练习指导**

今日做物理作业7的解答题。计算题策略：①先判断机械能是否守恒（检查守恒条件）；②选好势能零点；③列守恒方程½mv₁²+mgh₁=½mv₂²+mgh₂求解。重点练习斜面滑动、竖直下落、圆轨道运动的机械能守恒问题。

**易错提醒**

1. 机械能守恒条件判断错误（有摩擦力做功时不守恒）
2. 重力势能正负号搞错（低于零点为负）
3. 弹性势能公式中x是形变量不是弹簧长度
