### ⚡ 物理：机械能守恒1：功与功率

**概念复习**

功是力在位移方向上的累积效果，W=Flcosθ（θ为力与位移方向夹角）。功是标量，单位焦耳(J)。正功表示力促进物体运动，负功表示阻碍。功率是做功的快慢，P=W/t（平均功率），P=Fvcosθ（瞬时功率）。额定功率是发动机正常工作时的最大功率。汽车以恒定功率启动时，速度增大牵引力减小，加速度减小，最终做匀速运动（牵引力=阻力）。汽车以恒定加速度启动时，功率逐渐增大到额定功率后，转为恒功率加速。功和功率是能量问题的入门，恒功率启动和恒加速度启动是两种重要的汽车运动模型。

**公式**

1. 功：W = Flcosθ
2. 功率：P = W/t = Fvcosθ
3. 匀速条件：F牵 = f阻，v_max = P/f

**关键要点**

1. 功W=Flcosθ，θ是力与位移夹角
2. 功是标量，正功促进运动，负功阻碍
3. 平均功率P=W/t，瞬时功率P=Fvcosθ
4. 恒功率启动：v增大→F减小→a减小→最终匀速
5. 恒加速度启动：P增大到额定后转恒功率

**作业练习指导**

今日做物理作业7的单选题部分。做题要点：①计算功时注意力与位移的夹角；②功率问题区分恒功率和恒加速度启动模式；③注意瞬时功率P=Fvcosθ中θ是力与速度的夹角。重点练习功的计算和汽车启动问题。

**易错提醒**

1. 功公式中忘记cosθ（力与位移不共线时）
2. 混淆平均功率和瞬时功率
3. 恒功率启动时认为加速度恒定
