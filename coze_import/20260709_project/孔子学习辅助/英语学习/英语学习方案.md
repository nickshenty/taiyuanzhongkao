# 申奇峰英语暑假学习方案（7月6日-8月31日）

## 一、学习目标
- **词汇**：掌握高考必背3500词，重点攻克高频词汇
- **阅读**：从当前水平（高一65%）提升到高二-高三水平（80%+）
- **方法**：艾宾浩斯记忆法 + 每日测试反馈 + 分级阅读训练

## 二、每日时间安排
| 时间 | 内容 | 用时 |
|------|------|------|
| 7:30-8:00 | 晨起背单词（新词+复习） | 30分钟 |
| 下午学习时段 | 阅读练习（1篇文章） | 15-20分钟 |
| 晚饭后 ~19:00 | 词汇速测 + 阅读反馈 | 10分钟 |

## 三、词汇学习计划

### 3.1 词库规划
- **主词库**：高考3500必背词汇
- **拓展词库**：高考边缘词汇200-300个
- **分级**：
  - A1 基础词（初中词汇，约500词）——快速过，查漏补缺
  - A2 进阶词（高一核心词汇，约1000词）——重点学习
  - B1 中阶词（高一-高二词汇，约1000词）——重点学习
  - B2 高阶词（高二-高三词汇，约700词）——拓展提升
  - C1 拓展词（高考边缘词汇，约300词）——有余力时学

### 3.2 艾宾浩斯复习计划
**复习间隔**：第1天 → 第2天 → 第4天 → 第7天 → 第15天

**每日任务结构**：
- 新词学习：15-20分钟
- 到期复习词：10-15分钟

**每日词汇量规划**：
| 阶段 | 时间 | 每日新词 | 每日复习（累计） | 日总量 |
|------|------|---------|----------------|-------|
| Day 1 | 7/6 | 测试50词（不学新词） | — | 50（测试） |
| 起步期 | Day 2-7（7/7-7/12） | 50 | 50→300 | 100-350 |
| 稳定期 | Day 8-21（7/13-7/26） | 50 | 300→500 | 350-550 |
| 强化期 | Day 22-42（7/27-8/16） | 45 | 500→400 | 445-545 |
| 冲刺期 | Day 43-57（8/17-8/31） | 40 | 400→200 | 240-440 |

**总计新词**：50×6 + 50×14 + 45×21 + 40×15 = 300 + 700 + 945 + 600 = 2545词
加上Day 1测试后确认已掌握的词（预计约1000词），总计覆盖约3500词。

### 3.3 每日晚间测试
- **测试内容**：当天新学的单词（10分钟）
- **测试格式**：英译中 / 中译英 / 选词填空（轮换）
- **调整规则**：
  - 正确率 ≥ 80%：维持当前新词量
  - 60% ≤ 正确率 < 80%：减少5个新词，加强复习
  - 正确率 < 60%：减少10个新词，增加复习时间

### 3.4 词汇进度跟踪
每日记录：新词数、复习词数、测试正确率、已掌握总数
每周日复盘：本周学习量、平均正确率、薄弱词汇清单

## 四、阅读学习计划

### 4.1 第一天（7/6）：水平测试
- 5篇文章，难度从初二→高二递进
- 每篇约300词，5道理解题
- 测试目的：确定当前阅读水平基线，匹配后续文章难度

### 4.2 日常阅读计划（Day 2+）
- **每日1篇**阅读文章（15-20分钟）
- **文章来源**：
  - ChinaDaily（中高级难度）
  - 21世纪英语报（多难度分级）
  - 新东方题库（考试导向）
  - BBC Learning English（原版英语）
  - 可可英语/沪江英语（国内资源）
- **每篇文章配套**：3-5道理解题 + 5个重点词汇
- **阅读反馈**：做完后反馈答题情况和理解情况

### 4.3 难度递进规则
- 连续3天正确率 ≥ 80%：提升一个难度等级
- 连续3天正确率 < 60%：降低一个难度等级
- 单日正确率 < 40%：次日重复同难度

### 4.4 阅读技能训练重点
1. **快速浏览**（Skimming）：抓文章主旨大意
2. **寻读**（Scanning）：快速定位特定信息
3. **推理判断**：根据上下文推断词义和作者态度
4. **细节理解**：准确理解文章具体信息

## 五、Day 1（7月6日）具体任务

### 上午（7:30-8:00）
**词汇水平测试**：50词多选测试
- 测试文件：`Day1_词汇测试.md`
- 5个难度级别，每级10词
- 用时约20分钟，剩余10分钟初步评估
- 目的：确定词汇量基线，规划每日新词量

### 下午（14:30-17:30学习时段内）
**阅读水平测试**：5篇文章
- 测试文件：`Day1_阅读水平测试.md`
- 难度：初二→初三→高一→高一高二过渡→高二
- 每篇5题，共25题
- 用时约30-40分钟
- 做完反馈每篇正确率

### 晚饭后
**测试反馈**：根据词汇和阅读测试结果，确定：
- 每日新词量（基准50，可调整为30-60）
- 阅读文章起始难度等级
- 制定Day 2正式学习计划

## 七、注意事项
1. 词汇学习不要贪多，质量优先于数量
2. 阅读材料选择要有趣，保持阅读兴趣
3. 测试结果不理想不要灰心，调整计划继续
4. 遇到不懂的单词先猜后查，培养猜词能力
5. 每周日的"本周学习复盘"时间要总结英语学习情况
