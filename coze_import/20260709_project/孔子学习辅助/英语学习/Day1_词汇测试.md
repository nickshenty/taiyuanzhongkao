## 评分标准与建议

| 各部分正确率 | 词汇水平评估 | 建议 |
|-------------|-------------|------|
| 第一部分 ≥ 80% | 初中词汇基础扎实 | 可跳过A1级，直接从A2开始 |
| 第一部分 < 60% | 初中词汇有缺口 | 需先补初中核心词汇 |
| 第二部分 ≥ 80% | 高一基础词汇掌握好 | 正常进度学习A2-B1 |
| 第二部分 < 60% | 高一基础薄弱 | 适当减少每日新词量 |
| 第三部分 ≥ 60% | 高一-高二词汇有基础 | 按计划学习B1-B2 |
| 第三部分 < 40% | 高一-高二词汇薄弱 | 加大词汇学习投入 |
| 第四部分 ≥ 50% | 高阶词汇有一定基础 | 可适当拓展C1词汇 |
| 第四部分 < 30% | 高阶词汇薄弱 | 重点攻克B2级词汇 |
| 第五部分 | 拓展词汇，做对越多越好 | 根据整体水平决定是否拓展 |

### 整体评估
- **总分 ≥ 64/80**：词汇基础较好，每日可学60词
- **总分 48-63**：词汇中等，每日50词
- **总分 32-47**：词汇偏弱，每日40词
- **总分 < 32**：词汇薄弱，每日30词，加强基础
