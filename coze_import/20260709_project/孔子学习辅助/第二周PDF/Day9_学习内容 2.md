### ⚡ 物理：抛体运动2：斜抛运动

**概念复习**

斜抛运动是物体以一定角度斜向上抛出，只受重力作用的运动。斜抛可分解为水平方向的匀速运动和竖直方向的匀变速运动。初速度分解：v₀x=v₀cosθ，v₀y=v₀sinθ。最高点时竖直速度为零，上升时间t上=v₀sinθ/g，总飞行时间T=2v₀sinθ/g，射程x=v₀²sin2θ/g（g恒定时射程取决于sin2θ，θ=45°时射程最大）。到达最高点时速度大小为v₀cosθ，方向水平。斜抛运动的对称性是解题的重要工具，上升和下降过程关于最高点对称。

**公式**

1. 水平位移：x = v₀cosθ · t
2. 竖直位移：y = v₀sinθ·t - ½gt²
3. 射程：R = v₀²sin2θ/g
4. 最高高度：H = v₀²sin²θ/(2g)

**关键要点**

1. 斜抛=水平匀速+竖直匀变速（上抛+自由落体）
2. 初速度分解：v₀x=v₀cosθ，v₀y=v₀sinθ
3. 最高点vy=0，速度为v₀cosθ（水平方向）
4. 射程x=v₀²sin2θ/g，θ=45°时射程最大
5. 飞行时间T=2v₀sinθ/g

**作业练习指导**

今日做物理作业2的多选题和实验题。多选题注意：①斜抛最高点速度不为零；②射程与初速度和角度的关系；③对称性——上升和下降过程对称。实验题注意平抛运动轨迹分析的细节。重点练习斜抛运动的分解和射程计算。

**易错提醒**

1. 斜抛最高点速度为零（应为水平分量v₀cosθ）
2. 射程公式中误用sinθ而非sin2θ
3. 忽略空气阻力时上升和下降时间相等

## 📜 语文古诗文

### 书愤
**宋　· 陆游**

**原文**

> 早岁那知世事艰，中原北望气如山。
> 楼船夜雪瓜洲渡，铁马秋风大散关。
> 塞上长城空自许，镜中衰鬓已先斑。
> 出师一表真名世，千载谁堪伯仲间！

**译文**

> 早年哪里知道世事的艰难，北望中原收复失地的决心坚定如山。
> 记得当年楼船在夜雪中渡过瓜洲，铁马在秋风中驰骋于大散关。
> 空自期许成为守卫边疆的塞上长城，镜中衰老的鬓发却已先斑白。
> 诸葛亮的《出师表》真是名传后世，千载以来谁能与他不相上下！

**注释**

- **早岁** → 早年、年轻时
- **世事艰** → 指抗金复国事业艰难
- **气如山** → 收复失地的决心坚定如山
- **楼船** → 高大的战船
- **瓜洲渡** → 瓜洲渡口，在今江苏扬州
- **铁马** → 披铁甲的战马
- **大散关** → 在今陕西宝鸡西南
- **塞上长城** → 比喻能守卫边疆的将领，用南朝檀道齐典故
- **空自许** → 白白地自我期许
- **出师一表** → 指诸葛亮的《出师表》
- **伯仲** → 兄弟的次第，引申为不相上下

**背诵要点**

1."楼船夜雪瓜洲渡，铁马秋风大散关"——名句，回忆早年战斗经历，对仗工整；2."塞上长城空自许"——用典，以南朝檀道济自比；3."出师一表真名世，千载谁堪伯仲间"——借诸葛亮抒发壮志未酬之愤；4.注意"那知""空自许""已先斑"的情感层次
