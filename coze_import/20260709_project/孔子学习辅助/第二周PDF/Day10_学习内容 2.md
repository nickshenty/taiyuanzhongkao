### ⚡ 物理：抛体运动2：平抛与斜抛计算

**概念复习**

平抛与斜抛综合计算涉及多种情境：鸟食抛出与鸟接住的时间关系、跳一跳游戏的运动参数分析、炸弹投放与拦截问题等。关键技巧：两个平抛物体在空中相遇时，它们的高度差和水平距离需同时满足条件；竖直上抛与平抛的相遇问题，利用竖直方向运动方程和时间相等条件求解。对于炸弹拦截问题，炸弹做平抛运动，拦截弹做竖直上抛运动，相遇条件是两者在同一时刻到达同一位置。相遇问题的本质是两个物体在同一时刻到达同一位置，需要两个方向同时满足条件。

**公式**

1. 相遇条件：y₁(t) = y₂(t) 且 x₁(t) = x₂(t)
2. 竖直上抛：y = v₀t - ½gt²
3. 落地速度：v = √(v₀² + 2gh)

**关键要点**

1. 两平抛相遇：高度相同+水平到达+时间相等
2. 炸弹平抛与拦截弹上抛相遇：竖直位移相等+时间相等
3. 跳一跳：最高点高度h决定上升时间t=√(2h/g)
4. 落地速度大小v=√(v₀²+2gh)
5. 利用运动对称性简化计算

**作业练习指导**

今日做物理作业2的解答题。计算题策略：①相遇问题先列两个物体的运动方程，再利用位置相等的条件联立；②炸弹拦截问题分别列平抛和上抛方程，用时间相等和高度相等联立；③风洞问题中水平方向受恒力，需用匀变速运动处理。注意检查解的物理合理性。

**易错提醒**

1. 相遇问题中只考虑一个方向而忽略另一个方向
2. 上抛运动到达最高点时间与下落时间相等但方向不同
3. 风洞问题中忽略水平恒力的作用

## 📜 语文古诗文

### 虞美人·春花秋月何时了
**五代　· 李煜**

**原文**

> 春花秋月何时了？往事知多少。小楼昨夜又东风，故国不堪回首月明中。
> 雕栏玉砌应犹在，只是朱颜改。问君能有几多愁？恰似一江春水向东流。

**译文**

> 春花秋月什么时候才能了结？往日的事情还记得多少。小楼昨夜又刮起了东风，在明月之中不忍回首故国。
> 雕花的栏杆和玉石砌成的台阶应该还在，只是人的容颜已经衰老改变。问你心中能有多少愁苦？恰似一江春水向东奔流不息。

**注释**

- **了** → 了结、终了
- **往事** → 指南唐旧事
- **东风** → 春风
- **故国** → 指南唐故都金陵
- **不堪** → 不忍、承受不了
- **雕栏玉砌** → 指南唐宫殿的精美建筑
- **朱颜改** → 红润的容颜已经改变，暗指亡国
- **几多** → 多少
- **一江春水** → 比喻愁绪如春水般连绵不断

**背诵要点**

1."问君能有几多愁？恰似一江春水向东流"——千古名句，以水喻愁；2."春花秋月"本是美景，词人却问"何时了"，反衬亡国之痛；3."雕栏玉砌应犹在，只是朱颜改"——物是人非之叹；4.此词相传为李煜绝命词
