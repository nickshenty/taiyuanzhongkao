### ⚡ 物理：圆周运动1：匀速圆周运动基本概念

**概念复习**

匀速圆周运动是指物体沿圆周运动且线速度大小不变的运动。描述圆周运动的物理量：线速度v=2πr/T（方向沿切线），角速度ω=2π/T=2πf（单位rad/s），周期T、频率f=1/T。线速度与角速度的关系v=ωr。向心加速度a=v²/r=ω²r=ωv，方向始终指向圆心，描述速度方向变化的快慢。匀速圆周运动是变速运动（速度方向不断变化），加速度大小不变但方向变化，属于非匀变速运动。圆周运动的各物理量之间有确定的换算关系，熟练掌握v=ωr是解题的基础。

**公式**

1. 线速度：v = 2πr/T = ωr
2. 角速度：ω = 2π/T = 2πf
3. 向心加速度：a = v²/r = ω²r = ωv
4. 周期与频率：T = 1/f

**关键要点**

1. 线速度v=ωr，方向沿切线
2. 角速度ω=2π/T=2πf
3. 向心加速度a=v²/r=ω²r，指向圆心
4. 匀速圆周运动是变速运动（方向变），非匀变速
5. 周期T与频率f互为倒数：f=1/T

**作业练习指导**

今日做物理作业3的单选题部分。做题要点：①先确定圆周运动的半径和周期/角速度；②利用v=ωr进行线速度与角速度换算；③注意匀速圆周运动的加速度方向始终指向圆心。重点练习各物理量之间的换算关系和匀速圆周运动性质判断。

**易错提醒**

1. 认为匀速圆周运动是匀速运动（实际是变速运动）
2. 向心加速度方向误认为是切线方向
3. 混淆线速度和角速度的单位

## 📜 语文古诗文

### 短歌行
**东汉　· 曹操**

**原文**

> 对酒当歌，人生几何！譬如朝露，去日苦多。
> 慨当以慷，忧思难忘。何以解忧？唯有杜康。
> 青青子衿，悠悠我心。但为君故，沉吟至今。
> 呦呦鹿鸣，食野之苹。我有嘉宾，鼓瑟吹笙。
> 明明如月，何时可掇？忧从中来，不可断绝。
> 越陌度阡，枉用相存。契阔谈讌，心念旧恩。
> 月明星稀，乌鹊南飞。绕树三匝，何枝可依？
> 山不厌高，海不厌深。周公吐哺，天下归心。

**译文**

> 面对美酒应当高歌，人生能有多少岁月！就像早晨的露水，逝去的日子太多令人苦恼。
> 慷慨激昂，忧思难以忘怀。用什么来排解忧愁？只有美酒。
> 青青的是你的衣领，悠悠的是我的思念。只因为你的缘故，我沉吟思念直到如今。
> 鹿群呦呦鸣叫，吃着野地里的艾蒿。我有尊贵的客人，弹瑟吹笙来欢迎。
> 明亮如月的人才，什么时候才能得到？忧愁从中涌来，不可断绝。
> 穿过纵横的田间小路，劳驾你前来探望。久别重逢设宴畅谈，心中感念旧日的恩情。
> 月明星稀的夜晚，乌鹊向南飞去。绕着树飞了三圈，哪个枝头可以栖息？
> 山不嫌高，海不嫌深。像周公那样吐哺迎贤，天下人就会归心。

**注释**

- **几何** → 多少
- **朝露** → 早晨的露水，比喻人生短暂
- **慨当以慷** → 即"慷慨"，指情绪激昂
- **杜康** → 相传是酿酒的祖师，此处代指酒
- **青青子衿** → 出自《诗经·郑风》，借指贤才。衿，衣领
- **呦呦鹿鸣** → 出自《诗经·小雅·鹿鸣》，表示宴请宾客
- **苹** → 艾蒿
- **掇** → 拾取、摘取
- **越陌度阡** → 穿过田间小路。陌、阡均为田间小路
- **枉用相存** → 劳驾探望。枉，劳驾；存，问候
- **契阔** → 久别重逢
- **讌** → 通"宴"，宴饮
- **三匝** → 三圈。匝，周、圈
- **周公吐哺** → 周公为接待贤才"一沐三握发，一饭三吐哺"

**背诵要点**

1."对酒当歌，人生几何"——开篇感叹人生短暂；2."青青子衿，悠悠我心"——用《诗经》典故表达求贤之渴；3."月明星稀，乌鹊南飞"——名句，以乌鹊喻贤才择主；4."周公吐哺，天下归心"——用周公典故表达招揽天下人才的雄心；5.注意"掇""讌""匝"等字的写法
