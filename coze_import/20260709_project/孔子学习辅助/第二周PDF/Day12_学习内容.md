### ⚡ 物理：抛体运动2：检测复习

**概念复习**

抛体运动2检测复习：系统回顾平抛进阶、斜抛运动和综合应用。重点梳理：斜抛运动的分解（水平匀速+竖直匀变速）、射程公式x=v₀²sin2θ/g、最高点速度为v₀cosθ；平抛相遇问题的双方向联立条件；杆运动的速度分解约束；风洞中受恒力的抛体运动分析方法。实验部分回顾平抛轨迹分析的数据处理方法。复习时要对比平抛和斜抛的异同，整理常见题型的解题套路和易错点。平抛和斜抛都只受重力，区别在于初速度方向——平抛水平、斜抛有角度。射程公式v₀²sin2θ/g在θ=45°时最大。

**公式**

1. 斜抛全套：x=v₀cosθ·t, y=v₀sinθ·t-½gt²
2. 射程R=v₀²sin2θ/g, 最大高度H=v₀²sin²θ/(2g)

**关键要点**

1. 斜抛射程R=v₀²sin2θ/g，θ=45°最大
2. 斜抛最高点速度v=v₀cosθ（水平方向）
3. 相遇问题：两个方向方程联立+时间相等
4. 杆不变形：沿杆方向速度分量相等
5. 风洞恒力：水平方向匀变速运动

**作业练习指导**

今日复习物理作业2全部内容。复习策略：①回顾斜抛运动的核心公式和分解方法；②重做错题，特别是相遇问题和杆运动问题；③整理平抛和斜抛的解题套路。建议做一套自测题检验掌握程度，重点检查计算题的步骤完整性。

**易错提醒**

1. 斜抛最高点速度为零（应为v₀cosθ）
2. 射程公式用sinθ而非sin2θ
3. 杆运动忘记沿杆方向速度约束

## 📜 语文古诗文

### 青玉案·元夕
**宋　· 辛弃疾**

**原文**

> 东风夜放花千树，更吹落、星如雨。宝马雕车香满路。凤箫声动，玉壶光转，一夜鱼龙舞。
> 蛾儿雪柳黄金缕，笑语盈盈暗香去。众里寻他千百度，蓦然回首，那人却在，灯火阑珊处。

**译文**

> 东风仿佛在夜里吹开了千树繁花，又像吹落了如雨的繁星。华丽的马车驶过，满路飘香。凤箫声响起，月光流转，整夜鱼龙花灯飞舞。
> 姑娘们头上戴着蛾儿、雪柳、黄金缕等饰物，笑语盈盈地走过，留下暗暗的香气。在人群中寻找她千百遍，忽然回头，那人却在灯火稀疏冷落的地方。

**注释**

- **花千树** → 形容灯火繁多如花树
- **星如雨** → 形容焰火纷纷如雨
- **宝马雕车** → 华丽的马车
- **凤箫** → 箫的美称
- **玉壶** → 比喻月亮（一说指白玉灯）
- **鱼龙舞** → 鱼形龙形花灯飞舞
- **蛾儿雪柳** → 元代妇女头上的饰物
- **黄金缕** → 金色的丝带饰物
- **盈盈** → 仪态美好的样子
- **蓦然** → 忽然
- **阑珊** → 稀疏冷落

**背诵要点**

1."众里寻他千百度，蓦然回首，那人却在，灯火阑珊处"——千古名句，王国维评为人生最高境界；2."东风夜放花千树"——写元宵灯火之盛；3.那人"在灯火阑珊处"——自甘寂寞、不慕荣华的象征；4.注意"蓦然回首""灯火阑珊"的写法
