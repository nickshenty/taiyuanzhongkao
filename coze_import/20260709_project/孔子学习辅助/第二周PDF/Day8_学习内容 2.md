### ⚡ 物理：抛体运动2：平抛运动进阶

**概念复习**

平抛运动进阶讨论更复杂的情境：不同抛出点的平抛比较、半圆环上的平抛碰撞、跳台滑雪中的平抛运动等。关键要点：两个平抛物体同时抛出时，落地时间差由高度差决定；落到斜面上时，运动时间与斜面角度和初速度有关；在半圆环上的平抛，小球落点位置与初速度大小有关，v₀越大可能落到更高位置。分析时要善于利用几何关系建立方程。平抛进阶问题的核心在于灵活运用几何关系，将曲面、圆环等约束转化为运动方程。半圆环上平抛时v₀越大落点越高，但小球不可能垂直撞击圆环。

**公式**

1. 落到斜面：tanθ = ½gt² / (v₀t) = gt/(2v₀)
2. 圆环碰撞条件：x² + (R-y)² = R²

**关键要点**

1. 同时抛出的平抛，时间差由高度差决定
2. 落到斜面上的平抛，利用tanθ=y/x建立方程
3. 半圆环平抛：v₀不同落点不同，落到最低点C时间最长
4. 小球不可能垂直撞击半圆环（速度方向不沿半径）
5. v₀足够大时小球可能不落在圆环上

**作业练习指导**

今日做物理作业2的单选题部分。做题要点：①比较两个平抛运动时，先确定时间关系（由高度决定）；②落到圆环或曲面上的问题，利用几何方程（圆方程）联立运动方程；③注意"不可能"类题目可用极端情况分析。重点练习半圆环平抛和跳台滑雪问题。

**易错提醒**

1. 认为v₀越大运动时间越长（在斜面上时间与v₀有关，但在水平面上无关）
2. 半圆环问题中忽略圆的几何约束
3. 忘记验证物理量的合理性

## 📜 语文古诗文

### 登岳阳楼
**唐　· 杜甫**

**原文**

> 昔闻洞庭水，今上岳阳楼。
> 吴楚东南坼，乾坤日夜浮。
> 亲朋无一字，老病有孤舟。
> 戎马关山北，凭轩涕泗流。

**译文**

> 从前就听说洞庭湖的盛名，今天终于登上了岳阳楼。
> 吴楚两地向东南分裂开来，天地日月日夜在湖中浮动。
> 亲戚朋友没有一个字的音信，年老多病只有一只孤舟相伴。
> 北方关山一带还有战事，靠着栏杆不禁涕泪横流。

**注释**

- **洞庭水** → 洞庭湖
- **坼** → 分裂、裂开
- **乾坤** → 天地、日月
- **浮** → 浮动
- **无一字** → 没有一点音信
- **戎马** → 战马，借指战争
- **关山北** → 北方边境，指当时吐蕃入侵
- **凭轩** → 靠着窗户或栏杆
- **涕泗** → 眼泪和鼻涕

**背诵要点**

1."吴楚东南坼，乾坤日夜浮"——名句，写洞庭湖的壮阔景象；2."坼"字易写错，意为分裂；3."亲朋无一字，老病有孤舟"——个人身世之悲；4."戎马关山北"——由个人之悲推及家国之忧；5.全诗由景及情，层层推进
