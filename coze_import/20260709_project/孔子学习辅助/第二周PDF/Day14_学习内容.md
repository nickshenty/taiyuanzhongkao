### ⚡ 物理：圆周运动1：向心力与向心加速度

**概念复习**

向心力是使物体做圆周运动的合外力，方向指向圆心，大小F=mv²/r=mω²r。向心力是效果力，由某个或几个力提供，不是额外施加的力。分析圆周运动问题时，先确定圆心位置和半径，再进行受力分析，将各力沿半径方向和切线方向分解，半径方向的合力即为向心力。常见提供向心力的力：绳的拉力、重力分量、支持力分量、摩擦力等。向心加速度a=F/m=v²/r，描述速度方向变化的快慢。向心力分析的关键是确定圆心位置和半径方向，然后将各力沿径向和切向分解。

**公式**

1. 向心力：F = mv²/r = mω²r
2. 向心加速度：a = F/m = v²/r = ω²r

**关键要点**

1. 向心力F=mv²/r=mω²r，指向圆心
2. 向心力是效果力，由其他力提供，不是额外力
3. 分析步骤：定圆心→受力分析→沿径向分解→ΣF径=mv²/r
4. 绳拉力、重力分量、摩擦力等都可提供向心力
5. 向心加速度a=v²/r，只改变速度方向不改变大小

**作业练习指导**

今日做物理作业3的多选题和实验题。多选题注意：①向心力是效果力不是真实力；②匀速圆周运动切线方向合力为零。实验题（向心力探究实验）：注意控制变量法、传感器数据读取。重点练习向心力的来源分析和方程列写。

**易错提醒**

1. 把向心力当作一个额外的力来受力分析
2. 圆心位置判断错误导致半径方向搞反
3. 匀速圆周运动中切线方向合力为零（容易忽略）

## 📜 语文古诗文

### 归园田居·其一
**东晋　· 陶渊明**

**原文**

> 少无适俗韵，性本爱丘山。误落尘网中，一去三十年。
> 羁鸟恋旧林，池鱼思故渊。开荒南野际，守拙归园田。
> 方宅十余亩，草屋八九间。榆柳荫后檐，桃李罗堂前。
> 暧暧远人村，依依墟里烟。狗吠深巷中，鸡鸣桑树颠。
> 户庭无尘杂，虚室有余闲。久在樊笼里，复得返自然。

**译文**

> 从小就没有迎合世俗的性格，天性本来就喜爱山林。误落入世俗的罗网中，一去就是三十年。
> 关在笼中的鸟依恋从前居住的树林，养在池中的鱼思念曾经生活的深潭。在南边田野的边界开垦荒地，安守本分回归田园。
> 住宅方圆有十余亩地，茅草屋有八九间。榆树柳树遮蔽着后屋檐，桃树李树排列在堂屋前。
> 远处的村落依稀可见，村落里的炊烟袅袅上升。狗在深巷中吠叫，鸡在桑树顶端啼鸣。
> 门庭里没有世俗杂事，空静的居室有充足的闲暇。长久地被关在樊笼里，如今终于能够重返自然。

**注释**

- **适俗韵** → 迎合世俗的性格、气质
- **尘网** → 世俗的罗网，指官场
- **三十年** → 一说为十三年之误
- **羁鸟** → 关在笼中的鸟
- **守拙** → 安守本分，不随波逐流
- **方宅** → 住宅周围。方，四周
- **暧暧** → 昏暗、依稀可见的样子
- **依依** → 轻柔的样子
- **墟里** → 村落
- **樊笼** → 鸟笼，比喻官场

**背诵要点**

1."羁鸟恋旧林，池鱼思故渊"——名句，比喻自己对田园的向往；2."暧暧远人村，依依墟里烟"——写田园风光之美；3."久在樊笼里，复得返自然"——点题之句，表达回归自然的喜悦；4."狗吠深巷中，鸡鸣桑树颠"——化用汉乐府《鸡鸣》之意；5.注意"暧暧"不要写成"暖暖"
