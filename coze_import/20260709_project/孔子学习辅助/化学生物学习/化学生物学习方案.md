## 二、化学学习方案

### 2.1 高一化学知识点+高考高频考点清单

#### 专题一：离子反应与氧化还原反应 ★★★★★
**高考出题频率：几乎每年必考，选择题+大题**

1. **电解质与非电解质**
   - 电解质：水溶液中或熔融状态下能导电的化合物（酸、碱、盐、活泼金属氧化物）
   - 非电解质：水溶液和熔融状态下都不能导电的化合物（蔗糖、酒精、SO₂、NH₃等）
   - 注意：单质、混合物既不是电解质也不是非电解质

2. **强电解质与弱电解质**
   - 强电解质：强酸（HCl、H₂SO₄、HNO₃、HClO₄、HBr、HI）、强碱[NaOH、KOH、Ca(OH)₂、Ba(OH)₂]、大多数盐
   - 弱电解质：弱酸（CH₃COOH、H₂CO₃、H₂SO₃、HClO、HF、H₂S）、弱碱（NH₃·H₂O、Cu(OH)₂、Fe(OH)₃）、水

3. **电离方程式书写**

4. **离子方程式书写四步法**
   - 写→拆→删→查
   - 不拆的：气体、沉淀、水、弱酸、弱碱、氧化物、单质
   - 拆的：强酸、强碱、可溶性盐

5. **离子共存问题**
   - 发生复分解反应（生成沉淀/气体/水）不能共存
   - 发生氧化还原反应不能共存
   - 发生双水解不能共存
   - 常见沉淀：AgCl、AgBr、AgI、BaSO₄、CaCO₃、BaCO₃、Mg(OH)₂、Cu(OH)₂、Fe(OH)₃等

6. **氧化还原反应基本概念**
   - 氧化剂→得电子→化合价降低→被还原→发生还原反应→生成还原产物
   - 还原剂→失电子→化合价升高→被氧化→发生氧化反应→生成氧化产物

7. **电子转移表示法**
   - 双线桥法、单线桥法

8. **氧化还原方程式配平**
   - 化合价升降法、电子守恒法

9. **氧化还原反应规律**
   - 强氧化剂+强还原剂→弱氧化产物+弱还原产物
   - 先强后弱律、价态归中律、歧化反应

#### 专题二：化学反应速率与化学平衡 ★★★★★
**高考出题频率：几乎每年必考，大题核心**（申奇峰期末薄弱点，重点突破）

1. **化学反应速率**
   - 概念与计算：v=Δc/Δt
   - 影响因素：浓度、温度、压强、催化剂、表面积
   - 速率常数k

2. **化学平衡**
   - 概念：可逆反应达到正逆反应速率相等的状态
   - 特征：等（v正=v逆）、动（动态平衡）、定（各组分浓度不变）、变（条件改变平衡移动）
   - 平衡标志判断

3. **化学平衡移动**
   - 勒夏特列原理：改变影响平衡的条件，平衡向减弱该改变的方向移动
   - 浓度影响、温度影响、压强影响

4. **平衡常数K与浓度商Q**
   - K的表达式与意义
   - Q<K：反应正向进行；Q>K：反应逆向进行；Q=K：平衡

5. **转化率计算**

6. **等效平衡**

7. **化工生产中的速率与平衡**
   - 合成氨工业条件选择
   - SO₂催化氧化

#### 专题三：非金属及其化合物 ★★★★☆
**高考出题频率：常出现在化工流程题和实验题中**

1. **硅及其化合物**
   - Si→SiO₂→H₂SiO₃→硅酸盐
   - SiO₂的性质（酸性氧化物、与HF反应）
   - 硅酸盐工业（玻璃、水泥、陶瓷）

2. **氯及其化合物**
   - Cl₂的性质（黄绿色、有毒、与金属/非金属/水/碱反应）
   - Cl₂的实验室制法（MnO₂+浓HCl）
   - HClO的性质（弱酸、强氧化性、漂白性）
   - 漂白粉[Ca(ClO)₂+CaCl₂]

3. **硫及其化合物**
   - S→SO₂→SO₃→H₂SO₄
   - SO₂的性质（酸性氧化物、漂白性、还原性）
   - 浓H₂SO₄的特性（吸水性、脱水性、强氧化性）

4. **氮及其化合物**
   - N₂→NH₃→NO→NO₂→HNO₃

   - HNO₃的性质（强氧化性、不稳定性）
   - 氮的氧化物与水反应

### 2.2 化学记忆方法推荐

#### 方法一：化学方程式记忆法
- **分类记忆**：按反应类型分类（化合、分解、置换、复分解、氧化还原）
- **规律记忆**：抓住反应规律，如"强制弱"规律、"强酸制弱酸"
- **配平口诀**：氧化还原用电子守恒法，先配化合价变化的元素
- **联想记忆**：将反应条件与产物联想（如"点燃"对应CO₂+H₂O）

#### 方法二：元素化合物知识网络法
- 以元素为中心，构建"单质→氧化物→酸/碱→盐"转化线
- 钠系：Na→Na₂O→Na₂O₂→NaOH→Na₂CO₃↔NaHCO₃
- 铁系：Fe→FeO/Fe₂O₃→Fe(OH)₂/Fe(OH)₃→Fe²⁺↔Fe³⁺
- 铝系：Al→Al₂O₃→Al(OH)₃→Al³⁺/AlO₂⁻

#### 方法三：实验现象记忆技巧
- **颜色口诀**：Cu²⁺蓝色、Fe²⁺浅绿色、Fe³⁺黄色、MnO₄⁻紫色
- **特征现象**：沉淀颜色（白色AgCl/BaSO₄、蓝色Cu(OH)₂、红褐色Fe(OH)₃、白色Fe(OH)₂变灰绿变红褐）
- **气体特征**：H₂S臭鸡蛋味、Cl₂黄绿刺激性、NH₃刺激味、NO₂红棕色

#### 方法四：口诀/联想记忆法
- **溶解性口诀**：钾钠铵硝溶水快，硫酸除钡铅钙银，盐酸除银亚汞铅，碳酸只溶钾钠铵
- **化合价口诀**：一价氢氯钾钠银，二价氧钙钡镁锌，三铝四硅五价磷，二三铁、二四碳，二四六硫都齐全
- **强酸记忆**：硫硝盐酸氢溴碘（H₂SO₄、HNO₃、HCl、HBr、HI）+ HClO₄
- **强碱记忆**：钾钠钙钡（KOH、NaOH、Ca(OH)₂、Ba(OH)₂）

## 三、生物学习方案

### 3.1 高一生物知识点+高考高频考点清单

#### 专题一：遗传的基本规律 ★★★★★
**高考出题频率：几乎每年必考大题**（申奇峰期末考了必修二，需巩固）

1. **孟德尔遗传实验方法**：杂交、自交、测交
2. **分离定律**
   - 一对相对性状的遗传实验
   - 基因型与表现型
   - 3:1比例及变式（完全显性、不完全显性、共显性）
   - 测交验证
3. **自由组合定律**
   - 两对相对性状的遗传实验
   - 9:3:3:1比例及16种变式
4. **遗传概率计算**
   - 乘法原理、加法原理
   - 概率计算常见题型
5. **基因互作**

#### 专题二：细胞代谢（光合作用、呼吸作用）★★★★★
**高考出题频率：高频大题，实验探究题常考**

1. **酶**
   - 本质：绝大多数是蛋白质，少数是RNA
   - 特性：高效性、专一性、温和性（需要适宜条件）
   - 影响酶活性的因素：温度、pH
2. **ATP**
   - 结构（A-P~P~P）
   - ATP-ADP循环
   - ATP与能量供应
3. **细胞呼吸**
   - 有氧呼吸三阶段（糖酵解→三羧酸循环→电子传递链）
   - 无氧呼吸（酒精发酵/乳酸发酵）
   - 影响因素：温度、O₂浓度、含水量
4. **光合作用**
   - 光反应：水的光解、ATP/NADPH生成
   - 暗反应：CO₂固定（C₃→C₅+C₃）、C₃还原
   - 影响因素：光照强度、CO₂浓度、温度
5. **光合与呼吸综合**
   - 净光合速率=总光合速率-呼吸速率
   - O₂释放量、CO₂吸收量、有机物积累量的关系

#### 专题三：遗传的分子基础 ★★★★☆
**高考出题频率：常与遗传规律结合**

1. **DNA是主要遗传物质**
   - 肺炎双球菌转化实验（格里菲思+艾弗里）
   - 噬菌体侵染细菌实验（赫尔希和蔡斯）

## 五、Day 1（7月6日，周一）化学具体任务

### 5.1 今日主题：离子反应（电解质、电离、离子方程式书写）

### 5.2 知识点清单（请阅览回顾，10:00-10:15）

**1. 电解质与非电解质**
- 电解质：在水溶液中或熔融状态下能导电的化合物
  - 包括：酸（HCl、H₂SO₄、CH₃COOH）、碱（NaOH、NH₃·H₂O）、盐（NaCl、BaSO₄）、活泼金属氧化物（Na₂O、Al₂O₃）
- 非电解质：在水溶液和熔融状态下都不能导电的化合物
  - 包括：蔗糖、酒精、SO₂、SO₃、NH₃、CO₂
- ⚠️ 注意：
  - 单质（如Cu、Cl₂）和混合物（如盐酸、NaOH溶液）既不是电解质也不是非电解质
  - CO₂溶于水能导电，但CO₂是非电解质（导电是因为生成了H₂CO₃）

**2. 强电解质 vs 弱电解质**
| | 强电解质 | 弱电解质 |
|--|---------|---------|
| 定义 | 溶于水后完全电离 | 溶于水后部分电离 |
| 强酸 | HCl、H₂SO₄、HNO₃、HClO₄、HBr、HI | CH₃COOH、H₂CO₃、H₂SO₃、HClO、HF、H₂S |
| 强碱 | NaOH、KOH、Ca(OH)₂、Ba(OH)₂ | NH₃·H₂O、Cu(OH)₂、Fe(OH)₃ |
| 盐 | 绝大多数盐 | — |
| 其他 | 水 | — |

**3. 离子方程式书写四步法**
- **写**：写出正确的化学方程式
- **拆**：把强酸、强碱、可溶性盐拆成离子形式
- **删**：删去等号两边相同的离子
- **查**：检查质量守恒和电荷守恒

**拆与不拆的规则**：
| 不拆 | 拆 |
|------|---|
| 气体（↑） | 强酸 |
| 沉淀（↓） | 强碱 |
| 水 | 可溶性盐 |
| 弱酸、弱碱 | |
| 氧化物 | |
| 单质 | |

**4. 常见沉淀速记**
- 白色：AgCl、AgBr（淡黄）、BaSO₄、CaCO₃、BaCO₃、Mg(OH)₂、Al(OH)₃、Zn(OH)₂
- 蓝色：Cu(OH)₂
- 红褐色：Fe(OH)₃
- 浅绿色→灰绿→红褐色：Fe(OH)₂（氧化过程）

3. **背诵溶解性口诀**：钾钠铵硝溶水快，硫酸除钡铅钙银，盐酸除银亚汞铅，碳酸只溶钾钠铵
