# 一、数学学习方案

## 1.1 高一数学知识点清单（按章节）

### 第一章 集合与常用逻辑用语

- **集合的概念与表示**：元素与集合的关系（∈/∉）、集合的表示方法（列举法、描述法、Venn图法）
- **集合间的基本关系**：子集（⊆）、真子集（⊊）、相等（=）、空集（∅）的含义与判定
- **集合的基本运算**：交集（∩）、并集（∪）、补集（∁UA）的定义与运算性质
- **充分条件与必要条件**：p⇒q 的含义；充分不必要、必要不充分、充要、既不充分也不必要的判断
- **全称量词与存在量词**：∀（对所有）、∃（存在）；含量词命题的否定
- **核心公式/结论**：
  - |A∪B| = |A| + |B| − |A∩B|
  - ∅是任何集合的子集，是任何非空集合的真子集
  - ⌀∪A = A，⌀∩A = ⌀

### 第二章 函数概念与基本初等函数

- **函数的概念**：定义域、值域、对应法则；函数的三要素；同一函数的判定
- **函数的表示方法**：解析法、列表法、图像法；分段函数
- **函数的基本性质**：
  - 单调性：增函数/减函数的定义与判定；用定义法证明单调性
  - 奇偶性：f(−x)=f(x)（偶）、f(−x)=−f(x)（奇）；定义域关于原点对称是前提
  - 周期性：f(x+T)=f(x)
  - 对称性：f(a+x)=f(a−x) ⇒ 关于 x=a 对称
- **二次函数**：y=ax²+bx+c（a≠0）；顶点坐标、对称轴、开口方向；三种解析式（一般式/顶点式/零点式）
- **指数与指数函数**：
  - 分数指数幂的运算性质
  - y=aˣ（a>0, a≠1）：定义域 R，值域 (0,+∞)，过定点 (0,1)，单调性取决于底数 a
- **对数与对数函数**：
  - 对数的定义与换底公式：logₐb = lnb/lna
  - 对数运算性质：logₐ(MN)=logₐM+logₐN，logₐ(Mⁿ)=n·logₐM
  - y=logₐx（a>0, a≠1）：定义域 (0,+∞)，值域 R，过定点 (1,0)
- **幂函数**：y=xᵃ；常见幂函数（x¹, x², x³, x⁻¹, x^(1/2)）的图像与性质
- **函数与方程**：零点存在定理（f(a)·f(b)<0 且连续 ⇒ 有零点）；二分法
- **核心公式/结论**：
  - 指对互化：aᵇ=N ⇔ logₐN=b
  - 换底公式：logₐb = logcb / logca
  - f(x)零点个数 ⇔ f(x)图像与 x 轴交点个数

### 第三章 三角函数

- **任意角与弧度制**：正角/负角/零角；弧度与角度互换（π rad = 180°）；扇形面积公式 S=½|α|r²
- **三角函数定义**：单位圆定义 sin/cos/tan；各象限符号；特殊角值（0, π/6, π/4, π/3, π/2 等）
- **同角三角函数基本关系**：
  - sin²α + cos²α = 1
  - sinα/cosα = tanα
- **诱导公式**：口诀"奇变偶不变，符号看象限"；π±α、2π±α、−α、π/2±α 的变换
- **三角函数的图像与性质**：
  - y=sinx, y=cosx, y=tanx 的图像、周期、单调区间、对称轴/对称中心
  - y=Asin(ωx+φ)：振幅A、周期T=2π/|ω|、初相φ、相位变换
- **三角恒等变换**：
  - 两角和差公式：cos(α±β), sin(α±β), tan(α±β)
  - 二倍角公式：sin2α, cos2α, tan2α
  - 半角公式、辅助角公式：a·sinx + b·cosx = √(a²+b²)·sin(x+φ)，其中 tanφ=b/a
- **核心公式/结论**：
  - sin(α+β) = sinαcosβ + cosαsinβ
  - cos(α+β) = cosαcosβ − sinαsinβ
  - cos2α = cos²α − sin²α = 2cos²α−1 = 1−2sin²α

### 第四章 数列

- **数列的概念**：通项公式 aₙ、前 n 项和 Sₙ；aₙ 与 Sₙ 的关系：aₙ = Sₙ − Sₙ₋₁（n≥2），a₁ = S₁
- **等差数列**：
  - 定义：aₙ₊₁ − aₙ = d（常数）
  - 通项公式：aₙ = a₁ + (n−1)d
  - 前 n 项和：Sₙ = n(a₁+aₙ)/2 = na₁ + n(n−1)d/2
  - 性质：若 m+n=p+q，则 aₘ+aₙ = aₚ+aq
- **等比数列**：
  - 定义：aₙ₊₁/aₙ = q（常数，q≠0）
  - 通项公式：aₙ = a₁·qⁿ⁻¹
  - 前 n 项和：Sₙ = a₁(1−qⁿ)/(1−q)（q≠1），Sₙ = na₁（q=1）
  - 性质：若 m+n=p+q，则 aₘ·aₙ = aₚ·aq
- **数列求和方法**：
  - 分组求和法
  - 裂项相消法：1/[n(n+1)] = 1/n − 1/(n+1)
  - 错位相减法（适用于等差×等比型）
  - 倒序相加法
- **核心公式/结论**：
  - 等差中项：a, b, c 成等差 ⇔ 2b = a+c
  - 等比中项：a, b, c 成等比 ⇔ b² = ac（abc 同号）

### 第五章 平面向量

- **向量的概念**：有向线段；零向量、单位向量、平行向量（共线向量）、相等向量
- **向量的线性运算**：
  - 加法：三角形法则、平行四边形法则
  - 减法：a − b = a + (−b)
  - 数乘：λa 的方向与模
- **共线定理**：a∥b（b≠0）⇔ 存在唯一实数 λ，使 a=λb
- **平面向量基本定理**：若 e₁, e₂ 不共线，则平面内任一向量 a 可唯一表示为 a=λe₁+μe₂
- **向量的坐标表示**：a=(x,y)；坐标运算：a±b=(x₁±x₂, y₁±y₂)，λa=(λx, λy)
- **数量积（点积）**：
  - 定义：a·b = |a||b|cosθ
  - 坐标运算：a·b = x₁x₂ + y₁y₂
  - 夹角公式：cosθ = (a·b)/(|a||b|)
  - 垂直条件：a⊥b ⇔ a·b = 0 ⇔ x₁x₂+y₁y₂=0
  - |a|² = a·a = x²+y²
- **核心公式/结论**：
  - |a| = √(x²+y²)
  - 两点间距离：|AB| = √[(x₂−x₁)²+(y₂−y₁)²]

### 第六章 立体几何 ⚠️【薄弱点·重点突破】

- **空间几何体**：
  - 棱柱、棱锥、棱台的结构特征
  - 圆柱、圆锥、圆台、球的结构特征
  - 三视图：正视图、侧视图、俯视图的画法与还原
  - 直观图：斜二测画法
- **表面积与体积公式**：
  - 柱体：S侧=Ch，V=Sh
  - 锥体：V=⅓Sh
  - 台体：V=⅓h(S₁+√(S₁S₂)+S₂)
  - 球：S=4πR²，V=(4/3)πR³
- **点、直线、平面之间的位置关系**：
  - 平面的基本性质：三个公理（确定平面的条件）
  - 空间中直线与直线的位置关系：相交、平行、异面
  - 异面直线所成角、空间四边形
- **线面平行**：
  - 判定定理：平面外一条直线与平面内一条直线平行 ⇒ 该直线与此平面平行
  - 性质定理：一条直线与一个平面平行，过该直线的平面与此平面相交 ⇒ 交线与该直线平行
- **线面垂直**：
  - 判定定理：一条直线与平面内两条相交直线都垂直 ⇒ 该直线与此平面垂直
  - 性质定理：垂直于同一平面的两条直线平行
- **面面平行与面面垂直**：
  - 面面平行判定：一个平面内两条相交直线分别平行于另一个平面 ⇒ 两平面平行
  - 面面垂直判定：一个平面经过另一个平面的一条垂线 ⇒ 两平面垂直
  - 面面垂直性质：两平面垂直，一个平面内垂直于交线的直线垂直于另一个平面
- **空间角计算**：
  - 线面角：直线与平面所成的角（斜线与射影的夹角）
  - 二面角：二面角的平面角
- **空间向量法（选学/提高）**：
  - 空间向量坐标运算
  - 法向量求法与应用
  - 用向量法求线面角、二面角
- **核心公式/结论**：
  - 线面角 sinθ = |方向向量·法向量| / (|方向向量|·|法向量|)
  - 二面角 cosθ = |法向量₁·法向量₂| / (|法向量₁|·|法向量₂|)

### 第七章 概率与统计 ⚠️【薄弱点·首要攻坚】

- **随机事件与概率**：
  - 随机试验、样本空间、样本点、随机事件
  - 事件的关系：包含、并（和事件）、交（积事件）、互斥、对立
  - 概率的基本性质：P(A∪B) = P(A)+P(B)−P(A∩B)；互斥时 P(A∪B)=P(A)+P(B)；对立事件 P(A)+P(Ā)=1
- **古典概型**：
  - 特征：有限性、等可能性
  - 公式：P(A) = 事件A包含的样本点数 / 样本空间总数
- **概率的基本性质与运算**：
  - 加法公式：P(A∪B) = P(A) + P(B) − P(A∩B)
  - 互斥事件：P(A∪B) = P(A) + P(B)
  - 对立事件：P(Ā) = 1 − P(A)
- **条件概率**：
  - 定义：P(B|A) = P(A∩B) / P(A)
  - 含义：在事件A已发生的条件下事件B发生的概率
- **全概率公式**：
  - 若 B₁, B₂, ..., Bₙ 为样本空间的一个划分，则 P(A) = Σ P(Bᵢ)·P(A|Bᵢ)
- **贝叶斯公式**（了解）：
  - P(Bₖ|A) = P(Bₖ)·P(A|Bₖ) / P(A)
- **独立性**：
  - A与B独立 ⇔ P(A∩B) = P(A)·P(B)
  - 独立重复试验（n次独立重复试验）
- **离散型随机变量及其分布**：
  - 随机变量 X 的概念
  - 分布列：P(X=xᵢ) = pᵢ，Σpᵢ = 1
  - 数学期望：E(X) = Σ xᵢ·pᵢ
  - 方差：D(X) = Σ (xᵢ−E(X))²·pᵢ = E(X²) − [E(X)]²
  - 性质：E(aX+b) = aE(X)+b；D(aX+b) = a²D(X)
- **二项分布**：
  - n次独立重复试验，每次成功概率 p
  - X~B(n,p)：P(X=k) = C(n,k)·pᵏ·(1-p)ⁿ⁻ᵏ
  - E(X) = np，D(X) = np(1-p)
- **超几何分布**：
  - N件产品中含M件次品，无放回抽取n件，X为次品数
  - P(X=k) = C(M,k)·C(N−M, n−k) / C(N, n)
- **正态分布**：
  - X~N(μ, σ²)：概率密度曲线关于 x=μ 对称
  - 3σ原则：P(μ−σ < X < μ+σ) ≈ 0.683；P(μ−2σ < X < μ+2σ) ≈ 0.954；P(μ−3σ < X < μ+3σ) ≈ 0.997
- **统计基础**：
  - 抽样方法：简单随机抽样、分层抽样、系统抽样
  - 样本均值 x̄、样本方差 s²、样本标准差 s
  - 经验回归方程：ŷ = b̂x + â，其中 b̂ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
  - 相关系数 r：|r|越接近1，线性相关性越强
  - 独立性检验（2×2列联表）：χ²统计量，对照临界值表判断是否有关联
- **核心公式/结论**：
  - 期望线性性质：E(aX+bY) = aE(X)+bE(Y)
  - X~B(n,p) 时 E(X)=np，D(X)=np(1−p)
  - 正态分布 3σ 原则三个概率值

# 二、物理学习方案

## 2.1 高一物理知识点清单（按章节）

### 第一章 运动学（直线运动）

- **质点、参考系、坐标系**：质点的概念与简化条件；参考系的选择；一维坐标系
- **时间和位移**：时刻与时间间隔的区别；路程与位移的区别（标量vs矢量）
- **速度与加速度**：
  - 速度 v = Δx/Δt（矢量）；速率 = |v|（标量）
  - 加速度 a = Δv/Δt（矢量）；a 的方向与 Δv 方向一致
  - v、a 方向关系：同向加速，反向减速
- **匀变速直线运动**：
  - 速度公式：v = v₀ + at
  - 位移公式：x = v₀t + ½at²
  - 速度-位移公式：v² − v₀² = 2ax
  - 平均速度公式：v̄ = (v₀+v)/2 = v(t/2)
  - 中间时刻速度 = 平均速度
- **重要推论**：
  - 连续相等时间间隔 T 内位移差：Δx = x₂ − x₁ = aT²（逐差法）
  - 初速度为零的匀加速直线运动比例关系：
    - 1s末、2s末、3s末速度比 v₁:v₂:v₃ = 1:2:3
    - 1s内、2s内、3s内位移比 x₁:x₂:x₃ = 1:4:9
    - 第1s内、第2s内、第3s内位移比 Δx₁:Δx₂:Δx₃ = 1:3:5
- **自由落体运动**：v₀=0, a=g=9.8m/s²；v=gt, h=½gt², v²=2gh
- **运动图像**：
  - x-t 图像：斜率 = 速度
  - v-t 图像：斜率 = 加速度；面积 = 位移
- **追及与相遇问题**：
  - 速度相等时距离最大/最小（临界条件）
  - 位移关系方程；画 v-t 图辅助分析

### 第二章 力与牛顿运动定律

- **三种常见力**：
  - 重力：G=mg，方向竖直向下；g≈9.8m/s²
  - 弹力：胡克定律 F=kx（弹簧）；方向垂直接触面（或沿绳）
  - 摩擦力：
    - 滑动摩擦力 f=μN（μ为动摩擦因数）
    - 静摩擦力：0 ≤ f ≤ f_max，大小由平衡条件决定
    - 方向：与相对运动（或相对运动趋势）方向相反
- **力的合成与分解**：
  - 平行四边形定则 / 三角形定则
  - 合力范围：|F₁−F₂| ≤ F合 ≤ F₁+F₂
  - 正交分解法：将力分解到 x、y 两个方向
- **受力分析**：整体法与隔离法；受力分析的一般步骤
- **牛顿三大定律**：
  - 第一定律（惯性定律）：物体不受力或受合外力为零时保持静止或匀速直线运动
  - 第二定律：F合 = ma（合外力方向与加速度方向一致）
  - 第三定律：作用力与反作用力大小相等、方向相反、作用在不同物体上
- **牛顿定律的应用**：
  - 已知受力求运动：F→a→v,x
  - 已知运动求受力：v,x→a→F
  - 超重与失重：
    - 加速度向上 → 超重（视重 > 实重）
    - 加速度向下 → 失重（视重 < 实重）
    - 自由落体 → 完全失重（视重 = 0）
  - 连接体问题：整体法求加速度，隔离法求内力
- **核心公式/结论**：
  - F合 = ma
  - 滑动摩擦力 f = μN
  - 胡克定律 F = kx

### 第三章 曲线运动 ⚠️【薄弱点·第二重点】

- **曲线运动的基本概念**：
  - 曲线运动中速度方向沿切线方向
  - 做曲线运动的条件：合外力方向与速度方向不在同一直线上
  - 合外力指向轨迹凹侧
- **运动的合成与分解**：
  - 分运动与合运动的等时性、独立性
  - 小船渡河问题：最短时间（船头垂直河岸）、最短位移（合速度垂直河岸）
- **平抛运动**：
  - 水平方向：匀速直线运动 vx = v₀, x = v₀t
  - 竖直方向：自由落体 vy = gt, y = ½gt²
  - 合速度：v = √(v₀² + (gt)²)，方向 tanθ = vy/vx = gt/v₀
  - 合位移：s = √(x² + y²)
  - 重要推论：任意时刻速度方向与水平方向夹角的正切 = 位移方向与水平方向夹角正切的 2 倍
  - 速度反向延长线交水平位移的中点
- **圆周运动**：
  - 描述量：线速度 v、角速度 ω、周期 T、频率 f、转速 n
  - 关系式：v = ωr, ω = 2π/T, v = 2πr/T, f = 1/T
  - 向心加速度：aₙ = v²/r = ω²r = ωv
  - 向心力：Fₙ = mv²/r = mω²r（方向始终指向圆心，是效果力不是真实存在的力）
  - 匀速圆周运动：向心力 = 合外力
  - 变速圆周运动：向心力是合外力沿径向的分量
- **圆周运动的临界问题**：
  - 绳模型（最高点最小速度）：mg = mv²/r ⇒ v_min = √(gr)
  - 杆模型（最高点最小速度）：v_min = 0；杆可以提供支持力
  - 汽车过拱桥最高点：mg − N = mv²/r，N=0 时 v = √(gr)（飞离条件）
  - 水平面圆周运动（圆锥摆）：tanθ = v²/(gr)
- **核心公式/结论**：
  - 平抛：t = √(2y/g)，水平射程 x = v₀·√(2y/g)
  - 向心加速度 a = v²/r = ω²r
  - 向心力 F = mv²/r = mω²r

### 第四章 万有引力与航天 ⚠️【薄弱点·第二重点】

- **开普勒三大定律**：
  - 第一定律（轨道定律）：行星沿椭圆轨道运动，太阳在焦点上
  - 第二定律（面积定律）：相同时间扫过相同面积（近日点快，远日点慢）
  - 第三定律（周期定律）：a³/T² = k（a为半长轴，T为周期，k与中心天体有关）
- **万有引力定律**：
  - F = G·m₁m₂/r²，G = 6.67×10⁻¹¹ N·m²/kg²
  - 适用于两个质点（或均匀球体，r为球心间距）
- **万有引力与重力的关系**：
  - 在地球表面（忽略自转）：mg = GMm/R² ⇒ g = GM/R²
  - 黄金代换公式：GM = gR²
- **卫星运动**：
  - 轨道半径 r 越大：v 越小、ω 越小、T 越大、a 越小
  - 第一宇宙速度（最大环绕速度/最小发射速度）：v₁ = √(GM/R) = √(gR) ≈ 7.9km/s
  - 第二宇宙速度：v₂ = 11.2km/s（脱离地球引力）
  - 第三宇宙速度：v₃ = 16.7km/s（脱离太阳引力）
  - 同步卫星特点：T=24h，轨道在赤道上方，h≈36000km
- **变轨问题**：
  - 低轨→高轨：加速（离心运动），新轨道速度更小但机械能更大
  - 高轨→低轨：减速（向心运动），新轨道速度更大但机械能更小
  - 轨道相切点的速度比较
- **双星系统**：
  - 两颗星绕连线上的某点做圆周运动，周期相同
  - m₁r₁ = m₂r₂（质量大的轨道半径小）
  - Gm₁m₂/L² = m₁·(2π/T)²·r₁ = m₂·(2π/T)²·r₂
- **核心公式/结论**：
  - 轨道速度 v = √(GM/r)
  - 周期 T = 2π√(r³/GM)
  - 表面重力 g = GM/R²
  - 黄金代换 GM = gR²

### 第五章 功和能 ⚠️【薄弱点·首要攻坚】

- **功**：
  - 定义：W = Flcosα（F为恒力，l为位移，α为力与位移的夹角）
  - 功的正负：0°≤α<90° → 正功；α=90° → 不做功；90°<α≤180° → 负功
  - 总功 = 各力做功的代数和：W总 = ΣWᵢ
  - 变力做功：图像法（F-l 图面积）、动能定理法、微元法
  - 一对作用力与反作用力做功的代数和不一定为零
- **功率**：
  - 平均功率：P̄ = W/t
  - 瞬时功率：P = Fvcosα（F与v同向时 P=Fv）
  - 额定功率与实际功率
  - 汽车启动问题：
    - 恒定功率启动：a↓→v↑→当F=f时a=0，达到最大速度 v_max = P/f
    - 恒定加速度启动：F不变，v↑→P↑→当P=P额时进入恒功率阶段
- **动能**：Ek = ½mv²（标量，非负值）
- **动能定理**：
  - 合外力做的功等于物体动能的变化量
  - W总 = ΔEk = Ek₂ − Ek₁ = ½mv₂² − ½mv₁²
  - 适用条件：适用于单个物体或系统（注意内力做功）
  - 优势：不涉及运动过程细节，只看初末状态
- **重力势能**：Ep = mgh（h为相对参考面的高度，可正可负）
  - 重力做功与路径无关，只与初末高度差有关
  - 重力做正功 → 重力势能减小；重力做负功 → 重力势能增大
  - W_G = −ΔEp
- **弹性势能**：弹簧弹力做功等于弹性势能变化量的负值
  - Ep = ½kx²（x为形变量）
  - 弹力做正功 → 弹性势能减小
- **机械能**：E = Ek + Ep（动能 + 势能）
- **机械能守恒定律**：
  - 条件：只有重力（和弹簧弹力）做功
  - 表达式：E₁ = E₂，即 Ek₁ + Ep₁ = Ek₂ + Ep₂
  - 或 ΔEk = −ΔEp（动能增加量 = 势能减少量）
  - 注意：系统内力中的滑动摩擦力做功会生热，机械能不守恒
- **功能关系**（综合）：
  - 合外力做功 = 动能变化量：W合 = ΔEk
  - 重力做功 = 重力势能变化量的负值：WG = −ΔEp
  - 除重力/弹力外的力做功 = 机械能变化量：W其他 = ΔE
  - 一对滑动摩擦力做功的代数和 = 系统内能增加量（Q = f·Δx_相对）
- **能量守恒定律**：能量不会凭空产生或消失，只会从一种形式转化为另一种形式
- **核心公式/结论**：
  - W = Flcosα
  - P = Fv（瞬时功率，同向时）
  - 动能定理：W总 = ½mv₂² − ½mv₁²
  - 机械能守恒：Ek₁+Ep₁ = Ek₂+Ep₂
  - 功能关系：W其他 = ΔE机

### 第六章 动量

- **动量**：p = mv（矢量，方向与速度方向一致）
- **冲量**：I = Ft（矢量，方向与力方向一致）
- **动量定理**：
  - 合外力的冲量等于物体动量的变化量
  - I合 = Δp = mv₂ − mv₁
  - F合·t = mv₂ − mv₁
  - 方向性：冲量方向与动量变化量方向一致
  - 应用：缓冲、打击问题（增大作用时间减小力）
- **动量守恒定律**：
  - 条件：系统不受外力或受合外力为零
  - 近似条件：内力远大于外力（碰撞、爆炸等短时间过程）
  - 表达式：m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'（一维情况）
  - 矢量性：必须规定正方向，注意速度的正负
- **碰撞**：
  - 弹性碰撞：动量守恒 + 动能守恒
    - m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'
    - ½m₁v₁² + ½m₂v₂² = ½m₁v₁'² + ½m₂v₂'²
    - 结论：v₁' = [(m₁−m₂)v₁ + 2m₂v₂]/(m₁+m₂)
    - 特例：等质量弹性碰撞 → 交换速度
  - 非弹性碰撞：动量守恒，动能不守恒（有损失）
  - 完全非弹性碰撞：碰后粘在一起，动能损失最大
    - v共 = (m₁v₁ + m₂v₂)/(m₁ + m₂)
  - 反冲运动：系统动量守恒，初始总动量为零时 m₁v₁ = m₂v₂
- **核心公式/结论**：
  - 动量定理：Ft = Δp = mv₂ − mv₁
  - 动量守恒：Σmv = 常量（条件成立时）
  - 弹性碰撞等质量交换速度

   - 集合元素的特性：确定性、互异性、无序性
   - 集合的表示方法：列举法、描述法、Venn图法

2. **集合间的关系**
   - 子集（⊆）：A中所有元素都在B中
   - 真子集（⊊）：A是B的子集且A≠B
   - 集合相等（=）：A⊆B且B⊆A
   - 空集（∅）：不含任何元素的集合；∅是任何集合的子集

3. **集合的运算**
   - 交集 A∩B = {x | x∈A 且 x∈B}
   - 并集 A∪B = {x | x∈A 或 x∈B}
   - 补集 ∁UA = {x | x∈U 且 x∉A}
   - 重要公式：|A∪B| = |A| + |B| − |A∩B|

4. **充分条件与必要条件**
   - p⇒q：p是q的充分条件，q是p的必要条件
   - 四种关系判断：
     - 充分不必要：p⇒q 但 q⇏p
     - 必要不充分：q⇒p 但 p⇏q
     - 充要：p⇔q
     - 既不充分也不必要：p⇏q 且 q⇏p

5. **全称量词与存在量词**
   - 全称量词 ∀："对所有""任意"
   - 存在量词 ∃："存在""有些"
