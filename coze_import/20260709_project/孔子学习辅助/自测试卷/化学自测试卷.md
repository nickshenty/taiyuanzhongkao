## 一、单项选择题

**1. D**

[知识点：物理变化与化学变化]　A 碘升华、B 干冰升华、C 钠熔化均为状态变化，无新物质生成，属物理变化。D 氯酸钾受热分解：2KClO₃ =（MnO₂，△）= 2KCl + 3O₂↑，有新物质生成，属化学变化。

**2. C**

[知识点：纯净物与混合物]　A 盐酸是 HCl 的水溶液（混合物）；B 漂白粉是 Ca(ClO)₂ 和 CaCl₂ 的混合物；D 铝热剂是铝粉和金属氧化物的混合物。C 液氯为纯净的 Cl₂，属纯净物。

**3. B**

[知识点：物质分类与电解质概念]　A 错，Na₂CO₃ 是盐不是碱；B 正确，NaHCO₃ 含可电离的 H⁺，属酸式盐；C 错，SO₂ 溶于水生成 H₂SO₃ 能导电，但 SO₂ 本身不能电离，是非电解质（H₂SO₃ 才是电解质）；D 错，Na₂O₂ 含过氧键（—O—O—），属过氧化物，不是碱性氧化物。

**4. C**

[知识点：强电解质与弱电解质]　A 醋酸（CH₃COOH）是弱电解质；B 氨水是弱电解质 NH₃·H₂O 的水溶液，且为混合物；D 蔗糖是非电解质。C 碳酸钙（CaCO₃）虽难溶于水，但溶解的部分完全电离，属强电解质。

**5. B**

[知识点：离子共存]　A 中 H⁺ 与 CO₃²⁻ 反应产生 CO₂，不能共存；C 中 Fe³⁺、Cu²⁺ 与 OH⁻ 生成沉淀，不能共存；D 中 Ba²⁺ 与 SO₄²⁻ 生成 BaSO₄ 沉淀，不能共存。B 中 Na⁺、K⁺、NO₃⁻、SO₄²⁻ 互不反应，可大量共存。

**6. C**

[知识点：离子方程式的含义]　A 中 Cu(OH)₂ 难溶，不能拆写，离子方程式为 3H⁺ + Cu(OH)₂ = Cu²⁺ + 3H₂O，不符合；B 中生成 BaSO₄ 沉淀，离子方程式为 2H⁺ + SO₄²⁻ + Ba²⁺ + 2OH⁻ = BaSO₄↓ + 2H₂O，不符合；D 中醋酸（CH₃COOH）为弱酸，不能拆写，不符合。C 中 HCl + NaOH = NaCl + H₂O，各物质均可溶可拆，离子方程式为 H⁺ + OH⁻ = H₂O，正确。

**7. B**

[知识点：离子的检验]　① 加过量稀硝酸产生无色气体（CO₂），说明原溶液中一定含有 CO₃²⁻；② 在①酸化后的溶液中加 AgNO₃ 产生白色沉淀（AgCl），说明含有 Cl⁻（HNO₃ 不含 Cl⁻，无干扰）；③ 另取**原溶液**加 BaCl₂ 产生白色沉淀，但原溶液已含 CO₃²⁻，BaCO₃ 也是白色沉淀，故无法确定是否含 SO₄²⁻。因此一定含有的是 CO₃²⁻ 和 Cl⁻，选 B。

**8. B**

[知识点：氧化还原反应判断]　B 中 CaO + H₂O = Ca(OH)₂，各元素化合价不变（Ca 为 +2，O 为 -2，H 为 +1），非氧化还原反应。A（Na: 0→+1，Cl: 0→-1）、C（O: -1→-2 和 0）、D（Fe: 0→+2，Cu: +2→0）均有化合价变化。

**9. B**

[知识点：电子转移分析]　反应物 Cl₂ 中 Cl 为 0 价。产物 NaCl 中 Cl 为 -1 价（被还原，5 个 Cl 原子）；NaClO₃ 中 Cl 为 +5 价（被氧化，1 个 Cl 原子）。被氧化:被还原 = 1:5，选 B。

**10. D**

[知识点：氧化剂、还原剂概念]　A 错，氧化剂化合价降低（被还原）；B 错，还原剂发生氧化反应（化合价升高）；C 错，元素由化合态到游离态可能被还原（如 Fe²⁺ → Fe）也可能被氧化（如 2Cl⁻ → Cl₂）；D 正确，金属单质化合价为 0，化学反应中化合价只能升高，作还原剂。

**11. B**

[知识点：氧化还原定量计算]　n(Cl₂) = 2.24 L ÷ 22.4 L/mol = 0.1 mol。由方程式 MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O，4 mol HCl 中 2 mol 被氧化（生成 Cl₂，Cl: -1→0），2 mol 起酸性作用（生成 MnCl₂，Cl 保持 -1 价）。被氧化的 HCl 的物质的量 = 0.1 mol × (2/1) = 0.2 mol，选 B。

**12. D**

[知识点：钠与水反应]　D 错误。钠与水反应生成 NaOH，溶液呈碱性，滴加酚酞后变红色。A（浮：密度小）、B（熔：反应放热使钠熔化）、C（游、响：反应剧烈）均为正确现象。

**13. A**

[知识点：铝的化合物的两性]　加入过量 NaOH 溶液：Mg²⁺ + 2OH⁻ = Mg(OH)₂↓（Mg(OH)₂ 不溶于过量 NaOH），Al³⁺ + 3OH⁻ = Al(OH)₃↓，Al(OH)₃ + OH⁻ = AlO₂⁻ + 2H₂O（Al(OH)₃ 溶于过量 NaOH）。过滤后，沉淀为 Mg(OH)₂，滤液中含 AlO₂⁻（已除去 Al³⁺）。将 Mg(OH)₂ 沉淀溶于适量盐酸即得 MgCl₂ 溶液。B 氨水碱性弱，不能溶解 Al(OH)₃，两者沉淀无法分离；C、D 不反应。

**14. B**

[知识点：硫及其化合物的性质]　A 错，SO₂ 使品红褪色是可逆的，加热后红色复原；B 正确，常温下铁在浓硫酸中钝化，表面形成致密氧化膜；C 错，SO₂ 是化合漂白（生成不稳定的无色化合物），Cl₂ 是氧化漂白（破坏有色物质的发色基团），原理不同；D 错，Cu + 2H₂SO₄(浓) =（△）= CuSO₄ + SO₂↑ + 2H₂O，浓硫酸既表现强氧化性（S: +6→+4）又表现酸性（生成 CuSO₄ 中的 SO₄²⁻）。

**15. C**

[知识点：氮及其化合物的性质]　C 错误，稀硝酸与铜反应产生 NO 气体：3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。A（2NO + O₂ = 2NO₂）、B（3NO₂ + H₂O = 2HNO₃ + NO）、D（N₂ + 3H₂ = 2NH₃，属人工固氮）均正确。

## 三、离子方程式书写题

**21.**（3 分）

第一步（少量酸时）：CO₃²⁻ + H⁺ = HCO₃⁻（1.5 分）

第二步（酸过量时）：HCO₃⁻ + H⁺ = H₂O + CO₂↑（1.5 分）

> 知识点：碳酸根离子与酸反应分两步进行。先转化为碳酸氢根，再转化为碳酸分解为 CO₂ 和 H₂O。

**22.**（3 分）

Fe³⁺ + 3OH⁻ = Fe(OH)₃↓

> 知识点：FeCl₃ 和 NaOH 均为强电解质，拆写后 Fe³⁺ 与 OH⁻ 结合生成难溶的 Fe(OH)₃ 沉淀。

**23.**（3 分）

第一步：Al³⁺ + 3OH⁻ = Al(OH)₃↓（1.5 分）

第二步：Al(OH)₃ + OH⁻ = AlO₂⁻ + 2H₂O（1.5 分）

> 知识点：Al(OH)₃ 是两性氢氧化物，既能与酸反应又能与碱反应。加少量 NaOH 时生成 Al(OH)₃ 沉淀；加过量 NaOH 时 Al(OH)₃ 溶解生成偏铝酸根 AlO₂⁻。

## 四、实验题

**24.**（8 分）

（1）MnO₂ + 4HCl(浓) =（△）= MnCl₂ + Cl₂↑ + 2H₂O（2 分）

> Mn 元素化合价从 +4 降为 +2（被还原），HCl 中部分 Cl 从 -1 升为 0（被氧化）。

（2）B 装置的作用：除去 Cl₂ 中混有的 HCl 气体（饱和食盐水可溶解 HCl，而对 Cl₂ 溶解度较小）；C 装置的作用：干燥 Cl₂（浓硫酸吸收水蒸气）。（2 分）

（3）向上排空气法（Cl₂ 密度比空气大，且不与空气反应）。（1 分）

（4）Cl₂ + 2OH⁻ = Cl⁻ + ClO⁻ + H₂O（1 分）

> Cl₂ 与 NaOH 发生歧化反应，生成 NaCl 和 NaClO。

（5）若无 B 装置，HCl 气体随 Cl₂ 一同进入后续装置。HCl 溶于水使溶液呈酸性，会干扰 Cl₂ 的性质实验（如使石蕊试液变红而非先变红后褪色）；同时 HCl 也会与 NaOH 反应，消耗尾气处理液，降低尾气处理效果。（2 分）

## 五、计算推断题

**25.**（9 分）

（1）n(Al) = m/M = 5.4 g ÷ 27 g/mol = **0.2 mol**（2 分）

（2）由化学方程式 2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑

化学计量数关系：n(Al) : n(H₂) = 2 : 3

n(H₂) = 0.2 mol × (3/2) = 0.3 mol

V(H₂) = n × Vm = 0.3 mol × 22.4 L/mol = **6.72 L**（标准状况下）（3 分）

（3）NaOH 恰好完全反应，n(NaOH) : n(Al) = 2 : 2 = 1 : 1

n(NaOH) = 0.2 mol

c(NaOH) = n/V = 0.2 mol ÷ 0.200 L = **1.0 mol/L**（4 分）

**26.**（9 分）

**推断过程：**

- X 最外层电子数 = 内层电子数 × 2：X = C（6 号），内层 2 个电子，最外层 4 个，4 = 2 × 2 ✓
- Y 是地壳中含量最高的元素：Y = O（8 号）✓
- Z 与 Y 同主族（第 VIA 族），原子序数 > Y：Z = S（16 号）✓
- W 最外层电子数比 Z 多 1：Z = S（最外层 6），W 最外层 7，原子序数 > 16：W = Cl（17 号）✓

（1）X = **C**，Y = **O**，Z = **S**，W = **Cl**（2 分）

（2）X 与 Y 形成的化合物为 CO₂，含**共价键**（C=O 双键），属于**分子**晶体。（2 分）

（3）Z(S) 的最高价为 +6，最高价氧化物对应水化物为 **H₂SO₄**。（1 分）

（4）Z 单质（S）在 Y 单质（O₂）中燃烧：**S + O₂ =（点燃）= SO₂**（2 分）

（5）X(C) 的最高价氧化物对应水化物为 H₂CO₃（弱酸），W(Cl) 的最高价氧化物对应水化物为 HClO₄（最强酸）。非金属性 Cl > C，故最高价含氧酸酸性：**HClO₄ > H₂CO₃**（2 分）
