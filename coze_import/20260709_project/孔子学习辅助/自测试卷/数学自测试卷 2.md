- 但 $x^2 > 1$ 时，$x > 1$ 或 $x < -1$，不一定 $x > 1$，所以不必要。
- 故为充分不必要条件。

**7. 答案：B**

**知识点：** 等差数列的性质

**8. 答案：A**

## 三、填空题

**13. 答案：$-2$**

**知识点：** 函数的极值

**解析：**
$f(x) = x^3 - 3x$，$f'(x) = 3x^2 - 3 = 3(x^2 - 1)$。

令 $f'(x) = 0$ 得 $x = \pm 1$。

- $x = 1$：$f'(x)$ 从负变正（左负右正），为极小值点。
- $x = -1$：$f'(x)$ 从正变负（左正右负），为极大值点。

极小值 $f(1) = 1 - 3 = -2$。

- $\cos\alpha = \dfrac{x}{r} = \dfrac{-3}{5} = -\dfrac{3}{5}$

$$\tan\alpha + \cos\alpha = -\frac{4}{3} + \left(-\frac{3}{5}\right) = -\frac{20}{15} - \frac{9}{15} = -\frac{29}{15}$$

**解析：**
$\dfrac{x-1}{x+2} < 0$ 等价于 $(x-1)(x+2) < 0$。

**16. 答案：$0$**

## 四、解答题

**17. 参考答案与解析**

**知识点：** 三角函数 $y = A\sin(\omega x + \varphi)$ 的图像与性质

**解析：**

**（1）** $f(x) = 2\sin\left(2x + \dfrac{\pi}{6}\right)$

- 振幅 $A = 2$
- 周期 $T = \dfrac{2\pi}{\omega} = \dfrac{2\pi}{2} = \pi$

**（2）** 求 $f(x)$ 的单调递增区间：

令 $u = 2x + \dfrac{\pi}{6}$，$y = 2\sin u$ 递增 $\Leftrightarrow u \in \left[2k\pi - \dfrac{\pi}{2},\; 2k\pi + \dfrac{\pi}{2}\right]$，$k \in \mathbb{Z}$。

$$2k\pi - \frac{\pi}{2} \leq 2x + \frac{\pi}{6} \leq 2k\pi + \frac{\pi}{2}$$

$$2k\pi - \frac{2\pi}{3} \leq 2x \leq 2k\pi + \frac{\pi}{3}$$

$$k\pi - \frac{\pi}{3} \leq x \leq k\pi + \frac{\pi}{6}, \quad k \in \mathbb{Z}$$

单调递增区间为 $\left[k\pi - \dfrac{\pi}{3},\; k\pi + \dfrac{\pi}{6}\right]$，$k \in \mathbb{Z}$。

**（3）** 当 $x \in \left[0, \dfrac{\pi}{2}\right]$ 时：

$$u = 2x + \frac{\pi}{6} \in \left[\frac{\pi}{6},\; \pi + \frac{\pi}{6}\right] = \left[\frac{\pi}{6},\; \frac{7\pi}{6}\right]$$

$\sin u$ 在 $\left[\dfrac{\pi}{6}, \dfrac{\pi}{2}\right]$ 上递增，最大值 $\sin\dfrac{\pi}{2} = 1$；
$\sin u$ 在 $\left[\dfrac{\pi}{2}, \dfrac{7\pi}{6}\right]$ 上递减，$\sin\dfrac{7\pi}{6} = -\dfrac{1}{2}$。

- 最大值：$2 \times 1 = 2$
- 最小值：$2 \times \left(-\dfrac{1}{2}\right) = -1$

值域为 $[-1, 2]$。

**解析：**

$$n = \frac{1 \pm \sqrt{1 + 2400}}{6} = \frac{1 \pm \sqrt{2401}}{6} = \frac{1 \pm 49}{6}$$

正根 $n = \dfrac{50}{6} \approx 8.33$，负根 $n = -8$（舍去）。

故 $n > 8.33$，最小正整数 $n = 9$。

验证：$S_8 = \dfrac{8 \times 23}{2} = 92 < 100$，$S_9 = \dfrac{9 \times 26}{2} = 117 > 100$ ✓

**（3）** $b_n = \dfrac{1}{a_n \cdot a_{n+1}} = \dfrac{1}{(3n-2)(3n+1)}$

利用裂项：$\dfrac{1}{(3n-2)(3n+1)} = \dfrac{1}{3}\left(\dfrac{1}{3n-2} - \dfrac{1}{3n+1}\right)$

$$T_n = \frac{1}{3}\left[\left(\frac{1}{1} - \frac{1}{4}\right) + \left(\frac{1}{4} - \frac{1}{7}\right) + \cdots + \left(\frac{1}{3n-2} - \frac{1}{3n+1}\right)\right]$$

$$= \frac{1}{3}\left(1 - \frac{1}{3n+1}\right) = \frac{1}{3} \cdot \frac{3n+1-1}{3n+1} = \frac{n}{3n+1}$$

**20. 参考答案与解析**

**知识点：** 空间线面垂直关系、线面角、三棱锥体积

**解析：**

设正方体棱长为 $a$。建立空间直角坐标系：

$A(0,0,0)$，$B(a,0,0)$，$C(a,a,0)$，$D(0,a,0)$，$A_1(0,0,a)$，$B_1(a,0,a)$，$C_1(a,a,a)$，$D_1(0,a,a)$。

**（1）** 证明 $BD \perp AC_1$：

- $\vec{BD} = D - B = (-a, a, 0)$
- $\vec{AC_1} = C_1 - A = (a, a, a)$
- $\vec{BD} \cdot \vec{AC_1} = (-a)(a) + (a)(a) + (0)(a) = -a^2 + a^2 + 0 = 0$

$\vec{BD} \cdot \vec{AC_1} = 0$，故 $BD \perp AC_1$。$\square$

**（2）** 求直线 $AC_1$ 与平面 $BCC_1B_1$ 所成角的正弦值：

平面 $BCC_1B_1$ 的法向量：该平面过 $B(a,0,0)$，$C(a,a,0)$，$C_1(a,a,a)$，法向量为 $\vec{n} = (1, 0, 0)$（即 $x$ 轴方向，因为该平面为 $x = a$）。

$\vec{AC_1} = (a, a, a)$，设线面角为 $\theta$。

$$\sin\theta = \frac{|\vec{AC_1} \cdot \vec{n}|}{|\vec{AC_1}| \cdot |\vec{n}|} = \frac{|a \times 1 + a \times 0 + a \times 0|}{\sqrt{a^2+a^2+a^2} \times 1} = \frac{a}{\sqrt{3}a} = \frac{\sqrt{3}}{3}$$

直线 $AC_1$ 与平面 $BCC_1B_1$ 所成角的正弦值为 $\dfrac{\sqrt{3}}{3}$。

**（3）** 求三棱锥 $D_1$-$ABD$ 的体积：

三棱锥 $D_1$-$ABD$ 的底面为 $\triangle ABD$，高为 $D_1$ 到平面 $ABCD$ 的距离。

- 底面 $\triangle ABD$：$A(0,0,0)$，$B(a,0,0)$，$D(0,a,0)$
  - $S_{\triangle ABD} = \dfrac{1}{2} \times a \times a = \dfrac{a^2}{2}$
- 高 $h = a$（$D_1$ 到平面 $ABCD$ 的距离为棱长 $a$）

$$V_{D_1\text{-}ABD} = \frac{1}{3} \times S_{\triangle ABD} \times h = \frac{1}{3} \times \frac{a^2}{2} \times a = \frac{a^3}{6}$$
