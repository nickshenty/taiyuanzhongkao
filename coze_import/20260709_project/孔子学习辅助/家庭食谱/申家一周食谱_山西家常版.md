# 申家一周食谱（家常版·v4）

> 根据《中国居民膳食指南（2022）》及《中国学龄儿童膳食指南（2022）》编制
> **v4调整说明**：早餐牛奶+鸡蛋+面包+配菜；午餐按"一天面、两天米"节奏安排，吃米至少两道菜；口味南北融合不局限于山西

## 膳食原则

- **每日食物种类≥12种**，每周≥25种
- **三餐能量分配**：早餐25-30%，午餐30-40%，晚餐30-35%
- **天天喝奶**：每日300ml以上液态奶
- **深色蔬菜**占蔬菜总量一半以上
- **全谷物**占主食1/3以上
- 早餐包含谷薯类、蔬菜水果、动物性食物、奶类中**三类及以上**
- 午餐和晚餐制作时间不超过1小时，早餐10-15分钟
- **早餐模式**：牛奶+鸡蛋+面包+配菜，不安排面食
- **午餐节奏**：一天面、两天米，循环安排
- **吃米时**：至少两道菜（主菜+副菜），可配汤
- **吃面时**：安排臊子/卤（面条超市购买成品）

## 食材准备计划

### 周日晚上（妈妈准备本周）
1. **卤牛肉**：牛腱子500g+老抽+八角+桂皮+香叶，大火烧开转小火煮90分钟，关火浸泡入味，冷藏切片。够周一至周三早餐
2. **泡发海带丝**：干海带丝100g泡水
3. **泡发木耳**：干木耳15g泡发
4. **检查鸡蛋存量**：确保30个左右
5. **检查牛奶和面包**：牛奶5L，面包先买3袋（周三补）
6. **包饺子**：周日午餐多包冷冻备用
7. **预约小米粥**：电饭煲定时周一早上
8. **熟花生**：花生50g提前煮熟

### 每天晚上（妈妈准备次日）
1. **预约小米粥**（如次日配粥）
2. **检查面包存量**：不够提前买
3. **蔬菜清洗**：菠菜、西兰花前一晚洗好沥水
4. **干品提前泡发**：海带丝/木耳需提前一晚

### 周三补充采购
1. **面包**：补2袋
2. **绿叶菜**：菠菜、西兰花再买一轮
3. **黄瓜**：补2-3根
4. **西红柿**：补1kg
5. **鸡蛋**：检查余量补1板
