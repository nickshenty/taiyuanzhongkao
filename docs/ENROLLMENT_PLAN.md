# 招生计划数据（Enrollment Plans）

> 状态：**数据已齐备（2019–2024，523 条）** ｜ **模型验证结论：不纳入预测模型**

招生计划数（各校当年招多少人）曾被假设为分数线波动的重要外生变量
（扩招压低分数线、缩招抬高分数线）。本文档记录数据采集与**特征有效性验证**结果。

## 二、特征有效性验证（结论：不纳入）

脚本：`scripts/analyze-plan-feature.js`

### 方法

对 2020–2024 共 **377 个样本**（学校×年份），计算：

```
residual   = 实际录取线 - 模型预测线
planChange = (本年计划 - 上年计划) / 上年计划
```

若计划数有解释力，应观察到 **扩招 → 实际低于预测（残差为负）** 的系统性关系。

### 结果

| 指标 | 数值 |
|------|------|
| 计划变化率 | 均值 +3.5%，标准差 16.0% |
| 残差 | 均值 −0.44 分，标准差 12.08 分 |
| **相关系数 r** | **0.0051** |
| 回归斜率 k | 0.39 分 / 单位变化率 |
| **t 统计量** | **0.10**（\|t\|>2 才约 5% 显著）|

**分组观察（残差均值）：**

| 计划变化 | 样本数 | 平均残差 | 理论预期 |
|---------|-------|---------|---------|
| 大幅扩招 ≥20% | 35 | −2.80 分 | 负 ✓ |
| 扩招 5~20% | 41 | **+3.80 分** | 负 ✗ |
| 基本持平 ±5% | 264 | −0.56 分 | ≈0 ✓ |
| 缩减 5~20% | 19 | **−6.68 分** | 正 ✗ |
| 大幅缩减 ≥20% | 18 | **+2.89 分** | 正 ✓ |

五组中两组符合理论、两组方向相反、一组接近 0——**符号不一致说明是噪声而非信号**。

**加入修正项后的 MAE：**

| 方案 | MAE | 相对基线 |
|------|-----|---------|
| 基线 | 8.06 | — |
| 全量修正 k=0.39 | 8.07 | +0.00 |
| 仅 \|变化\|≥10% 修正 | 8.07 | +0.00 |

**没有改善，甚至略微变差。**

### 结论

> **不将招生计划变化纳入预测模型。**

原因分析：
1. 官方"招生计划"包含特长生、小语种班、特色实验班、统招、定向等**全部类别**，
   统招部分的变化被稀释；
2. 多数学校年度计划变动在 ±5% 以内，有效变异太小；
3. 相对位置模型本身已通过历史分数线间接吸收了规模效应。

保留数据与脚本，便于未来在更大样本或更细口径（如仅统招计划）下重新检验。
