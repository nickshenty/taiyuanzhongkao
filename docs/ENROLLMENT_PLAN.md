# 招生计划数据（Enrollment Plans）

> 状态：**数据已齐备（2019–2026，703 条）** ｜ **模型验证结论：不纳入预测模型**

招生计划数（各校当年招多少人）曾被假设为分数线波动的重要外生变量
（扩招压低分数线、缩招抬高分数线）。本文档记录数据采集与**特征有效性验证**结果。

## 二、特征有效性验证（结论：不纳入）

脚本：`scripts/analyze-plan-feature.js`

### 方法

对 2020–2026 共 **553 个样本**（学校×年份），计算：

```
residual   = 实际录取线 - 模型预测线
planChange = (本年计划 - 上年计划) / 上年计划
```

若计划数有解释力，应观察到 **扩招 → 实际低于预测（残差为负）** 的系统性关系。

### 结果

| 指标 | 数值 |
|------|------|
| 计划变化率 | 均值 +5.0%，标准差 15.5% |
| 残差 | 均值 +2.52 分，标准差 15.94 分 |
| **相关系数 r** | **0.0024** |
| 回归斜率 k | 0.25 分 / 单位变化率 |
| **t 统计量** | **0.06**（\|t\|>2 才约 5% 显著）|

**分组观察（残差均值）：**

| 计划变化 | 样本数 | 平均残差 | 理论预期 |
|---------|-------|---------|---------|
| 大幅扩招 ≥20% | 49 | +0.40 分 | 负 ✗ |
| 扩招 5~20% | 135 | **+6.11 分** | 负 ✗ |
| 基本持平 ±5% | 326 | +1.60 分 | ≈0 ✓ |
| 缩减 5~20% | 20 | **−3.24 分** | 正 ✗ |
| 大幅缩减 ≥20% | 23 | **+4.07 分** | 正 ✓ |

扩招组（应使实际线偏低）残差为正、缩减组（应使实际线偏高）残差为负——
**两组方向都与理论相反**，且与"持平组"无显著差异，说明计划变化与残差基本正交。

**加入修正项后的 MAE：**

| 方案 | MAE | 相对基线 |
|------|-----|---------|
| 基线 | 9.76 | — |
| 全量修正 k=0.25 | 9.76 | −0.000 |
| 仅 \|变化\|≥10% 修正 | 9.76 | +0.000 |

变化不足 0.001 分，**远低于 0.05 分的"有意义的改善"阈值**。

### 结论

> **不将招生计划变化纳入预测模型。**

原因分析：
1. 官方"招生计划"包含特长生、小语种班、特色实验班、统招、定向等**全部类别**，
   统招部分的变化被稀释；
2. 多数学校年度计划变动在 ±5% 以内，有效变异太小；
3. 相对位置模型本身已通过历史分数线间接吸收了规模效应。

保留数据与脚本，便于未来在更大样本或更细口径（如仅统招计划）下重新检验。

## 四、数据完整性说明

八个年份的计划数据已全部入库（2019–2026）。与分数线表的差异均属口径问题：

- **特色办学实验班**（65306 / 65312 / 66301 / 66303 / 66318 等）：
  分数线单列，但招生计划计入母体学校总额，故计划表无独立行；
- **综合高中试点班**（88007 / 88013 / 88016 / 88033 / 88046）：
  2026 年起单独出现在分数线表，招生计划另表发布；
- **阳曲县第一中学校（阳曲生源班）**（66042）：计划单列但无独立分数线；
- **山西大学附属中学晋中学校**（75028）：跨市招生单位，计划表未列。

上述差异不影响按主校代码的匹配，数据可直接用于展示与后续分析。
