## 一、为什么必须先办域名和备案

微信对小程序网络请求有三条硬性要求，缺一不可：

1. **必须 HTTPS**，不支持 `http`（[官方说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/domain.html)）
2. **必须是标准 443 端口**，不能带自定义端口
3. **境内服务器的域名必须完成 ICP 备案**，否则微信后台**无法把它加入"服务器域名"列表**

> 也就是说，小程序无法直连 `http://192.168.0.200:5173` 或任何本地地址。
> 开发阶段可以用微信开发者工具临时绕过（见第四节），但**上线必须备案域名**。

## 二、办理域名与备案（1–3 周）

### 步骤 1：注册主体与小程序

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，用**企业或个体工商户**营业执照注册小程序
2. 完成主体认证（需营业执照、法人身份证、对公账户或法人微信验证）
3. 记录小程序的 **AppID**（开发管理 → 开发设置）

### 步骤 2：购买域名

在阿里云 / 腾讯云购买一个域名（约 ¥30–60/年）。
建议就用主域名，例如 `zk-example.com`。

### 步骤 3：购买服务器并备案

- 买一台境内云服务器（2 核 2G 足够，服务器部署见 [DEPLOYMENT.md](DEPLOYMENT.md)）
- 在云厂商控制台提交 **ICP 备案**，需要：
  - 营业执照、法人身份证
  - 网站负责人信息与核验照片
  - 服务器实例（必须在该厂商购买，且备案期间不能退）
- 审核周期一般 7–20 个工作日

> 备案期间域名不能对外提供网站服务，但可以先把服务器和代码准备好。

### 步骤 4：配置域名解析与 HTTPS

备案通过后：

```bash
# DNS 添加 A 记录：zk-example.com → 你的服务器公网 IP
# 服务器上按 DEPLOYMENT.md 部署，并用 certbot 申请证书
sudo certbot --nginx -d zk-example.com
```

验证：

```bash
curl -I https://zk-example.com/api/years    # 应为 200
```

## 三、小程序后台配置

备案 + HTTPS 就绪后，在 [微信公众平台](https://mp.weixin.qq.com/) 完成：

### 1. 配置服务器域名

**开发管理 → 开发设置 → 服务器域名**

| 类型 | 填写 |
|------|------|
| request 合法域名 | `https://zk-example.com` |
| socket 合法域名 | 不需要 |
| uploadFile / downloadFile | 不需要 |

### 2. 选择服务类目

**设置 → 基本设置 → 服务类目**

- 建议选「教育 → 教育信息服务」（所需资质以平台实际提示为准）
- 若提示需要资质而你没有，可考虑「工具 → 信息查询」，
  但**页面内容必须与类目一致**（不能出现招生咨询、录取承诺等表述），否则会被驳回

### 3. 填写用户隐私保护指引

**设置 → 基本设置 → 用户隐私保护指引**

本小程序会用到：

| 信息类型 | 用途 |
|---------|------|
| 用户填写的中考分数 | 生成志愿推荐，不存储、不上传身份信息 |
| 就读初中学校 | 判断定向名额 |

> 代码层面不会获取微信昵称、头像、手机号，也不会持久化分数，
> 可在指引中如实说明"仅用于当次计算，不留存"。

## 四、本地开发与联调（无需等备案）

域名没下来之前，用开发者工具连本地后端即可完整调试。

### 1. 启动后端

```bash
cd backend
PORT=3002 npm start
curl -s localhost:3002/health      # 确认 200
```

### 2. 导入小程序项目

1. 打开**微信开发者工具** → 导入项目
2. 目录选择仓库根目录 `TaiyuanZhongkao`
3. AppID 填你自己的（或先用测试号）

### 3. 关闭域名校验

**右上角「详情」→「本地设置」→ 勾选**
「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」

> `project.config.json` 中已设 `"urlCheck": false`，导入后通常默认就是关闭的。

### 4. 切换接口地址

编辑 [utils/config.js](../utils/config.js)：

```js
const DEV_BASE  = 'http://localhost:3002'   // 开发
const PROD_BASE = 'https://zk-example.com'  // 上线后改成你的域名
```

代码会按小程序环境自动选择（`develop`/`trial` 用 DEV，`release` 用 PROD）。

### 5. 验证

- 首页输入分数（如 700）→ 选择初中（如「太原市第二中学校」）→ 生成推荐
- 应出现 冲 / 稳 / 保 三档，点任一学校进入详情页
- 详情页能看到 2027 预测线与历年录取线条形图

## 五、上传与发布

### 1. 上传代码

开发者工具右上角「上传」→ 填版本号（如 `1.0.0`）与备注。

命令行方式（需先登录 IDE）：

```bash
/Applications/wechatwebdevtools.app/Contents/MacOS/cli upload \
  --project /Users/shenzheng/Documents/TaiyuanZhongkao \
  -v 1.0.0 -d "首个版本"
```

### 2. 设为体验版验证

**公众平台 → 版本管理 → 开发版本 → 选为体验版**，扫码在真机上走一遍。

### 3. 提交审核

**版本管理 → 提交审核**，需填写：

| 项 | 建议填写 |
|----|---------|
| 功能页面 | 首页为推荐页，学校详情为二级页 |
| 测试账号 | 无需登录，勾选"不需要账号" |
| 补充说明 | 说明数据来源为公开的历年录取线，预测为统计估计 |
| 类目 | 与第二步所选一致 |

### 4. 发布

审核通过后点「发布」。发布后可再设置"分阶段发布"控制放量。

## 六、审核避坑清单

按经验，这类工具最容易因以下原因被驳回：

- [ ] **类目与实际功能不符**：选「工具」却提供教育咨询服务
- [ ] **缺少免责声明**：页面底部必须有"预测数据仅供参考，实际录取以官方发布为准"（代码已内置）
- [ ] **出现录取承诺**：严禁"保过""确保录取""内部指标"等字样
- [ ] **诱导分享**：不能出现"分享给好友解锁"之类
- [ ] **隐私指引缺失**：未填写《用户隐私保护指引》
- [ ] **数据来源不明**：审核员可能询问数据出处，准备好"太原市教育局公开公告"的说明
- [ ] **页面空白/报错**：审核时若后端未启动会直接驳回，提交前务必确认线上接口可用

```
├── app.js                  # 全局配置（API 地址、目标年份）

    ├── index/              # 首页：分数 + 选校 + 推荐
```

用到的后端接口：

| 页面 | 接口 |
|------|------|

## 九、常见问题

**Q：开发者工具里请求报 `url not in domain list`**
未勾选「不校验合法域名」，或 `utils/config.js` 里的地址写错。

**Q：真机上白屏/请求失败**
体验版和正式版**强制校验域名**，必须用已备案的 HTTPS 域名，
`http://localhost` 只在开发者工具里可用。

**Q：域名已备案但后台仍加不进去**
检查：是否为 443 端口、证书是否受信任（可用 `curl -I https://域名` 验证）、
域名是否与证书一致。

**Q：能不能不备案**
境内服务器必须备案。若用境外服务器，微信仍要求域名可访问且 HTTPS，
但**未备案域名无法在小程序后台配置**——所以实际上绕不过去。
